# 해외 구직 채널

해외 채용공고, 회사 정보와 프리랜서 일을 찾을 때 비교할 수 있는 채널 목록이다. 저장한 자료의 10곳을 모두 기록하고, 2026-10-10 공식 사이트에서 확인한 용도와 한계를 덧붙였다. 목록 보존은 사용자의 해외 취업, 프리랜서 활동이나 해당 서비스 이용 결정이 아니다.

## 채널을 고르는 기준

1. 목표 국가와 취업 자격, 사용 언어에 맞는 공고가 있는지 확인한다. 원격 공고도 허용 근무 국가, 시간대와 계약 형태가 다를 수 있다.
2. 채용공고 탐색, 회사 평판 조사, 구직 관리 도구와 프리랜서 계약을 구분한다. 같은 기준으로 채용 효과를 비교하지 않는다.
3. 탐색 플랫폼에서 발견한 공고는 기업의 공식 채용 페이지와 대조해 마감 여부와 지원 경로를 확인한다. 실제 지원 후보를 정할 때만 [[Job-Search-Tracker|구직 트래커]]에 공고 URL과 함께 기록한다.
4. 자동 지원이나 AI 이력서 기능은 사실과 지원 의도를 직접 검토한 뒤 사용한다. 플랫폼의 기능 안내와 채용 성공 효과는 별개다.

| [Jobboom](https://www.jobboom.com/fr) | 퀘벡 중심 채용공고 검색, 구직과 경력 관리 자료 | 지역, 직군과 언어에 맞는 공고를 확인한다. 사이트 규모에 관한 홍보 문구는 비교 우위의 근거로 쓰지 않는다. |
| [SimplyHired](https://www.simplyhired.com/) | 직무와 미국 지역, 원격 조건으로 채용공고 검색 | 원자료의 `SimpyHired`는 `SimplyHired`의 오기로 추정되어 공식 이름으로 기록했다. 원자료의 의도 자체는 미확인이다. 공식 홈은 Indeed와 계정을 연결한다고 안내한다. |
| [CareerBuilder](https://www.careerbuilder.com/) | 채용공고 검색, 이력서 도구와 공고 알림 | 공식 홈에서 미국 지역 검색을 확인했다. 사이트 접근 확인은 공고의 최신성이나 채용 가능성까지 보장하지 않는다. |
| [Upwork](https://www.upwork.com/) | 프리랜서 업무와 고객을 연결하는 플랫폼 | 일반 입사 채용과 계약, 수수료, 대금 지급 조건이 다르므로 별도로 검토한다. 실제 계약이나 수익은 확인하지 않았다. |
| [Eluta](https://www.eluta.ca/) | 캐나다 채용공고 검색 | 공식 홈은 Canada's Top 100 Employers 프로젝트의 구직 검색 엔진으로 소개한다. 순위와 개별 기업의 적합성은 구분한다. |
| [Glassdoor](https://www.glassdoor.com/) | 회사 리뷰, 평점과 급여 정보, 채용공고 매칭 | 확인 시 Glassdoor Recruiter 페이지로 이동했고 미국 공고와 Indeed 연결을 안내했다. 리뷰와 통계는 조사 단서이며 개인의 근무 경험이나 처우를 보장하지 않는다. |

## 목록의 권고를 해석하는 한계

LinkedIn과 Indeed 대신 이 목록을 쓰라는 권고에는 비교 기준, 대상 국가와 채용 성과 자료가 없다. Workopolis, SimplyHired와 Glassdoor의 공식 페이지에는 Indeed 연결도 명시되어 있다. 따라서 이 10곳은 추가 탐색 후보로 보존하고, 기존 채널을 중단할 근거나 사용자에게 더 낫다고 확인된 순위로 사용하지 않는다.

공식 사이트의 존재와 공개 안내만 확인했다. 회원가입, 이력서 제출, 자동 지원과 유료 결제는 수행하지 않았고 서비스의 개인정보 처리, 비용과 개별 공고 조건은 실제 이용 전에 다시 확인한다.
