# 윤회 1차 본 미팅, 면접 준비 체크리스트

> 상위: [[Interview-Prep-Yunhoe-1st-Lead-Questions|리드, 컬처핏, 역질문, 체크 TOC]]

## 기술 준비

- [ ] 데이터 격리, 권한, 상태 전이, 외부 연동의 위험을 설명할 수 있는가?
- [ ] 동시성은 잠금, 멱등성, 재시도, 복구 경로로 설명할 수 있는가?
- [ ] 비동기 흐름은 핵심 상태, 후속 효과, 실패 큐, 관측으로 나누어 설명할 수 있는가?
- [ ] 데이터 모델 변경은 이중 쓰기, 백필, 읽기 전환, 검증, 롤백의 단계로 말할 수 있는가?
- [ ] 실행 계획, 인덱스, ORM 조회 방식, 관측성의 개선 사례를 준비했는가?
- [ ] 표준의 세부 적용은 공식 원문 확인 전까지 가설로 말하는가?

## FIT와 리드 답변

- [ ] 이전 역할과 경력 전환을 외부 귀책이 아닌 배움과 다음 책임으로 설명하는가?
- [ ] 리더십을 직책이 아니라 기준, 문서화, 리뷰, 온보딩, 운영으로 설명하는가?
- [ ] 당시 사용한 Claude Code와 계층형 `CLAUDE.md` 맥락을 보존하고, AI 도구를 명세, 작은 변경, 리뷰, 테스트와 사람의 책임으로 연결하는가?
- [ ] 보안과 외부 데이터의 신뢰성을 문제, 판단, 행동, 결과와 한계로 설명하는가?
- [ ] 개인 프로젝트는 직접 물을 때만 일반화된 경험으로 꺼내는가?

## 당일과 후속 기록

- [ ] 2026-05-20 14:00, 대면 1차 본 미팅의 일정과 준비물을 확인했는가?
- [ ] 역할의 첫 문제, 성공 기준, 운영과 협업 구조를 묻는 질문을 준비했는가?
- [ ] 실제 받은 질문, 내 답변, 결과와 다음 단계는 회고에 요약했는가?
- [ ] 제3자 실명, 연락처, 개인 처우 금액, 비공개 회사 정보와 제3자 발화 원문이 없는가?
