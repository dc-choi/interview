# 피트릭스 1차, JD와 회사 분석

> [[Interview-Prep-Fitrix-1st|메인]]으로 돌아가기. JD 원문은 2026-09-29에 원티드 공고 페이지에서 확인했다. 원문의 가운뎃점은 쉼표나 연결어로 바꿔 적었다. 회사 단계, 재무, 조직 규모, 고객 수와 기술 구현은 공개 근거가 없어 쓰지 않는다.

## 1. 공개된 회사 개요

| 항목 | 확인한 내용 | 출처 |
| --- | --- | --- |
| 설립 배경 | 현대자동차 사내벤처로 출발해 2020년 스핀오프한 디지털 헬스케어 기업 | JD 회사 소개, 원티드 기업 소개 |
| 핵심 제품 | 신체정보 기반 헬스케어 플랫폼 OUTBODY. 비접촉 측정으로 자세와 신체 상태를 분석하고, 결과가 운동, 건강관리와 사후 코칭으로 이어지도록 지원 | JD |
| 제품 구성 | OUTBODY FX(검사와 해석 솔루션), OUTBODY STUDIO(데이터 통합 관리 웹, 앱 플랫폼), OUTBODY MOBILE(개인 맞춤형 체형 분석과 건강 솔루션) | 원티드 기업 소개 |
| 사용 현장 | 웰니스 센터, 기업 건강관리, 검진센터, 병원. 기업 소개에는 피트니스 센터와 필라테스 스튜디오도 있다. | JD, 원티드 기업 소개 |
| 측정 | 기업 소개는 2분 이내 체형과 근육 불균형 검사라고 설명한다. 2025-04 보도는 아웃바디 체크업이 자세, 유연성, 근력, 민첩성, 밸런스와 체성분 인자까지 100여 개 근골격 관련 항목을 2분 만에 측정해 3D 데이터로 제공한다고 전했다. | 원티드 기업 소개, 한국경제 2025-04-04 |
| 시장 | JD는 해외 시장에서도 서비스되고 있다고 적었다. 기업 소개는 국내와 일본의 피트니스, 메디컬 시장을 언급한다. 2025-04 보도는 일본 법인 설립과 일본, 유럽, 미국 인증 획득을 전했다. | JD, 원티드 기업 소개, 한국경제 |
| 미션 | JD: Read your body, connect your goal. 기업 소개: Digitalize your Body | JD, 원티드 기업 소개 |
| 고객 가치 | 회원 고객에게는 맞춤형 운동과 예방 관리, 사업장에는 측정과 관리 시간 단축, 고객별 데이터 기반 지도와 이탈률 감소 | 원티드 기업 소개 |

**미확인**: 투자 단계, 매출, 조직 규모, 개발팀 구성, 트래픽 규모, 측정 기기와 서버의 연동 방식, 데이터 저장 위치, 현재 Azure 서비스 구성, Koa와 Express와 FastAPI의 실제 사용 범위, 구독 과금 여부. 모두 역질문으로 남긴다. 준비 문서는 JD 원문 표현(신체 데이터)을 쓴다.

**BM 해석(추정, 사실 아님)**: 사업장 대상 측정 솔루션과 관리 플랫폼, 회원 대상 앱이 함께 있는 구조로 읽힌다. 과금 방식, 계약 형태와 B2B 비중은 공개 근거가 없어 면접에서 사실처럼 말하지 않는다.

## 2. 포지션 정보

| 항목 | 내용 |
| --- | --- |
| 포지션 | 백엔드 서버 개발자 (Node.js / Azure), 경력 5~15년, 정규직, 상시채용 |
| 근무지 | 서울 강남구 논현동 |
| 역할 성격 | 관리만 하는 리더가 아닌 Hands-on 시니어. 백엔드 아키텍처와 기술 방향을 주도하면서 핵심 기능 개발과 문제 해결에 직접 참여 |
| 채용 절차 | 서류전형, 1차면접, 2차면접, 최종합격. 면접일정은 추후 통보 |
| 공개 복지 | 9시~10시 자율 출근, 1년 이상 근속자 대상 매년 1주 여름방학, 복지포인트, 해외 전시회 참여 비용 지원, 간식과 음료 제공, 경조사 휴가 |

### 주요 업무 (원문 요지)

1. Node.js 기반 백엔드와 API 서버를 직접 설계하고 개발
2. Koa, Express, FastAPI 등을 활용해 서비스 시스템을 구축하고 개선
3. OUTBODY에서 발생하는 다양한 서비스와 신체 데이터를 안정적으로 처리하도록 DB 구조를 설계하고 최적화
4. Azure 기반 인프라를 설계, 운영하고 안정성과 확장성을 개선
5. 기술 구조와 개발 방향을 함께 결정하고 코드 리뷰와 개발 기준을 주도
6. 운영 장애를 직접 분석하고 원인을 해결하며 재발 방지 구조를 만듦
7. 로깅과 모니터링 시스템 구축
8. 테스트, CI/CD, 배포 환경을 지속 개선
9. AI 개발 도구를 개발, 테스트, 리팩터링, 문서화에 적극 활용
10. 기존 시스템의 비효율적인 구조나 프로세스를 제안하고 직접 개선

### 핵심 키워드

Hands-on 시니어, 신체 데이터 DB 설계, Azure, 재발 방지 구조, 로깅과 모니터링, 코드 리뷰와 개발 기준, AI 도구와 생성 코드 품질 판단, 레거시 개선, 해외 확장.
