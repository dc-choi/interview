# 한국모바일결제 1차, JD와 회사 분석

> [[Interview-Prep-KoreaMobilePayment-1st|목차]]. 회사 사실은 아래 출처에서 2026-09-29에 확인한 범위만 쓴다. 공고 원문은 웹 요약 도구로 읽었으므로 면접 전에 원문을 직접 한 번 더 대조한다.

## 1. 공개된 회사 개요

| 항목 | 확인한 내용 | 출처 |
|---|---|---|
| 회사와 서비스 | 한국모바일결제가 셀프빨래방 키오스크 결제 솔루션 바로(baro)를 운영한다 | 공고, 바로 공식 사이트 |
| 서비스 규모 표기 | 공고 문구상 전국 400여 개 셀프빨래방이 바로의 키오스크와 결제 서비스로 매장을 운영한다. 회사가 공고에 쓴 수치이며 기준일은 없다 | 공고 |
| 고객 결제 흐름 | 고객은 카드, 간편결제, 멤버십으로 충전한다. 공식 사이트는 앱으로 세탁기의 QR을 촬영하는 QR 결제, 키오스크 결제, 앱 결제를 안내한다 | 공고, 공식 사이트 |
| 점주 기능 | 점주앱으로 매출과 가격 설정을 관리한다. 공식 사이트는 점주 페이지에서 쿠폰을 선물하는 기능을 안내한다 | 공고, 공식 사이트 |
| 멤버십 | 공식 사이트 기준 월 가입비, 첫 달 무료 체험, 매달 할인쿠폰, 충전 보너스를 안내한다. 공고는 멤버십 자동결제 관리를 업무로 적는다 | 공식 사이트, 공고 |
| 방향 | 공고는 결제를 넘어 무인매장 운영 전체를 본사가 함께 책임지는 방향으로 서비스를 넓힌다고 설명한다. 본사 직접 운영 매장의 관리, 정산 기능 개발도 업무에 있다 | 공고 |
| 앱 제공자 | 앱스토어의 개발자 표기는 주식회사 한국모바일결제 | App Store |
| 근무지 | 서울 강남구 선릉로 428 위워크 | 공고 |

**미확인 (추정하지 않고 질문으로 둔다)**: 설립 연도와 사업 단계, 매출과 투자, 조직 규모와 개발 인원, 계열사가 어디인지, 사용하는 PG사와 VAN 경로, 인프라와 DB, 키오스크와 단말기의 통신 방식, 기존 개발 담당자와 인수인계 상태, 고용 형태, 채용 절차, 온콜 범위, 프론트 작업 비중.

검색에서 회사의 브랜드 수상 보도 제목이 보였으나 본문을 신뢰할 수 있게 확인하지 못해 사실로 쓰지 않는다.

## 2. 포지션 정보

| 항목 | 확인한 내용 |
|---|---|
| 포지션 | AI Product Engineer (개발, 유지보수, 서버 운영). 헤더 경력 5~10년 |
| 역할 성격 | 바로 서비스의 기술 오너. 서버, 결제 연동, 점주앱, 어드민까지 기술 전체를 맡는다. 대표 직속이며 계열사 AI 프로덕트 엔지니어와 서로 백업한다 |
| 일하는 방식 | 유지보수와 신규 기능은 AI(Claude Code, Codex)로 만들고 사람은 검수와 배포 판단, 결제 안정성에 집중한다 |
| 주요 업무 | 서버 운영(인프라, 배포와 롤백, 모니터링, 장애 대응), 유지보수(키오스크와 단말기 연동, 점주앱, 어드민 오류 수정), 결제 안정성(PG 결제, 취소, 정산 연동, 계좌이체 충전, 멤버십 자동결제), 운영 자동화(멤버십 해지와 환불 셀프 처리, 본사 자동 CS), 신규 운영 모델(본사 직영 매장 관리와 정산), 운영 문서화(한 사람이 빠져도 서비스가 멈추지 않는 구조) |
| 자격 요건 | 실서비스 백엔드 개발, 운영 3년 이상(연차보다 결과물로 판단), Node.js(NestJS, TypeScript) 실무, 서버 운영(배포, 롤백, 모니터링, 장애 대응), 결제 또는 돈이 오가는 서비스 개발, 운영, AI로 코드를 만들고 검수해 실서비스에 올린 경험 |
| 우대 사항, 복지, 절차 | 2026-09-29 확인한 원문에서 별도 섹션을 찾지 못했다 |
| 기술 스택 | 앱 React Native, API Node.js, NestJS, TypeScript, 어드민과 웹 Next.js(React) |
| 제출 서류 | 이력서, 장애 해결 경험 1가지, AI 활용 사례 1개(있다면), 관련 링크 |

### 핵심 키워드

운영 안정성, 결제 정합성(결제, 취소, 정산, 자동결제, 충전), 단말기 연동, 운영 자동화와 셀프 처리, AI 구현과 사람의 검수, 기술 오너십, 문서화와 상호 백업.

## 6. 페르소나

이 자리에서 기대한 기여를 해낸 사람은, 전국 매장의 결제가 멈추지 않도록 배포와 롤백, 관측과 장애 대응을 혼자서도 재현 가능한 절차로 만들고, AI가 만든 변경을 결제 불변식 기준으로 검수해 안전하게 내보내며, 해지, 환불, CS처럼 사람이 손으로 하던 운영을 셀프 처리로 바꾸고, 그 모든 절차를 문서로 남겨 계열사 동료가 대신 대응할 수 있게 만든 사람이다.
