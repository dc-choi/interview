# 브랜뉴닷컴 1차 JD 분석과 경험 매칭

> [[Interview-Prep-BrandNewCom-1st|목차]]로 돌아가기. 확인일 2026-09-29. 사람인 공고 본문은 이미지로 게시돼 있어 이미지 원문을 직접 읽어 정리했다. 회사 단계, 투자와 재무, 조직 규모, 고객 수, 실제 연동 대상과 내부 구현은 공개 출처로 확인되지 않아 사실로 쓰지 않고 확인 질문으로 남긴다.

## 1. 공개된 회사 개요

| 항목 | 확인한 내용 | 출처 |
| --- | --- | --- |
| 회사 소개 | 이커머스 고객이 필요로 하는 맞춤형 솔루션을 제공해 기업의 운영 효율성과 경쟁력을 높이는 데 기여한다고 소개 | 공고 본문 |
| 운영 서비스 | 셀록홈즈, 빅타오, 리뷰브릿지 등 여러 기능을 개발하고 서비스 중이라고 명시. 자사 운영 서비스 홈페이지로 셀록홈즈 주소를 안내 | 공고 본문 |
| 셀록홈즈 | 온라인 부업 셀러를 위한 도구로 소개. 키워드 분석, 쿠팡 시장 분석, 데이터 기반 상품 추천, 타오바오와 1688 상품 검색, 공급가와 마진 확인용 가격 비교, 상품 검색부터 주문과 배송까지의 원스톱 처리를 내세움 | 셀록홈즈 공식 홈페이지 |
| 과금 형태 | 셀록홈즈에 무료 체험과 유료 멤버십 요금제가 게시돼 있음 | 셀록홈즈 공식 홈페이지 |
| 지향점 | 글로벌 인플루언서 플랫폼 기업으로 발전하는 데 집중한다고 소개 | 공고 본문 |
| 문화 표기 | 복리후생 항목에 수평적인 조직 문화를 명시 | 공고 본문 |
| 빅타오, 리뷰브릿지 | 기능과 대상 고객 미확인 | 확인 질문으로 남김 |
| 사업 단계, 투자, 매출, 조직 규모, 개발 인원 | 미확인 | 추정하지 않음 |

**해석과 사실 구분**: 셀록홈즈가 셀러 대상 구독형 도구라는 것은 요금제 게시 사실에서 나온 해석이다. 회사 전체의 수익 구조, 해외 구매처가 실제로 타오바오와 1688인지, 어떤 국내 마켓과 결제, 배송 사업자와 연동하는지는 확인되지 않았다.

## 2. 포지션 정보

| 항목 | 확인한 내용 |
| --- | --- |
| 채용 직무 | 백엔드 개발자, 경력 1년 이상 |
| 근무 형태 | 계약직 이후 정규직 채용전환 가능 |
| 주요 업무 | 자사 운영 서비스 개발 및 유지보수 |
| 근무 조건 | 서울 금천구, 주 5일, 09:00~18:00. 급여는 회사 내규에 따름 |
| 채용 절차 | 서류전형, 면접(실무진), 최종합격 |
| 포지션 우대 | 관련학과 전공자와 관련 자격증 보유자 |
| 학력 표기 | 사람인 요약은 대학교 졸업(4년) 이상, 공고 본문은 학력 무관으로 서로 다름. 확인 필요 |

출처: [사람인 공고 상세](https://www.saramin.co.kr/zf_user/jobs/relay/view-detail?rec_idx=55132071), [셀록홈즈 공식 홈페이지](https://sellochomes.co.kr/). 둘 다 2026-09-29 확인.

### 함께할 업무 (공고 원문 요약)

1. 국내 마켓, 해외 구매처, 결제와 배송 등 외부 서비스와 연동하고 주문, 정산, 알림 등의 업무 자동화
2. 기존 서비스 데이터 흐름을 이해하고 연동 실패, 중복 처리, 재시도 등 운영 중 발생하는 문제를 함께 해결
3. 기존 시스템을 점진적으로 개선하고 코드, 설계, 운영 절차를 문서화해 지식을 공유
4. 필요에 따라 관리자 및 고객용 웹 화면 개발

### 핵심 키워드

- 외부 연동의 실패 경로: 연동 실패, 중복 처리, 재시도가 업무 문장에 직접 적혀 있다. 이 역할의 평가 축은 기능 구현보다 운영에서 깨지지 않는 연동이다.
- 업무 자동화: 주문, 정산, 알림. 금액과 상태가 걸린 흐름이라 멱등성과 대사가 필요하다.
- 점진적 개선과 문서화: 새로 만들기보다 기존 흐름을 이해하고 안전하게 바꾸는 역할이다.
- 넓은 범위: React 화면 수정, 리눅스 운영, CI/CD, 클라우드까지 한 사람이 넓게 다루는 구성이다.

## 6. 매칭 요약

- **강**: Node.js와 NestJS API, MySQL 쿼리, 외부 API 연동, Docker와 CI/CD, AWS, AI 도구 검토. 업무 문장의 연동 실패, 중복, 재시도는 기술 카드 1, 2와 시솔지주 배치 경험으로 직접 답할 수 있다.
- **중**: 커머스 도메인(결제 직접 연동 범위 미확인), 배치와 스크래핑(브라우저 자동화 제외), 리눅스 장애 분석.
- **약**: React, Next.js 화면 개발, 브라우저 자동화, Azure. 자격 요건 가운데 유일한 약 항목은 React이므로 면접에서 먼저 물어볼 가능성이 높다.
