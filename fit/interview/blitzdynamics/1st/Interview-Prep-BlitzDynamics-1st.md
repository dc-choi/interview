## 0. 1차 전략

- **이 자리는 백엔드 개발 공고가 아니다.** 공고는 무엇을 만들지 정하는 일부터 맡고, 다른 팀이 실제로 쓰고 일이 줄었다는 확인까지를 한 사이클로 정의한다. 기술 깊이보다 업무 분해, 우선순위 판단, 채택 유도, 성과 확인을 묻는 질문이 중심일 것으로 보고 답변을 이 순서로 정렬한다.
- **가장 강한 카드는 팀 AI 협업 규약이다.** AI가 건드릴 영역과 안 되는 영역을 명시하고 작업 종료 시 자동 검증 루프를 만들었으며, 작은 영역부터 적용해 동료가 따라오게 했다. 이 경험이 공고의 1번(도구 고도화), 2번(저조한 팀 지원), 4번(공통 인프라)에 모두 닿는다.
- **두 번째 카드는 반복 업무 자동화다.** 수기 발주의 이벤트 자동화, IoT 상태 리포트 자동 통보. 자동 경로와 사람 확인 경로를 함께 설계했다는 점을 업무 분해 요건에 연결한다.
- **경험 경계를 먼저 밝힌다.** 비개발자용 LLM 에이전트를 제품으로 배포한 경험, 사업 지표로 자동화 우선순위를 매긴 경험, 조직 운영 에이전트 경험은 없다. 설계 질문에는 학습한 원칙과 판단 기준으로 답하되 해본 것처럼 말하지 않는다.
- **퇴사 사유는 확정 답변(FIT C3)으로 짧게 말한다.** 재직 기간은 트라이포드랩 2024.02~2026.05, 키노라이츠 2026.06.29~2026.09.15로 확인했다. 백엔드에서 AX 역할로 넓히는 이유는 아직 확정되지 않았다.
- 답변 마무리는 공개된 역할(팀이 직접 자동화하는 공통 인프라, 일이 줄었는지의 확인)에 한 문장으로 연결한다. 회사 매출, 매장 계획, 조직 규모는 인용하지 않는다.

### 우선 준비 사항

1. **재직 이력 정합성 (확정)**: 이력서의 키노라이츠 재직중 표기를 2026.06~2026.09로, 요약 문단의 현재 시제를 과거로 고친다(트라이포드랩은 2024.02~2026.05, 원본 수정은 사용자 몫).
2. **이직 사유와 현재 활동 (확정)**: FIT 문서 C3, C4, C5 답변은 확정됐다. 30초 안에 말하는 연습을 한다. 커리어 방향(C2, C12)은 별도로 정한다.
3. 공고 5개 업무를 J1(업무 분해), J2(우선순위), J6(성과 확인) 한 흐름으로 말하는 연습. 이 셋이 공고가 정의한 한 사이클이다.
4. 팀 AI 협업 규약(R1)과 발주 자동화(R2)를 문제, 선택, 확산, 확인 순서로 2분 안에 말하는 연습.
5. 설계형 질문(J3, J5, J8)이 화이트보드나 대화형으로 나올 수 있으므로 명확화, 가정, 대안, 선택과 대가, 실패 대응 순서로 말하는 연습.

## 2. 미해결 확인 사항

| 항목 | 상태 | 필요한 결정 또는 확인 |
|---|---|---|
| 재직 기간 차이 | 확정 | 이력서의 키노라이츠 재직중 표기를 2026.06~2026.09로, 요약 문단의 현재 시제를 과거로 고친다(트라이포드랩은 2024.02~2026.05, 원본 수정은 사용자 몫). |
| 현재 이직 사유 | 확정 | 마스터의 현재 이직 사이클 절(2026-09-29 확정)을 fork한 FIT C3 답변을 쓴다. 개인 사업 활동은 먼저 밝히지 않고, 직접 물으면 사실대로 답한다 |
| 키노라이츠 퇴사 여부와 마지막 근무일 | 확정 | 2026-09-15 근무 종료. 답변은 FIT C3 |
| 사업 병행 | 확정 | 답변에 사업 내용은 넣지 않는다. 현재 활동은 회고와 다음 역할 준비로 짧게 답하고, 겸업을 직접 물으면 사실대로 답한다 (FIT C5) |
| 커리어 방향 | 미확정 | 백엔드 경력 축적 스탠스와 AX 역할 지원을 어떻게 연결할지 사용자가 정해야 한다 |
| 회사 단계, 재무, 조직 | 미확인 | 회사 소개문의 매출과 매장 수는 자기 기재이고 대부분 예상치이며 기준일이 없다. 투자 단계와 인원, 개발 조직 규모는 공식 근거가 없다 |
| 사업 구조와 고객 | 미확인 | 직영 운영과 제3자 페이지가 적은 B2B 운영 대행의 관계, 운영 브랜드 목록은 공식 근거가 없다 |
| 기술 구현 | 미확인 | 사내 바이브코딩 도구의 형태, 에이전트 스택, 데이터 소스, 개발 조직과의 역할 분담이 공개되지 않았다 |
| 공고 문안 | 확인 필요 | 회사 소개 절에 메뉴 R&D 담당자 문단이 섞여 있다. 다른 공고 문안이 섞인 것으로 보이지만 확인되지 않았다 |
| 1차 형식과 채용 절차 | 일부 확인 | 공고의 채용 전형(서류 평가, 1차에서 3차 면접, 처우 협의)은 2026-10-04 확인했다. 1차 형식, 면접관 역할, 과제나 설계 면접 여부는 공고에 없다 |
