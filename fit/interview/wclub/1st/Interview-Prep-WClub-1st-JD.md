# 더블유클럽 1차, JD와 회사 분석

> 상위 문서: [[Interview-Prep-WClub-1st|더블유클럽 1차 준비]]. 회사 사실은 2026-09-29에 공고와 공식 홈페이지에서 확인한 범위만 적는다. 공개 문구는 회사가 스스로 밝힌 내용이며 독립 검증된 수치가 아니다.

## 공개된 회사 개요

| 항목 | 확인한 내용 | 출처 |
|---|---|---|
| 서비스 | 실제 만남에 집중하는 프리미엄 매칭 서비스. 2019년부터 운영, 7년째 운영 중인 실서비스라고 소개한다. | 공고 |
| 공개 수치 | 누적 만남 111,735건(2026년 7월 기준), 애플과 구글 누적 다운로드 30만 회 이상. 공식 홈페이지는 조회 시점에 누적 만남 112,735+로 표기했다. | 공고, 공식 홈페이지 |
| 인증 방식 | 신분증, 명함, 소득 및 자산 인증의 3단계 검증과 제출 서류 기반 신원 확인을 안내한다. | 공식 홈페이지 |
| 결제 구조 | 만남권을 충전하면 만남 보장 매칭을 제안하는 방식이며, 상대방 귀책으로 약속이 취소되면 환불한다고 안내한다. | 공식 홈페이지 |
| 회사 단계, 재무, 조직 규모, 고객 구성 | 미확인. 확인 질문으로 남긴다. | 없음 |
| 기술 구현 | 공고의 스택 외 인프라, DB, 결제대행사, 인증 벤더는 미확인. | 없음 |

## 포지션 정보

| 항목 | 공개 공고 내용 |
|---|---|
| 주요 업무 | AI 결과물 검수와 실서비스 반영, API, DB 스키마, 인증과 권한, 결제 연동의 설계와 보완, 결제, 본인인증, 서류 인증 등 민감 영역 보안, 배포, 롤백, 장애 대응과 모니터링, Claude Code와 Codex 작업 규칙 및 코드 리뷰 기준 운영, 앱스토어와 구글플레이 배포 관리 |
| 자격 요건 | AI가 만든 코드를 실서비스에 배포하고 운영한 경험, Node.js(NestJS, TypeScript) 백엔드 실무, 배포, 롤백, 장애 대응 경험, AI 코드의 설계 결함과 보안 문제를 찾는 리뷰 역량, 실서비스 개발과 운영 3년 이상 |
| 우대 사항 | 2026-10-04 공고 재확인 시 별도 절이 있다. React Native와 Next.js 실무, 인앱결제와 PG 결제, 본인인증 연동, 개인정보보호 점검이나 보안 감사 대응, 테스트 자동화, CI/CD, 오류 모니터링 도구 구축, 앱스토어와 구글플레이 출시와 심사 대응, AI 중심으로 팀의 개발 방식을 바꾼 경험, 적은 인원으로 여러 서비스를 운영한 경험이다. 아래에서는 주요 업무 가운데 자격 요건에 없는 항목을 우대 성격으로 매칭한다. |
| 기술 스택 | App React Native, API Node.js와 NestJS와 TypeScript, Admin과 Web Next.js |
| 제출물 | 이력서, AI 결과물을 실서비스로 올린 사례 1개(AI가 만든 것, 직접 고친 것, 결정부터 배포까지 걸린 시간을 5줄 이내), 관련 링크(서비스, GitHub, PR 등), 운영 중 장애를 해결한 경험 1가지 |
| 채용 절차 | 서류, 3일 유료 과제, 2시간 라이브 과제, 처우 협의, 입사. 입사 4주 차 정식 확정, 수습 최대 3개월로 안내된다. 고용 형태는 공고에 표기되지 않았다. |
| 근무지 | 서울 강남구 선릉로 428 |

## 핵심 키워드

AI 결과물의 검수와 실서비스화, 민감 영역 보안(결제, 본인인증, 서류 인증), 인증과 인가, 스키마와 마이그레이션, 배포와 롤백, 장애 대응, AI 작업 규칙과 리뷰 기준, 모바일 앱 배포.

## 제출물 골격

> 아래는 형식 골격이다. 사례와 수치는 사용자가 확정해야 하며 추정으로 채우지 않는다.

1. 무엇을 만들었나: [사용자 확정 필요] 서비스와 기능 한 줄
2. AI가 만든 것: [사용자 확정 필요] 예를 들어 초기 구현, 테스트 초안, 마이그레이션 초안 중 실제로 위임한 범위
3. 직접 고친 것: [사용자 확정 필요] 인가, 트랜잭션 경계, 예외 경로처럼 리뷰에서 잡은 결함과 수정
4. 결정부터 배포까지 걸린 시간: [사용자 확정 필요]
5. 검증과 운영: [사용자 확정 필요] 배포 뒤 확인한 지표나 회귀 루프

장애 해결 경험은 이력서에 공개된 운영 개선 가운데 원인, 대응, 재발 방지를 모두 설명할 수 있는 한 건을 고른다. 시솔지주의 배치 오류 사례([[My-FIT-Answers]] 12번)가 후보다. 출석부 관련 링크를 쓸 경우 정확한 사용 수치는 적지 않는다.

## 확인 질문으로 남길 사항

- 회사 단계, 매출과 투자, 조직 규모와 개발 인원

- 서류 원본의 보관 여부와 기간, 관리자 접근 통제 방식
- 앱 릴리스 주기와 강제 업데이트 정책
