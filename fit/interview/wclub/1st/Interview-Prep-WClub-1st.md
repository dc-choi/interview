## 포지션 한 줄 해석

공고가 설명하는 역할은 AI 프로덕트 빌더와 Claude Code, Codex가 만든 결과물을 검수하고 다듬어 실서비스에 빠르고 안전하게 올리는 자리다. 핵심 평가는 새 기능을 빨리 만드는 능력보다 AI가 만든 코드에서 설계 결함과 보안 문제를 찾아내고, 결제, 본인인증, 서류 인증 같은 민감 영역을 배포, 롤백, 장애 대응까지 책임지는 능력에 있다.

## 강점

- NestJS와 TypeScript 기반 서비스를 설계부터 운영까지 맡은 경험. 동시성 정합성, 비동기 처리, 쿼리 개선, 관측과 배포 구조 전환이 이력서에 공개돼 있다.
- 인증 도메인 경험. 시솔지주에서 WebAuthn 명세를 분석해 FIDO 서버를 설계했고, 명세와 다른 오픈소스 동작을 재현해 이슈로 제기했다.
- AI 협업 규약을 팀 수준으로 표준화한 경험. AI가 건드릴 영역과 건드리면 안 되는 영역을 명문화하고 작업 종료 시점의 자기 검증 회귀 루프를 만든 내용이 이력서에 있다. JD의 작업 규칙과 코드 리뷰 기준 운영과 직접 겹친다.
- 배포와 장애 대응. 단일 NGINX 구조에서 CloudFront, ELB, ECS 구조로 전환했고 Grafana Alerting 기반 경보를 구축했다.

## 갭

- 첫 자격 요건과 제출물이 요구하는 AI 결과물을 실서비스에 올린 공개 사례와 링크. 증거 확보가 서류 통과의 선결 조건이다.
- React Native, Next.js, 앱스토어와 구글플레이 배포 경험이 이력서에 없다.
- 결제 연동과 서류 인증 보안을 직접 책임진 경험의 공개 근거가 약하다. 결제는 common 마스터의 환불 정책 사례가 유일한 연결점이다.
- 매칭 서비스와 소비자 앱 도메인 경험 없음.

## 우선 준비 사항

1. 제출물 5줄 사례와 공개 링크를 확정한다. 초안 골격은 [[Interview-Prep-WClub-1st-JD#제출물 골격|JD 문서]]에 있다.
2. AI 생성 코드 리뷰 체크리스트를 입으로 설명할 수 있게 만든다. 인가 누락, 트랜잭션 경계, 멱등성, 비밀 노출, 과다 응답, 파괴적 마이그레이션이 핵심이다.
3. 결제 멱등성, 상태 머신, 웹훅 서명 검증과 대사, 환불 경로를 한 흐름으로 설명한다.
4. 서류 인증 데이터의 수집, 저장, 접근, 폐기 경계를 설계형으로 답한다.
5. 3일 과제와 2시간 라이브 과제의 작업 순서를 리허설한다. 요구 명확화, 위험 우선 검수, 배포 판단 근거를 말로 남기는 연습이 핵심이다.

## 사용자 확정 필요 슬롯

- 이직 사유, 퇴사 사유, 현재 활동은 확정됐다(2026-09-29). FIT 문서 C1, C2, C3에 common 현재 사이클을 fork했다. 개인 사업과 1인 대표는 먼저 밝히지 않고, 직접 묻는 질문에는 사실대로 답한다.
- 경력 표기는 확정됐다. 트라이포드랩 재직은 2024.02~2026.05, 키노라이츠는 2026.06.29~2026.09.15다. 이력서 PDF에는 키노라이츠가 이미 있으나 재직중(4개월)과 현재 시제 요약 문단으로 적혀 있어, 2026.06~2026.09와 과거 시제로 고쳐야 한다(원본 수정은 사용자 몫).
- 개발 지식 온톨로지와 검색 MCP는 개인 프로젝트인데 이력서 PDF에는 키노라이츠 경력 아래에 적혀 있다. 이력서의 개인 프로젝트 항목으로 옮기는 것이 좋다(원본 수정은 사용자 몫). 면접에서는 먼저 개인 프로젝트라고 밝힌다.
- 이력서의 골든 케이스 약 145건 문구는 부정확하다(145건짜리 세트는 없고 74개와 94개 질문으로 비교). 이력서 정정 필요(원본 수정은 사용자 몫). 정정 문장은 [[Interview-Prep-WClub-1st-Tech-Resume|R10]] 참고.
- 제출할 AI 결과물 사례, 결정부터 배포까지 걸린 시간, 공개 가능한 링크.
- 총 경력 연차 표현. 공고는 4~8년, 본문은 실서비스 3년 이상을 요구한다. 이력서 기간의 합산 방식을 확인해 한 가지로 고정한다.
