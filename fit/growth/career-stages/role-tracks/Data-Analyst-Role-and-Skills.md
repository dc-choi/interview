# 데이터 분석가 역할과 역량

데이터 분석가는 조직의 질문에 답하도록 데이터를 수집, 정제, 탐색하고 결과를 전달한다. 도구 사용뿐 아니라 문제 정의, 품질 확인과 비기술 직군에게 설명하는 능력을 함께 본다.

2026-10-16 확인한 영국 정부 직무 프레임워크, Microsoft의 Power BI 직무 기준과 Google의 교육 범위를 참고한 역할 안내다. 특정 국가의 채용시장 전체나 모든 회사의 필수 요건을 뜻하지 않는다.

## 역할을 산출물로 이해한다

| 단계 | 확인할 역량 | 검토할 산출물 예시 |
| --- | --- | --- |
| 질문 정의 | 조직의 목적과 필요한 결정을 이해한다 | 분석 질문, 대상 기간과 지표 정의 |
| 데이터 준비 | 필요한 데이터를 찾고 품질 문제를 해결한다 | 입력 출처, 정제 규칙과 제외 사유 |
| 분석 | 질문에 맞는 통계와 분석 기법을 선택한다 | 재현 가능한 코드와 결과 검토 |
| 전달 | 대상의 지식과 필요에 맞춰 설명한다 | 결론, 근거, 한계와 다음 행동 |
| 관리 | 접근, 공유와 개인정보 보호 기준을 따른다 | 사용 권한과 공개 가능한 결과 범위 |

산출물 예시는 역량 확인을 위한 제안이다. 데이터 분석가도 데이터 이동, 모델링과 분석 코드를 다룰 수 있으므로 직군 이름만으로 업무를 엄격히 나누지 않는다. 실제 분업은 공고와 팀의 책임 범위에서 확인한다.

## 도구 이름과 직무 역량을 구분한다

Google의 Data Analytics 교육은 SQL, Python과 Tableau를 포함한다. 이 목록은 교육 범위의 사례이며, 모든 입문 채용에서 같은 도구를 요구한다는 증거는 아니다.

Power BI 역할은 데이터 준비, 모델링, 시각화와 분석, 관리와 보안을 함께 다룬다. Power Query와 DAX도 해당 역할의 역량에 포함된다. 따라서 차트를 만드는 능력만으로 이 직무의 준비가 끝났다고 판단하지 않는다.

도구 선택 제안: 목표 업무에서 쓰는 조회 도구와 BI 도구로 작은 분석 하나를 완성한다. Python이 필요한지는 반복 처리와 분석 요구로 판단한다. 특정 도구의 시장 우위, 급여 상승이나 취업 보장은 별도 근거 없이 전제하지 않는다.

## 작은 적합성 실험

아래는 진로 선택을 돕는 학습 예시이며 확정된 개인 학습 계획이 아니다.

1. 공개 또는 합성 주문 데이터로 월별 순매출을 계산한다. 환불 포함 여부와 날짜 기준을 먼저 정한다.
2. 중복, 누락과 형식 오류를 확인하고 처리 이유를 기록한다.
3. 원본 일부를 손으로 계산해 집계 결과와 비교한다.
4. 차트 하나와 짧은 설명으로 확인한 변화, 가능한 설명과 추가로 필요한 근거를 나눈다.
5. 다른 사람이 같은 입력과 절차로 결과를 재현하게 한다.

쿼리 작성의 재미뿐 아니라 지표 정의를 협의하고, 데이터 오류를 조사하고, 결과의 한계를 설명하는 과정도 맞는지 살핀다. 수료증 보유와 이 산출물을 독립적으로 만드는 능력은 구분한다.

- 차트가 정상적으로 표시되어도 분석 결과가 틀릴 수 있는 경우는 무엇인가?
