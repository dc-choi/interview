# 현재 목표와 통합 로드맵

2026-11-02 사용자 결정: 앞으로의 계획은 **2027학년도 후기 추천시스템 대학원 진학 준비에 집중한다. 구직은 중단하고, 자금은 아르바이트로 마련하며 공부에 집중한다.**

## 확정한 방향

- 입학 목표는 2027년 9월이다. 학교와 연구실, 학위 경로 및 상담 기록의 정본은 [[2027-AI-Masters-Plan]]이다.
- 서울대, 고려대, 연세대, 한양대, 중앙대, 서울시립대와 경희대의 7개 학교를 모두 유지한다. 학교 간판을 중요하게 고려하고 공학석사를 선호하되, 이를 후보 제외 조건으로 쓰지 않는다.
- 개발자 구직은 중단한다. 채용 후보, 지원과 전형의 과거 이력은 [[Job-Search-Tracker]]에 보존한다.
- 필요한 자금은 아르바이트로 마련할 계획이다. 아르바이트 확보나 근무 시작, 소득 발생은 아직 확인되지 않았다.
- 공부를 높은 강도로 집중해서 하겠다는 의사를 반영한다. 이전 전환기의 주 1~2회 학습 기준이나 인수인계 완료 조건을 현재 공부의 상한 또는 시작 조건으로 적용하지 않는다.
- 진학 목표를 향한 현재 학습은 **추천시스템을 직접 만드는 데 필요한 기반**에만 집중한다. Python 기초부터 필요하다는 사용자 자가 진단을 반영한다.
- 세부 학습 정본은 [[Recommender-System-Foundations-Roadmap]]이다. 대학원 지원 절차는 별도 계획으로 관리하며, 개별 학습 진도와 숙련은 별도 근거로 확인한다.

## 계획의 구성

아래는 확정한 방향을 운영하기 위한 분류다. 과목별 순서, 공부 시간과 마감일을 새로 확정한 일정은 아니다.

| 영역 | 현재 역할 | 실행 상태와 경계 |
|---|---|---|
| 추천시스템 구현 기반 | Python, 데이터 처리, 필요한 수학, 머신러닝과 추천시스템 기본 모델 및 평가 | 현재 학습 주축. Python 기초부터 시작하며 실제 진도는 미확인 |
| 대학원 지원 준비 | 7개 학교와 연구실 비교, 후기 모집과 학위 경로 확인, CV와 연구 관심 및 면접 준비 | 학습 정본과 별도로 관리. 최종 지원처와 학교별 일정은 미정 |
| 영어 | 지원 요건 충족과 논문 읽기를 위한 준비 | 현재 성적과 학교별 요구 수준 미확인 |
| 아르바이트 | 진학 준비에 필요한 자금 마련 | 사용자 채택 계획. 근무처와 시간은 미정 |
| 생활과 기존 책임 | 공부를 지속할 생활 기반과 이미 수락한 의무 유지 | 기존 계약과 필수 운영의 실제 상태는 각 프로젝트 정본에서 확인 |

Python, 수학과 머신러닝은 추천시스템 구현을 위한 구성 요소다. 공인영어와 제출서류는 대학원 지원 요건으로 별도 관리한다. 교재 보유나 지식 문서 등록을 실력이나 학습 완료로 계산하지 않는다.

## 현재 학습과 아카이브

현재 실행할 로드맵은 [[Recommender-System-Foundations-Roadmap|추천시스템 구현 기반]] 하나다. Python으로 작은 데이터를 읽고 계산하는 것부터 시작해 데이터 처리, 수학, 모델 학습과 평가를 연결한다.

기존 수학 전체 과정, 검색 우선 경로, DevOps와 SRE, Node.js 코어는 [[Archived-Learning-Roadmaps|아카이브]]로 옮겼다. 과거 계획과 체크포인트는 보존하며 현재 실행 목록과 분리한다. 범용 백엔드 확장, 자격증과 사업 학습을 현재 공부의 경쟁 목표로 다시 열지 않는다.

기존 교재와 기술 지식은 필요한 개념을 설명하는 자료로 활용할 수 있다. 과거 로드맵 전체 완독, 검색 엔진 구축이나 인프라 실습을 추천시스템 구현의 선행조건으로 요구하지 않는다.

## 기존 활동과의 관계

구직 중단은 사용자 확정 결정이다. 기업의 최종 결과, 지원 철회 통보와 약속 취소는 별도 사실이므로 완료를 추정하지 않는다. 아르바이트를 통한 자금 마련은 중단한 개발자 채용 지원과 구분한다.

사업 종료나 기존 계약 취소는 결정하지 않았다. 이미 수락한 의무, 필수 운영과 데이터 보호는 별도로 확인한다. 위클리스쿨의 최소 운영과 제품 확장은 구분하며, 진학 준비를 이유로 신규 기능, 마케팅과 수익화 실험을 자동 시작하지 않는다. 개인 자금 금액과 비공개 계약 정보는 공개 문서에 기록하지 않는다.

운동과 휴식 등 공부를 지속할 생활 기반은 유지한다. 운전면허와 주거 같은 생활 과제는 기존 기록을 보존하되, 확인하지 않은 마감이나 긴급도를 새로 부여하지 않는다.

## 세부 실행 계획에 필요한 확인

- [ ] 아르바이트 근무 조건과 실제 확보 가능한 공부 시간.
- [ ] 학점, 공인영어 성적, 수학과 머신러닝의 현재 준비 수준.
- [ ] 7개 학교의 2027년 후기 모집요강, 연구실 선발 계획과 실제 지원 경로.
- [ ] 새 로드맵의 첫 Python 학습 단위를 수행하고 이해 여부와 막힌 부분을 기록한다.
- [ ] 입학 후 전일제 진학 또는 직장 병행 여부.

확인 전에는 하루 공부 시간, 주간 시간표와 과목별 마감일을 확정하지 않는다. [[2027-AI-Masters-Plan#상담에서 제안한 준비 일정|상담 준비안]]의 2027년 2월 핵심 자료 준비 목표도 사용자 채택 여부가 확인되지 않은 제안으로 유지한다.
