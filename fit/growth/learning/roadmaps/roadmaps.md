# 학습 로드맵

날짜보다 검토 가능한 산출물과 완료 gate를 우선하는 실행 계획 모음이다.

상위 생활, 업무와 학습 우선순위는 [[Current-Goals-and-Roadmap|현재 목표와 통합 로드맵]]에서 관리한다.

## 상시 업무 우선순위

1. 검색 — 현재 역할 기술의 1순위다. 업무 결과에 필요한 부분은 개인 학습 gate를 기다리지 않는다.
2. GraphQL, Redis와 [[git#상황별 작은 gate|Git]] — 실무에서 자주 쓰이는 공통 기반이다. 검색보다 앞선 별도 커리큘럼을 열지 않고 실제 Task에서 빈칸 하나를 닫는다.
3. 그 밖의 회사 기술 — 현재 Task나 반복 책임이 확인되면 미래 투자와 범용 학습보다 먼저 다룬다.

업무 학습은 동시에 여러 진도표를 여는 일이 아니다. 현재 문제 하나를 해결하고 결과와 공개 가능한 작은 설명을 남긴 뒤 개인 학습의 현재 위치로 돌아온다.

## 현재 개인 트랙

## 다음 정규 트랙 후보

- 회사 기술 심화
  - [[2027-Search-Recommendation-Roadmap|검색 엔진 우선, 추천 시스템 전환 로드맵]] — 현재 1순위인 검색 책임과 데이터 및 리뷰 환경이 계속 있을 때
  - GraphQL과 Redis — 검색 업무 다음으로 별도 심화가 필요한 빈칸과 검토 환경이 있을 때
  - gRPC, Kafka와 그 밖의 회사 기술 — 현재 Task나 반복 책임이 확인될 때
- 미래 역할 투자
  - [[2027-DevOps-Practical-Roadmap|DevOps 실전 로드맵]] — 긴급한 회사 기술 빈칸이 없고 가용 시간이 있을 때 Terraform부터 시작
  - Kubernetes — Terraform 성공선 뒤 통합 gate에서 다시 선택한 경우
- 범용 백엔드 대기열
  - [[Node-Core-Output-Roadmap|JS, TS와 Node.js 코어]]
  - CS/OOP/패턴/아키텍처 → 시스템 디자인 → MySQL
- 새 트랙을 열지 않음 — 가용 시간이 부족하거나 후보의 근거가 약할 때

수학 2단계 gate와 입사 첫 90일 회고 뒤 하나만 고른다. 회사 기술, 미래 DevOps 투자, 범용 백엔드 대기열 순서로 비교하며, 현재 검색 책임이 이어지면 검색이 첫 후보다. 각 성공선을 닫을 때마다 다음 모듈을 자동으로 열지 않고 다시 선택한다. [[Search-Recommendation-Discovery-Learning-Path|검색과 추천 디스커버리 학습 경로]]의 고급 단계도 실제 역할 수요가 있을 때만 고른다. 연도는 가장 이른 시작 목표이며 마감일이 아니다.
