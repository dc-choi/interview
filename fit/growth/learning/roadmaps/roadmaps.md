# 학습 로드맵

날짜보다 검토 가능한 산출물과 완료 gate를 우선하는 실행 계획 모음이다.

상위 생활, 업무와 학습 우선순위는 [[Current-Goals-and-Roadmap|현재 목표와 통합 로드맵]]에서 관리한다.

## 현재 학습 상태

2026-08-10 당시 역할 연결을 근거로 시작한 검색 학습은 2026-09-01 퇴사 결정으로 보류했다. 완료 처리하지 않고 [[OpenSearch#시작 전: 실물 익히기|현재 gate]]를 재개 지점으로 보존한다. 수학도 0단계 시작 전에서 보류 중이며 현재 활성 정규 학습 트랙은 없다.

## 퇴사 전환 중 기술 보충

1. 남은 업무와 인계에 필요한 기술만 최소 범위로 보충한다.
2. GraphQL, Redis와 [[git#상황별 작은 gate|Git]]은 공개 예제와 로컬 실습으로 필요한 빈칸 하나씩 닫는다.
3. 보충 결과는 공개 가능한 설명이나 검증으로 남기되 정규 로드맵 진도로 계산하지 않는다.

기술 보충을 이유로 새 정규 진도표를 열지 않는다.

## 보류한 개인 트랙

1. [[OpenSearch|OpenSearch 학습 지도]] — 보류, 현재 gate를 재개 지점으로 보존
2. [[2026-H2-Math-Roadmap|2026 하반기 수학 기초 로드맵]] — 정규 개인 학습의 재개 대상, 현재 0단계 시작 전 보류

## 다음 정규 트랙 후보

- 독립 검색
  - [[2027-Search-Recommendation-Roadmap|검색 엔진 우선, 추천 시스템 전환 로드맵]] — 검색을 계속할 개인 목적, 독립 fixture와 검토 조건이 있을 때
- 미래 역할 투자
  - [[2027-DevOps-Practical-Roadmap|DevOps 실전 로드맵]] — 전환 의무와 회복을 해치지 않을 가용 시간이 있을 때 Terraform부터 시작
  - Kubernetes — Terraform 성공선 뒤 통합 gate에서 다시 선택한 경우
- 수학
  - [[2026-H2-Math-Roadmap|2026 하반기 수학 기초 로드맵]] — 0단계부터 재개
- 범용 백엔드 대기열
  - [[Node-Core-Output-Roadmap|JS, TS와 Node.js 코어]]
  - CS/OOP/패턴/아키텍처 → 시스템 디자인 → MySQL
- 새 트랙을 열지 않음 — 가용 시간이 부족하거나 후보의 근거가 약할 때

남은 업무와 인계 범위, 공개 가능한 경력 증거, 회복 상태와 주간 가용 시간 및 이미 수락한 의무를 확인한 뒤 하나만 고른다. 퇴사 결정만으로 구직, 출석부 실험이나 다음 학습 트랙을 자동으로 열지 않는다. 각 성공선을 닫을 때마다 같은 통합 gate로 돌아오며 연도는 가장 이른 시작 목표이지 마감일이 아니다.
