# 학습 로드맵

날짜보다 검토 가능한 산출물과 완료 gate를 우선하는 실행 계획 모음이다.

상위 생활, 업무와 학습 우선순위는 [[Current-Goals-and-Roadmap|현재 목표와 통합 로드맵]]에서 관리한다.

## 현재 학습 상태

2026-08-10부터 현재 역할과의 연결성을 근거로 개인적으로 선택한 검색 학습이 집중 자리 하나를 점유 중이다. 이는 회사 지시나 평가 기준을 뜻하지 않는다. 수학은 0단계 시작 전에서 보류 중이다. 현재 검색 학습은 수학 2단계 gate나 입사 첫 90일 회고를 기다리지 않는다.

## 응용 학습 우선순위

1. 검색 — 현재 집중 학습에 필요한 부분은 [[OpenSearch|OpenSearch 학습 지도]]를 통해 바로 진행한다.
2. GraphQL, Redis와 [[git#상황별 작은 gate|Git]] — 공개 예제와 로컬 실습으로 빈칸 하나씩 닫는 공통 기반이다.
3. 그 밖의 기술 — 실제 역할 수요가 확인되면 미래 투자와 범용 학습보다 먼저 다룬다.

응용 학습은 동시에 여러 진도표를 여는 일이 아니다. 현재 검색 수요의 문제 하나를 해결하고 검증 결과와 작은 설명을 남긴 뒤 집중 자리의 다음 gate로 돌아온다.

## 현재 집중 학습과 개인 트랙

1. [[OpenSearch|OpenSearch 학습 지도]] — 현재 검색 학습의 즉시 실행 지도. 현재 gate를 하나씩 확인하며, 실행 여부는 요청 재현과 설명으로만 갱신한다.
2. [[2026-H2-Math-Roadmap|2026 하반기 수학 기초 로드맵]] — 정규 개인 학습의 재개 대상, 현재 0단계 시작 전 보류

## 다음 정규 트랙 후보

- 응용 기술 심화
  - [[2027-Search-Recommendation-Roadmap|검색 엔진 우선, 추천 시스템 전환 로드맵]] — 현재 검색의 작은 gate를 넘은 뒤, 수학 2단계 gate와 입사 첫 90일 회고 뒤에도 실제 검색 역할 수요, 독립 fixture와 검토 조건이 이어질 때
  - GraphQL과 Redis — 검색 다음으로 실제 역할에서 별도 심화가 필요한 빈칸이 있을 때
  - gRPC, Kafka와 그 밖의 기술 — 실제 역할 수요가 확인될 때
- 미래 역할 투자
  - [[2027-DevOps-Practical-Roadmap|DevOps 실전 로드맵]] — 더 급한 실제 역할 기술 빈칸이 없고 가용 시간이 있을 때 Terraform부터 시작
  - Kubernetes — Terraform 성공선 뒤 통합 gate에서 다시 선택한 경우
- 범용 백엔드 대기열
  - [[Node-Core-Output-Roadmap|JS, TS와 Node.js 코어]]
  - CS/OOP/패턴/아키텍처 → 시스템 디자인 → MySQL
- 새 트랙을 열지 않음 — 가용 시간이 부족하거나 후보의 근거가 약할 때

수학 2단계 gate와 입사 첫 90일 회고 뒤 하나만 고른다. 응용 기술, 미래 DevOps 투자, 범용 백엔드 대기열 순서로 비교한다. 현재 검색 학습은 이 전환 gate를 기다리지 않는다. 각 성공선을 닫을 때마다 다음 모듈을 자동으로 열지 않고 실제 역할 수요, 해당 gate와 가용 시간을 다시 확인한다. [[Search-Recommendation-Discovery-Learning-Path|검색과 추천 디스커버리 학습 경로]]의 고급 단계도 실제 역할 수요가 있을 때만 고른다. 연도는 가장 이른 시작 목표이며 마감일이 아니다.
