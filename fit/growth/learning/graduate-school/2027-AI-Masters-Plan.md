# 2027년 후기 추천시스템 석사 진학 검토

최신 갱신일: 2026-11-13. 2026-11-13 사용자가 서울대와 연세대를 지원 대상에서 제외했다. 그 밖의 내용은 2026-11-02 기준이다. 사용자가 제공한 ChatGPT 상담 요약과 이후 직접 밝힌 진학 집중 결정을 반영했다. 상담 원본의 대화일은 제공되지 않았다. `status: active`는 대학원 준비를 현재 주축으로 채택했다는 뜻이며, 학습 진도와 실제 지원, 합격 및 진학은 별도로 확인한다.

## 현재 실행 방향

- **최우선 목표:** 앞으로의 계획과 공부를 대학원 진학 준비에 집중한다.
- **구직:** 중단한다. 기존 지원과 전형 이력은 [[Job-Search-Tracker]]에 보존하며, 외부 지원 철회 통보가 완료됐다고 기록하지 않는다.
- **자금 마련:** 아르바이트로 필요한 자금을 마련할 계획이다. 근무처, 시작일, 시간과 실제 수입 확보는 미확인이다.
- **공부:** [[Recommender-System-Foundations-Roadmap|추천시스템 구현 기반]]에 집중하며 Python 기초부터 시작한다. 높은 강도로 공부하겠다는 의사는 확정했지만 주간 학습 시간과 실제 진도는 별도로 확인한다.
- **기존 로드맵:** [[Archived-Learning-Roadmaps|아카이브]]에 보존하고 현재 실행 목록에서 제외한다. 이 문서는 대학원 지원 요건과 연구실 검토를 관리하며 추천시스템 구현의 세부 학습은 새 로드맵에서 관리한다.

운영 기준은 [[Current-Goals-and-Roadmap|현재 목표와 통합 로드맵]]을 따른다. 진학 준비에 집중한다는 결정은 아래의 상담 준비안을 날짜별로 모두 채택했거나 실제 학습을 시작했다는 뜻은 아니다. 입학 전 자금 마련 방식과 입학 후 전일제 또는 직장 병행 여부도 구분한다.

## 사용자가 확정한 목표와 조건

- **입학 목표:** 2027학년도 후기, 2027년 9월 입학.
- **관심 연구 분야:** 추천시스템. 세부 연구 주제는 미정이다.
- **학교 선택 기준:** 학교 간판을 중요하게 고려한다.
- **학위 선호:** 공학석사면 좋겠다는 입장이다. 공학석사만 가능한 것으로 제한하지 않는다.
- **검토 대상:** 고려대, 한양대, 중앙대, 서울시립대, 경희대의 5개 학교다. 2026-11-13 사용자가 서울대와 연세대를 제외했다. 서울대는 지원 요건이 까다롭고 연세대는 거리가 멀다는 이유다. 2026-11-02에는 7개 학교를 모두 유지하기로 했었다.
- **후보 제외 금지:** 간판에 따라 검토 순서를 정하더라도 중앙대, 서울시립대와 경희대를 제외하지 않는다. 간판과 공학석사 선호는 비교 기준이지 이 세 학교를 제외하는 조건이 아니다.

상담에서는 서울대, 고려대와 연세대, 한양대 서울캠퍼스에 준비 비중을 높이는 전략을 제안했다. 이는 AI의 제안이며 사용자가 확정한 학교별 우선순위가 아니다. 이 제안 가운데 서울대와 연세대는 2026-11-13 제외로 더는 해당하지 않는다. 남은 5개 학교를 비교하면서 각 학교 안에서 추천 연구와 공학석사 취득 경로를 함께 검토한다.

## 이전 기록과의 관계

[[2027-AI-Masters-Plan-2026-10-08|2026-10-08 검토 기록]]은 당시 공식 자료, 등록금과 학자금대출 조사까지 보존했다. 당시 고려대와 연세대만 검토한다는 제한과 입학 학기 미정 상태는 위의 최신 조건으로 대체한다.

이전에는 수도권 야간 또는 주말 과정과 직장 및 사업 병행을 검토했다. 최신 상담에서는 전일제 진학 또는 직장 병행 여부를 미확인으로 남겼으므로, 과거 병행 조건을 이번 연구실 후보의 필수 조건으로 적용하지 않는다. 과거의 진학 목적과 비용 기준은 당시 기록으로 보존하며, 이번 상담에서 변경 여부가 명시되지 않은 항목을 새로 확정하지 않는다.

## 기록의 확인 수준

아래 연구실, 학위, 모집 안내와 연구 적합성은 **사용자가 전달한 상담 내용**이다. 이번 등록에서 공식 원문을 다시 조회하지 않았으므로 현재 확인된 사실이나 2027년 적용 규정으로 단정하지 않는다. 요약에 일부 도메인만 있고 개별 문서 URL과 확인일이 없어 정확한 원문 대조가 남아 있다.

교수명은 공개 연구 활동과 연구실 후보를 식별하는 표기로 보존한다. 개인 연락처나 비공개 교류 정보는 기록하지 않는다. 교수 소속, 실제 지원 학과와 졸업 시 수여 학위명은 각각 확인한다.

## 학교별 연구실 후보

우선 검토와 함께 검토 구분은 상담의 제안이며 최종 지원 결정이 아니다. 서울대와 연세대는 2026-11-13 제외했으며, 이 절과 아래 절의 두 학교 내용은 당시 검토 기록으로 보존한다. 컨택 대상은 [[2027-Graduate-Contact-Email-Drafts|컨택 메일 초안]]에서 관리한다.

| 학교 | 우선 검토 후보 | 함께 검토할 후보 |
|---|---|---|
| 서울대 | 강유 — Data Mining Lab, 유재민 — Data AI Lab | 이준석 — VIP Lab |
| 고려대 | 강성구 — IDEA Lab, 윤수식 — DAIS Lab | 장부루 — Language & Intelligence Lab |
| 연세대 | 이경호 — Internet Computing Lab | 신원용 — MIDaS, 이동하 — DLI, 여진영 — LangAGI |
| 한양대 서울 | 김상욱 — BigDAS, 김현준 — Data Mining & Algorithm Lab | 채동규 — DILab |

| 서울시립대 | 황혜수 — 지능정보시스템 연구실 | 전종준 — Optim. Lab., 박재휘 — DILAB |

## 연구 관심에 따른 비교 방향

공개 연구 내용을 바탕으로 상담에서 제안한 적합성 분류다. 연구실의 현재 연구와 모집 주제를 이번 등록에서 검증한 결과는 아니다.

| 관심 방향 | 주로 비교한 후보 |
|---|---|
| 대규모 데이터, 추천 시스템과 처리 효율 | 서울대 강유, 한양대 김상욱과 김현준, 중앙대 고윤용 |
| 추천 모델, 순차 추천과 LLM 추천 | 서울대 유재민과 이준석, 고려대 강성구와 윤수식, 중앙대 조윤식 |
| 대화형 추천, 지식그래프와 언어모델 | 고려대 장부루, 연세대 이경호와 이동하, 신원용 |
| 그래프 기반 추천과 새로운 데이터에 대한 대응 | 서울시립대 황혜수 |
| 추천 편향, 통계와 인과추론 | 서울시립대 전종준 |
| 아이템 표현, 희소 데이터와 모델 효율 | 서울시립대 박재휘 |
| 리뷰, 멀티모달과 전자상거래 추천 | 경희대 김재경 |
| 생성형 추천의 실제 서비스 적용 | 경희대 박재홍 |

백엔드 경험을 활용할 수 있는 관심 주제의 예시로 사용자 로그 처리, 추천 모델 갱신, 추론 지연, 메모리와 비용 효율, 온라인 평가를 검토했다. 어느 하나도 확정한 세부 연구 주제는 아니다.

## 2027년 후기 지원의 확인 사항

### 전기 모집 마감과 후기 선발을 구분한다

- 고려대 강성구 IDEA의 마감 공지는 상담에서 2027학년도 전기 대상으로 정리했다.
- 중앙대 고윤용 MINDS의 자리 없음 공지는 상담에서 2027년 봄학기 대상으로 정리했다.
- 두 연구실 모두 2027년 후기 후보로 유지한다. 가을 선발 계획과 정원은 별도로 문의해야 한다.

### 서울대 모집단위 변경을 확인한다

상담에는 서울대가 2027학년도 전기부터 기존 데이터사이언스학과 등을 AI대학원 AI학과로 통합 모집한다고 공지했다는 내용이 있다. 이준석 연구실은 기존 데이터사이언스대학원 안내에만 의존하지 않고 새 AI대학원의 후기 모집요강, 실제 지원 경로와 학위명을 확인한다.

### 공개 모집 안내와 특정 학기 정원을 구분한다

상담에는 한양대 김현준 연구실이 상시 모집, CV와 성적표 및 공인영어 성적 제출, 원서접수 전 조기 연락을 안내한다는 내용이 있다. 이를 2027년 후기 정원 확정으로 해석하지 않는다.

## 상담에서 제안한 준비 일정

아래는 상담의 준비안이며 사용자가 확정한 실행 일정이나 학교별 공식 일정이 아니다. 이번 등록은 개인 캘린더 확인이나 일정 예약을 포함하지 않는다.

| 시기 | 제안한 준비 내용 |
|---|---|
| 2026년 11~12월 | 7개 학교 연구실 비교, 관심 논문 읽기, CV와 성적표 정리, 영어 상태 점검 |
| 2027년 1~2월 | 후기 선발 계획과 학위 경로 문의, 추천 실험과 연구 관심 설명 정리 |
| 2027년 3월 | 학교별 후기 모집요강 확인, 지원 학과와 학위과정 및 제출서류 확정 |
| 2027년 3~5월 | 학교별 일정에 맞춰 원서접수와 면접 준비 |
| 2027년 5~7월 | 면접과 합격 결과 확인, 연구실과 졸업 요건 및 비용 등을 비교해 결정 |
| 2027년 8~9월 | 입학 준비 |

상담에서는 **2027년 2월까지 핵심 지원 자료를 갖추는 것**을 준비 목표로 제안했다. 사용자 채택 여부는 확인되지 않았다.

연세대 공식 페이지에 2027년 4월 6~13일 원서접수, 2027년 3월 모집요강 공개 예정이 안내됐다는 상담 내용도 보존한다. 개별 페이지와 해당 모집과정은 이번 등록에서 확인하지 않았으며 확정 마감일로 사용하기 전에 원문을 대조한다.

## 아직 확인되지 않은 사항

- [ ] 학점, 공인영어 성적, 수학과 머신러닝 준비 수준.
- [ ] 전일제 진학 또는 직장 병행 여부와 연구실 활동 가능 조건.
- [ ] 각 연구실의 2027년 후기 석사 선발 계획과 정원.
- [ ] 복수 학위종이 있는 학과에서 본인에게 적용되는 공학석사 취득 경로.
- [ ] 각 후보의 실제 지원 학과, 2027년 모집요강과 제출서류 및 일정.
- [ ] 최종 지원할 연구실과 추천시스템의 세부 연구 주제.

2026-11-13 이후 검토 대상은 5개 학교다. 기록 완료를 모집 정보 검증, 준비 일정 채택이나 지원 완료로 처리하지 않는다.

## 출처

- 사용자 직접 발언, 2026-11-13: 서울대와 연세대를 포기한다는 결정. 서울대는 요건이 까다롭고 연세대는 거리가 멀다는 이유를 밝혔다.
- 사용자 직접 발언, 2026-11-02: 앞으로 대학원 진학에 집중하며 구직은 중단하고, 자금은 아르바이트로 마련하면서 공부에 집중한다는 결정. 후속으로 기존 로드맵 아카이브, 추천시스템 구현 기반에 집중, Python 기초부터 시작할 필요를 밝혔다.
- 추천시스템 대학원 진학 상담 요약 — 사용자가 2026-11-02 제공한 ChatGPT 상담 정리. 원본 대화 URL과 상담일은 미제공. 목표와 조건, 연구실 후보, 학위 정보, 연구 적합성 제안, 모집 확인 사항, 준비안과 미확인 항목을 기록했다.
- 상담 요약에 남아 있는 출처 식별자: `s-space.snu.ac.kr`, `idea.korea.ac.kr`, `gsds.snu.ac.kr`, `sites.google.com`, `graduate.yonsei.ac.kr`. 개별 문서 URL이 아니므로 검증된 직접 인용으로 취급하지 않는다.
