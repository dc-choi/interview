# 2027년 후기 연구실 컨택 메일 초안

최신 갱신일: 2026-11-13. 사용자 요청으로 대화에서 만든 컨택 메일 초안을 보존한다. 초안이며 발송하지 않았다. 발송은 수신자, 제목, 본문과 첨부의 최종본을 사용자가 확인하고 명시적으로 승인한 뒤에만 한다.

진학 결정과 학교 후보의 정본은 [[2027-AI-Masters-Plan]]이고, 메일의 정보 구조는 [[Graduate-Admission-Preparation#컨택 메일의 정보 구조|컨택 메일의 정보 구조]]를 따른다.

## 사용자 결정

- 2026-11-13: 컨택 대상을 8곳으로 정했다. AI가 제안한 7곳에 사용자가 서울시립대 황혜수 교수를 추가했다.
- 2026-11-13 후속: 서울대와 연세대를 포기했다. 서울대는 요건이 까다롭고 연세대는 거리가 멀다는 이유다. 컨택 대상은 아래 5곳이다.
- 2026-11-13: 대상 모두 석사 신입생 선발 문의로 통일한다. 연구 인턴 문의는 메일에 넣지 않는다.
- 자기소개는 학부 이력보다 약 4년의 백엔드 커리어를 중심으로 쓴다.
- 전일제 진학은 당연한 전제이므로 메일에서 따로 설명하지 않는다.

| 학교 | 교수 | 조사에서 확인한 소속 |
|---|---|---|
| 고려대 | 강성구 | 컴퓨터학과 |
| 한양대 | 김상욱 | 연구실 석사생이 인공지능학과와 컴퓨터소프트웨어학과에 걸쳐 있음 |
| 중앙대 | 조윤식 | AI학과, 컴퓨터공학과 겸임 |
| 경희대 | 김재경 | 미확인 |
| 서울시립대 | 황혜수 | 일반대학원 컴퓨터과학과 주임교수. 인공지능학과 교수 목록에도 있으나 그 학과에서 지도한 학위논문은 찾지 못함 |

## 교수별 연구 연결 문단

AI가 논문 본문을 대조해 쓴 문장이다. 사용자가 논문을 직접 읽은 상태가 아니므로, 읽고 자신의 말로 고치기 전에는 발송본으로 쓰지 않는다.

### 강성구 교수 (고려대)

교수님께서 교신저자로 참여하신 Capturing User Interests from Data Streams for Continual Sequential Recommendation(WSDM 2026)을 읽었습니다. 과거 블록에 다시 접근하지 않고 새로 들어온 행동 시퀀스만으로 모델을 갱신하면서, 선형 어텐션의 누적 메모리를 사용자별로 이어 가 장기 관심을 보존한다는 설계가 인상 깊었습니다. 저는 이벤트가 늦게 도착하거나 중복되는 상황을 서비스 쪽에서 다뤄 왔는데, 블록 경계를 넘어 늦게 온 이벤트와 중복 이벤트가 누적 메모리에 어떤 영향을 주는지 연구해 보고 싶습니다.

- 주의: 교수는 교신저자다. 연구실 단독 논문으로 쓰지 않는다.

### 김상욱 교수 (한양대)

교수님 연구실의 Ranking Items by the Current-Preferences and Profits(WWW 2025)를 읽었습니다. 사용자의 현재 선호와 수익을 함께 놓고 목록 전체의 순위를 학습한다는 접근이 실제 커머스의 문제와 가깝다고 느꼈습니다. 저는 재고와 발주 데이터를 다루면서 품절이나 입고 지연이 판매에 미치는 영향을 가까이서 봤고, 이런 재고 제약을 순위 학습에 반영하는 문제에 관심이 있습니다.

- 주의: 초록의 성능 향상 수치는 인용하지 않는다.

### 조윤식 교수 (중앙대)

교수님 연구실의 Norm Removed, Bias Remains(CIKM 2026)를 읽었습니다. 코사인 점수로 임베딩 노름을 점수에서 빼더라도 학습 중에 노름이 다시 커지고 상호작용 수만큼 기울기가 누적되면서 인기 편향이 되살아나며, 상호작용 수에는 선호와 노출 기회가 섞여 있다는 분석이 흥미로웠습니다. 저는 노출, 클릭, 주문 이벤트를 수집하는 쪽에서 일했고, 실제 노출 로그가 있을 때 이 가정을 어떻게 검증하고 편향을 분리할 수 있는지 알고 싶습니다.

- 참고: CIKM 2026 단편 논문이며 왓챠와 협업했다.

### 김재경 교수 (경희대)

교수님 연구실의 Balancing Long-Short-Term User Preferences via Multilevel Sequential Patterns for Review-Aware Recommendation(Electronics 2026)을 읽었습니다. 사용자가 쓴 리뷰 전체로 장기 선호를, 최근 리뷰와 카테고리 순서로 단기 선호를 따로 학습한 뒤 게이트로 섞는 설계가 인상 깊었습니다. 저는 외부 데이터 수집 파이프라인을 운영해 왔고, 논문이 향후 과제로 제시한 온라인 지속 학습, 즉 리뷰가 계속 쌓이는 환경에서 장단기 선호의 비중을 다시 맞추는 문제에 관심이 있습니다.

- 주의: 표 1의 수치는 인용하지 않는다.

### 황혜수 교수 (서울시립대)

교수님께서 교신저자로 참여하신 이질 간선과 신규 간선을 고려한 그래프 신경망 기반 추천(정보과학회 컴퓨팅의 실제 논문지, 2024)을 읽었습니다. 평소 선호와 무관한 이질 간선으로 생기는 과평탄화와, 새 상호작용을 반영하려면 모델을 다시 학습해야 하는 문제를 템플릿 정점과 그래프 트렌드 필터링으로 함께 다룬 점이 인상 깊었습니다. 저는 메시지 큐로 들어오는 이벤트와 데이터 정합성을 다뤄 왔기에, 논문이 한계로 밝힌 신규 정점 추가 상황과 상호작용이 시간 순서대로 쌓일 때 재학습 없이 성능이 어디까지 유지되는지에 관심이 있습니다.

- 주의: 2024~2026년에 출판된 추천시스템 논문은 이 1편뿐이다. 2025~2026년 국제 발표 4편은 그래프 학습 분야다. 추천시스템 전공 연구실이라고 단정하지 않는다.
- 주의: 초록은 신규 정점에도 효과적이라고 쓰지만 실험은 기존 정점 사이의 신규 간선만 다룬다. 논문 5절이 이를 한계로 인정한다. 표의 개선율 수치는 인용하지 않는다.
- 주의: 투고 중인 교차 도메인 추천 원고는 제목만 공개돼 있으므로 메일에서 언급하지 않는다.
- 참고: 2027 전기1차 모집요강은 컴퓨터과학과 지원자에게 지도예정교수와의 사전 연락을 요구한다. 2026 후기 안내는 후기 입시가 전기 잔여 인원으로 진행돼 모집 학과와 인원이 적다고 적었다.

## 제외한 후보의 문단

2026-11-13 사용자가 서울대와 연세대를 제외했다. 아래 문단은 발송 대상이 아니며 기록으로 보존한다.

### 강유 교수 (서울대)

교수님 연구실의 SpikeRec(CIKM 2026)을 읽었습니다. 학습 로그를 사용자 단위로 샘플링하면 각 사용자의 시청 이력은 보존되지만 채널별 시청자 수 시계열이 왜곡되어, 시청자 급증이 실제와 다른 시점에 나타나거나 작은 채널에서는 거의 사라진다는 관찰이 기억에 남았습니다. 저는 수집 파이프라인을 운영해 왔기에, 논문이 정확하다고 가정하는 전체 시청자 수 신호가 늦게 들어오거나 일부 빠질 때 추천 성능이 어떻게 달라지는지 연구해 보고 싶습니다.

- 주의: 연구실 안내는 입학 전 인턴 6개월 이상을 적고 있다. 기간의 기준 시점은 확인하지 못했다.

### 신원용 교수 (연세대)

교수님 연구실의 Memory Is No Longer a Bottleneck(TKDE 2026)을 읽었습니다. 아이템 유사도 행렬을 아예 만들지 않고 사용자별 Krylov 부분공간 안에서 다항 그래프 필터를 계산해 메모리 병목을 없애면서도 이론상 오차가 없다는 점이 서비스 운영에서 겪는 제약과 맞닿아 있다고 느꼈습니다. 논문이 향후 과제로 남긴 캐시 갱신 전략, 즉 새 상호작용이 들어올 때 사용자별 기저를 어디까지 다시 계산해야 하는지에 관심이 있습니다.

- 주의: 선행연구 FIRE(WWW 2022)와의 차이를 설명할 수 있어야 한다. 연구실 안내는 일괄 메일에 응답하지 않는다고 적고 있다.

### 이동하 교수 (연세대)

교수님 연구실의 WatchLens(RecSys 2026)를 읽었습니다. 피드와 시청 페이지에 추천 정책을 따로 배정하고, 추천 정책과 순위 위치 같은 노출 맥락을 이벤트 기록 시점에 함께 남겨 재생 행동과 추천 조건을 사후 조인 없이 연결한 설계가 인상 깊었습니다. 저는 이벤트 기반 비동기 처리와 모니터링을 맡아 왔기에 논문이 한계로 밝힌 단일 서버 배포의 고동시성 부하와 분산 배포 과제에 관심이 있습니다.

- 참고: RecSys 2026 Resource 논문이다. 코드는 MIT 라이선스로 공개돼 있다.

## 발송 전에 채워야 하는 것

- [ ] 준비 근거 문단. 직접 구현한 모델, 데이터와 결과가 있어야 쓸 수 있다. 코드와 데이터가 공개된 SpikeRec과 WatchLens는 제외한 학교의 논문이지만 재현 연습 대상으로는 쓸 수 있다.
- [ ] 인용한 논문을 직접 읽고 문단을 자신의 말로 고치기.
- [ ] 추천시스템에 관심을 갖게 된 실제 계기 1~2문장.
- [ ] CV와 성적증명서.
- [ ] 공인영어 성적. 2026 후기와 2027 전기 요강 기준으로 5개 학교 모두 입학 지원의 필수 요건이 아니다. 고려대 컴퓨터학과는 제출하면 평가에 반영한다. 2027 후기 요강이 게시되면 다시 확인한다.
- [ ] 교수별 수신 주소와 연구실이 요구하는 제목 형식, 첨부 서류 재확인.

AI가 권한 발송 시기는 2026년 12월 중순부터 2027년 1월 초다. 사용자가 채택한 일정은 아니다.
