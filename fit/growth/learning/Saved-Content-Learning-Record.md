# 저장 콘텐츠 학습 기록

2026-10-10 사용자 요청으로 저장된 학습 자료를 빠짐없이 기록한다. 기존 관측 247건에서 중복 텍스트를 정리한 145개 중 일상 대화 6개와 연예/행사 소식 2개를 제외한 **137개 항목**이다. 번호는 서로 다른 관측 텍스트의 식별자이며 게시물 수나 전체 대화 수가 아니다.

본문 부족과 미검증은 삭제 사유가 아니다. 계정명만 있는 항목도 식별자와 원문 확인 과제로 보존한다. 확보한 캡션 전체와 관측된 출처 경로는 보호된 별도 원본 기록에 유지한다. 아래는 공개 가능한 주제, 확인 수준과 문서 연결이다. 사적 계정 관계, 대화 상대, 사용자 계정과 로컬 원본 경로는 싣지 않는다.

- **개념 반영:** 확인한 개념을 지식 문서에 반영했다. 캡션의 모든 주장이나 빠진 이미지를 검증했다는 뜻은 아니다.
- **기존 개념 연결:** 중복되는 지식 문서에 연결했다. 개별 일화와 수치는 별도 검증 대상이다.
- **기록, 확인 대기:** 확보한 제목, 주장이나 목록을 보존했다. 원문 확인 또는 사실 대조가 남았다.
- **식별자 보존:** 계정명/클립 표시 외 내용이 없거나 콘텐츠에 접근할 수 없었다. 공개 프로필을 개별 게시물 원문으로 대체하지 않는다.
