# 교육 수료증과 실무 증거

교육 과정을 고를 때는 발급 기관의 이름보다 무엇을 수행하고 무엇을 검증받는지 확인한다. 수료 사실, 시험 통과와 실제 업무 경험은 서로 다른 증거다. 같은 certificate라는 이름을 쓰더라도 평가 방식과 활용 범위를 과정별로 읽어야 한다.

## 증거를 나누는 기준

| 구분 | 확인할 내용 | 설명할 때의 경계 |
| --- | --- | --- |
| 교육 과정 수료 | 필수 강의, 과제와 완료 조건 | 수료 사실을 특정 직무의 숙련이나 채용 확정으로 바꾸지 않는다 |
| 직무 시뮬레이션 | 예제 업무, 제공된 자료, 모범 답안과의 비교 | 실제 고용이나 고객 업무 경력과 구분한다 |
| 시험형 자격 | 발급 기관, 시험 범위와 합격 조건 | 과정 수료증과 같은 평가를 거쳤다고 가정하지 않는다 |
| 직접 만든 작업물 | 해결한 문제, 본인의 판단, 재현 방법과 한계 | 제공된 답안과 직접 결정한 부분을 구분한다 |

위 표는 학습 자료를 비교하기 위한 점검 틀이다. 자격 명칭의 법적 분류나 모든 채용 조직에 통하는 평가 순위가 아니다.

## 공식 안내에서 확인할 차이

2026-10-07 확인 기준이다. 금액과 기간은 아래에 표시한 프로그램과 지역의 안내이며, 한국의 결제 조건으로 옮겨 쓰지 않는다.

- **Forage 직무 시뮬레이션:** 플랫폼은 무료로 자기 속도에 맞춰 예제 업무를 수행하고 모범 답안과 비교한 뒤 수료증을 받는 과정을 안내한다. Deloitte Australia Data Analytics는 예상 소요 시간을 1~2시간으로 표시하며, 수료증을 이력서와 LinkedIn의 비교과 활동으로 기재하도록 안내한다. 따라서 해당 회사에서 일한 인턴 경력으로 적지 않는다.
- **Google Career Certificates:** 공식 FAQ는 미국과 캐나다에서 7일 무료 체험 뒤 월 US$49를 안내한다. 많은 학습자의 완료 기간은 3~6개월이며, 다른 국가의 비용은 Coursera 등록 옵션에서 확인하도록 한다. 무료 체험과 전체 과정 무료 수료는 다르다.

여러 프로그램을 묶어 모두 무료이거나 하루에 하나씩 끝낼 수 있다고 판단하지 않는다. 수강, 평가, 수료증 발급과 구독 갱신의 조건을 각각 확인한다. 과정이 제공하는 취업 지원도 개인의 채용 결과를 보장하는 증거는 아니다.

## 공개 강좌의 열람과 이수 조건

공개 학습 플랫폼에 강좌가 있다는 사실과 지금 수강 신청, 평가 참여, 이수증 발급이 가능하다는 사실은 구분한다. 비용뿐 아니라 신청 기간, 접근 가능한 자료와 완료 조건을 확인한다.

- **K-MOOC 청강:** 2026-10-07 확인한 공식 안내에서는 청강을 허용한 강좌에 한해 종강일 이후 청강 신청이 가능하다. 영상과 학습자료 등을 확인할 수 있지만 이수증은 발급하지 않는다. 재개강 여부와 일정도 강좌별로 다르다.
- **목적에 따른 선택:** 필요한 개념을 다시 보는 목적이면 청강 가능 범위를 먼저 확인한다. 수료 증빙이 필요하면 정규 수강 신청과 평가 조건을 확인한다. 이는 선택 절차 제안이며 특정 강좌의 효과나 수료를 보장하는 기준은 아니다.

공공 플랫폼 목록은 [[Self-Development-While-Working#8. 저비용 자원 활용|저비용 학습 자원]]에서 찾는다. 사이트 수를 늘리기보다 현재 질문에 맞는 강좌 하나를 골라 설명이나 적용 결과로 이해를 확인한다.

## 학습 목적에 맞게 선택하기

다음은 위 차이를 활용한 학습 절차 제안이다. 특정 수료증의 채용 효과를 입증한 연구 결과는 아니다.

1. 현재 설명하거나 수행하기 어려운 업무 하나를 적는다. 예를 들어 데이터 분석이라면 데이터를 읽고 오류를 찾은 뒤 결과를 설명하는 작업으로 좁힌다.
2. 후보 과정의 실제 과제가 그 빈칸을 다루는지 확인한다. 기업 로고와 짧은 소요 시간만으로 선택하지 않는다.
3. 비용과 전체 소요 시간, 완료 조건을 읽고 현재 학습 범위 안에서 선택한다. 수료증 목록이 늘었다는 이유로 여러 트랙을 동시에 시작하지 않는다.
4. 허용된 자료로 과제를 수행한 뒤 답안을 보지 않고 판단 이유와 한계를 설명한다. 공개할 수 없는 과제나 데이터를 포트폴리오에 복제하지 않는다.
5. 다른 입력으로 같은 작업을 다시 수행해 본다. 막힌 부분만 보완하고, 수료 사실과 독립 수행 여부를 별도로 기록한다.

## 이해 확인

- 무료 체험이 있는 유료 과정과 무료 직무 시뮬레이션의 비용 조건은 어떻게 다른가?
- 기업이 만든 시뮬레이션을 마쳤다는 사실과 그 기업에서 근무했다는 사실을 어떻게 구분해 설명할 것인가?
- 모범 답안을 닫은 뒤에도 결과가 나온 이유와 입력이 달라질 때의 한계를 설명할 수 있는가?
