# 교육 수료증과 실무 증거

교육 과정을 고를 때는 발급 기관의 이름보다 무엇을 수행하고 무엇을 검증받는지 확인한다. 수료 사실, 시험 통과와 실제 업무 경험은 서로 다른 증거다. 같은 certificate라는 이름을 쓰더라도 평가 방식과 활용 범위를 과정별로 읽어야 한다.

## 증거를 나누는 기준

| 구분 | 확인할 내용 | 설명할 때의 경계 |
| --- | --- | --- |
| 교육 과정 수료 | 필수 강의, 과제와 완료 조건 | 수료 사실을 특정 직무의 숙련이나 채용 확정으로 바꾸지 않는다 |
| 직무 시뮬레이션 | 예제 업무, 제공된 자료, 모범 답안과의 비교 | 실제 고용이나 고객 업무 경력과 구분한다 |
| 시험형 자격 | 발급 기관, 시험 범위와 합격 조건 | 과정 수료증과 같은 평가를 거쳤다고 가정하지 않는다 |
| 직접 만든 작업물 | 해결한 문제, 본인의 판단, 재현 방법과 한계 | 제공된 답안과 직접 결정한 부분을 구분한다 |

위 표는 학습 자료를 비교하기 위한 점검 틀이다. 자격 명칭의 법적 분류나 모든 채용 조직에 통하는 평가 순위가 아니다.

## 공식 안내에서 확인할 차이

2026-10-07 확인 기준이다. 금액과 기간은 아래에 표시한 프로그램과 지역의 안내이며, 한국의 결제 조건으로 옮겨 쓰지 않는다.

- **Forage 직무 시뮬레이션:** 플랫폼은 무료로 자기 속도에 맞춰 예제 업무를 수행하고 모범 답안과 비교한 뒤 수료증을 받는 과정을 안내한다. Deloitte Australia Data Analytics는 예상 소요 시간을 1~2시간으로 표시하며, 수료증을 이력서와 LinkedIn의 비교과 활동으로 기재하도록 안내한다. 따라서 해당 회사에서 일한 인턴 경력으로 적지 않는다.
- **Google Career Certificates:** 공식 FAQ는 미국과 캐나다에서 7일 무료 체험 뒤 월 US$49를 안내한다. 많은 학습자의 완료 기간은 3~6개월이며, 다른 국가의 비용은 Coursera 등록 옵션에서 확인하도록 한다. 무료 체험과 전체 과정 무료 수료는 다르다.

여러 프로그램을 묶어 모두 무료이거나 하루에 하나씩 끝낼 수 있다고 판단하지 않는다. 수강, 평가, 수료증 발급과 구독 갱신의 조건을 각각 확인한다. 과정이 제공하는 취업 지원도 개인의 채용 결과를 보장하는 증거는 아니다.

## 공개 강좌의 열람과 이수 조건

공개 학습 플랫폼에 강좌가 있다는 사실과 지금 수강 신청, 평가 참여, 이수증 발급이 가능하다는 사실은 구분한다. 비용뿐 아니라 신청 기간, 접근 가능한 자료와 완료 조건을 확인한다.

- **K-MOOC 청강:** 2026-10-07 확인한 공식 안내에서는 청강을 허용한 강좌에 한해 종강일 이후 청강 신청이 가능하다. 영상과 학습자료 등을 확인할 수 있지만 이수증은 발급하지 않는다. 재개강 여부와 일정도 강좌별로 다르다.
- **목적에 따른 선택:** 필요한 개념을 다시 보는 목적이면 청강 가능 범위를 먼저 확인한다. 수료 증빙이 필요하면 정규 수강 신청과 평가 조건을 확인한다. 이는 선택 절차 제안이며 특정 강좌의 효과나 수료를 보장하는 기준은 아니다.

공공 플랫폼 목록과 비용 구분은 아래 저비용 학습 플랫폼 절에서 확인한다. 사이트 수를 늘리기보다 현재 질문에 맞는 강좌 하나를 골라 설명이나 적용 결과로 이해를 확인한다.

## 자격 유지와 재취득을 구분하기

시험형 자격은 학습 이력뿐 아니라 유효기간과 유지 조건도 확인한다. 2026-10-07 확인한 AWS 정책은 3년 갱신(renewal)과 1년 유지(maintenance)를 구분한다. 경로는 자격별로 다르며 모든 자격에 같은 방법이 적용되지는 않는다.

- **Skill Builder 유지 경로:** 지원 대상인 활성 자격이 만료까지 90일 이내이고, 유효한 AWS Skill Builder 구독이 있어야 한다. 지정된 교육과 실습을 만료 전에 완료해야 한다.
- **기간 계산:** 1년 유지의 새 만료일은 활동 완료일부터 계산한다. 기존 만료일에 1년을 더하는 방식이 아니다. 시험 재응시를 통한 갱신도 시험 완료일부터 3년을 계산한다.
- **교육과 실습 요건:** 2026-06-23 공개 베타 안내는 Associate에 500점과 실습 활동 최소 1개, Professional에 700점과 최소 2개를 제시했다. 다른 등급으로 일반화하지 않고 신청할 때 해당 프로그램의 현재 요건을 확인한다.
- **서로 다른 무시험 경로:** Cloud Practitioner의 Cloud Quest 재인증은 만료 6개월 이내에 참여해 3년을 연장하는 별도 경로다. Skill Builder의 1년 유지 조건과 섞지 않는다.

기존 자격의 유지와 새 자격 취득은 목적이 다르다. 먼저 필요한 증빙과 만료일, 지원 경로를 확인한 뒤 비용과 학습 범위를 정한다. 유지 활동을 마쳤다는 사실만으로 실제 업무에서의 독립 수행 능력을 확인했다고 기록하지 않는다.

## 학습 목적에 맞게 선택하기

### 실습 평가형 자격의 범위

AWS Microcredentials는 제공된 AWS 환경에서 구성, 문제 해결과 최적화 작업을 수행하는 평가다. 객관식 문항으로 지식을 확인하는 방식과 구분하며, AWS Certifications를 보완하는 특정 주제의 실습 증거로 설명한다. 2026-04-23 공식 안내는 Skill Builder 구독 없이 무료로 접근하도록 변경했음을 알렸고, 2026-10-22 현재 Certification 안내에서도 구독이 필요하지 않음을 확인했다.

2026-10-22 FAQ 기준 유효기간은 12개월이다. 유효한 자격은 합격 후 9개월부터 갱신할 수 있고, 실패 후 재응시에는 최소 25일의 대기가 필요하다. 기존 AWS Certification의 유지와 갱신 조건을 이 평가에 그대로 적용하지 않는다.

활용 제안: 필요한 업무와 평가 주제가 맞을 때 선택하고, 합격한 주제와 유효기간을 명시한다. 평가 통과를 실제 고객 환경의 운영 경력이나 모든 AWS 서비스의 숙련으로 표현하지 않는다. 문제 원문을 공개 작업물로 옮기지 않고 별도의 공개 예제로 판단과 재현 능력을 보여준다. 이 절의 추가는 사용자의 응시 결정이나 새 학습 트랙 개설을 뜻하지 않는다. 다른 프로그램의 비용과 유지 정책은 재검증하지 않아 기존 `verified_at`을 유지한다.

### AI 입문 강좌와 시험형 자격의 구분

2026-10-21 공식 안내 부분 대조 기준이다. 같은 AI 입문 목록에 있더라도 강좌 수료와 시험 통과의 요건은 다르다.

- **AI for Everyone, Generative AI for Everyone:** DeepLearning.AI의 공식 도움말은 두 강좌에 코딩이 필요하지 않다고 안내한다. 개념과 활용 이해를 위한 입문 과정이라는 점을 확인할 수 있지만, 이 안내만으로 구현 역량이나 채용 효과를 입증할 수는 없다. 현재 수강료와 수료증 발급 조건은 별도 확인 대상이다.
- **Microsoft Certified: Azure AI Fundamentals:** 확인한 자격 페이지는 필수 시험을 `AI-901`로 연결하고 Azure AI 개념, Python 문법과 프로그래밍 기법, Azure 리소스 지식을 요구한다. 자격 이름만 보고 비개발자용 강좌와 같은 선수 조건이라고 판단하지 않는다. 오래된 시험 코드가 붙은 자료를 사용할 때는 현재 시험 페이지와 학습 가이드부터 대조한다.
- **이름이 불완전한 추천 목록:** 공급자 로고만으로 자격을 특정하지 않는다. 정식 명칭, 시험 코드, 학습 목표와 현재 운영 여부를 확인한 뒤 비교한다. 추천자의 S/A/B 등급을 채용 시장의 검증된 가치 순위로 바꾸지 않는다.

이는 과정 선택 기준이며 사용자의 자격증 준비나 새 학습 트랙을 시작한다는 결정이 아니다. 다른 절의 가격과 유지 정책을 다시 대조하지 않아 기존 `verified_at`은 유지한다.

### 선택과 이해 확인 절차

다음은 위 차이를 활용한 학습 절차 제안이다. 특정 수료증의 채용 효과를 입증한 연구 결과는 아니다.

1. 현재 설명하거나 수행하기 어려운 업무 하나를 적는다. 예를 들어 데이터 분석이라면 데이터를 읽고 오류를 찾은 뒤 결과를 설명하는 작업으로 좁힌다.
2. 후보 과정의 실제 과제가 그 빈칸을 다루는지 확인한다. 기업 로고와 짧은 소요 시간만으로 선택하지 않는다.
3. 비용과 전체 소요 시간, 완료 조건을 읽고 현재 학습 범위 안에서 선택한다. 수료증 목록이 늘었다는 이유로 여러 트랙을 동시에 시작하지 않는다.
4. 허용된 자료로 과제를 수행한 뒤 답안을 보지 않고 판단 이유와 한계를 설명한다. 공개할 수 없는 과제나 데이터를 포트폴리오에 복제하지 않는다.
5. 다른 입력으로 같은 작업을 다시 수행해 본다. 막힌 부분만 보완하고, 수료 사실과 독립 수행 여부를 별도로 기록한다.

## 교육 과정을 실제 업무 수요에 연결하기

조직이나 지역의 교육 설계에서도 먼저 필요한 역할과 역량을 정한다. AWS CAF의 Workforce transformation은 학습 목표를 전환 로드맵에 연결하고, 현재 지식과 기술의 차이를 파악해 역할별 학습 경로를 고르도록 안내한다. 이 조직 운영 원칙을 개인 학습에 적용할 때는 현재 수행할 업무와 확인할 빈칸으로 범위를 줄인다.

아래는 이 원칙을 교육 선택과 평가에 적용한 제안이다. 특정 지역 사업의 성과나 개인의 채용 가능성을 입증하는 기준은 아니다.

| 단계 | 남길 근거 | 혼동하지 않을 것 |
|---|---|---|
| 수요 확인 | 실제 역할에서 수행해야 하는 작업과 필요한 수준 | 인기 기술 목록을 업무 수요로 간주하지 않는다 |
| 격차 진단 | 도움 없이 수행 가능한 부분과 막히는 부분 | 수강 이력만으로 시작 수준을 정하지 않는다 |
| 실습 연결 | 해당 작업을 다루는 과제, 피드백과 재수행 결과 | 자격증 취득과 독립적인 문제 해결을 구분한다 |
| 후속 확인 | 다른 입력이나 실제 업무에 적용한 결과와 한계 | 수료율, 업무 적용과 취업 성과를 하나로 합치지 않는다 |

교육 이후에 실습 결과를 활용할 업무와 피드백 경로가 없다면 그 연결부터 보완한다. 이 절은 과정 선택 기준이며 사용자의 새 학습 트랙이나 자격증 준비를 시작한다는 결정이 아니다.

## 유료 피드백과 멘토링을 검토할 때

강의, 문서와 공개 영상은 무료로도 많이 구할 수 있다. 무료 자료로 대체하기 어려운 것은 내 코드, 이력서와 상황을 직접 보고 빠진 부분을 짚어 주는 개인화된 피드백이다. 유료 멘토링이나 코칭을 검토할 때는 콘텐츠의 양보다 피드백의 구조를 비교한다. 아래는 비교 질문이며 특정 서비스의 효과를 보장하는 기준이 아니다.

- **무엇을 검토받는지:** 누가, 어떤 산출물을, 얼마나 자주 보고 어떤 형식으로 답하는지 확인한다. 녹화 강의에 질문 게시판만 붙은 상품은 피드백 상품과 다르다.
- **혼자 걸릴 기간과의 비교:** 혼자 해결할 수 있는지보다 그 기간과 시행착오를 지금 감당할 수 있는지로 비교한다. 동료 코드 리뷰와 커뮤니티 피드백처럼 비용이 들지 않는 경로도 같은 비교에 넣는다([[Professional-Networking-and-Mentors|외부 네트워킹과 멘토 확보]]).
- **회수 계산의 전제:** 수강 뒤 연봉이 오르면 비용을 곧 회수한다는 계산은 취업 시점과 연봉을 가정한 시나리오다. 판매자가 내세우는 수강생 사례는 [[Effort-Value-In-Hiring#증명, 학습 방법, 투입 자원으로 전략을 고른다|부트캠프 선택 기준]]과 같은 항목으로 확인한다.
- **결과가 없을 때의 빈칸 찾기:** 한 과정을 마쳤는데 결과로 이어지지 않았다면 그 과정이 헛수고였다고 단정하기 전에 임팩트가 드러나지 않는 포트폴리오, 행동 면접 답변, 시간 제한이 있는 라이브 코딩처럼 다른 구간이 막혔는지 본다. 막힌 구간은 [[Effort-Value-In-Hiring#시장 결과와 개인 학습을 구분한다|지원 단계별 결과]]로 좁힌다.

## 이해 확인

- 무료 체험이 있는 유료 과정과 무료 직무 시뮬레이션의 비용 조건은 어떻게 다른가?
- 유료 멘토링 상품이 파는 것이 콘텐츠인지 내 산출물에 대한 피드백인지 무엇으로 확인할 것인가?
- 기업이 만든 시뮬레이션을 마쳤다는 사실과 그 기업에서 근무했다는 사실을 어떻게 구분해 설명할 것인가?
- 모범 답안을 닫은 뒤에도 결과가 나온 이유와 입력이 달라질 때의 한계를 설명할 수 있는가?
