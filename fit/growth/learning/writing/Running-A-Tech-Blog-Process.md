# 기술 블로그 운영 프로세스 (5단계)

[[Running-A-Tech-Blog|기술 블로그 운영]]의 지속성을 위한 표준 프로세스. 글감 등록부터 배포까지 단계를 고정해 개인 의지 대신 구조로 굴린다.

## 1. 글감 등록

- 아이디어 단계 → Issue/Board에 등록
- **누구에게 도움이 되는지**, **기대 효과** 한 줄 기재
- 제목 후보 1~2개

## 2. 글감 리뷰

- **예상 독자** 구체화 (주니어, 시니어, 비개발자)
- **핵심 메시지** 3~5줄
- 쓸 가치, 범위 확정
- 여러 주제가 겹치면 **시리즈로** 쪼개기

## 3. 글 작성

- 초안은 **구조화 위주** — 제목, 목차, 핵심 예시
- 완벽하지 않아도 **일단 끝내기**
- 템플릿 활용 (도입-본문-정리-참고)

## 4. 초안 피드백

- **Git PR로 리뷰** — 문체, 저작권, 정확성
- 리뷰어 2~3명
- 맞춤법, 읽기 흐름, 보충 자료

## 5. 보완 + 배포

- 피드백 반영
- SEO, 이미지, 링크 최종 점검
- 배포 후 공유
