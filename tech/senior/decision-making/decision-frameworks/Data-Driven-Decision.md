# 데이터 기반 의사결정

감(感)만이 아니라 관측 가능한 근거로 제품과 기술 방향을 결정하는 역량이다. 시니어 엔지니어는 "왜 이걸 하는가?"에 정량 또는 정성 근거로 답하고, 아직 계측하지 못한 것은 미측정으로 구분할 수 있어야 한다.

## 핵심 원칙

1. **측정 정의가 먼저다** — 가설, 분모, 코호트와 이벤트 연결이 없으면 숫자를 만들지 않고 미측정으로 둔다
2. **숫자에 맥락을 붙인다** — 활성 사용자 수만 나열하지 않고, 비교 기간, 분모, 유입과 이탈 조건을 함께 기록한다
3. **행동으로 이어진다** — 데이터 수집 자체가 목적이 아님. 데이터 → 인사이트 → 액션

## 전환 퍼널 분석

사용자가 서비스를 처음 접한 순간부터 핵심 가치를 경험하기까지의 단계별 전환율을 추적한다.

한 개인 프로젝트의 과거 퍼널은 가입과 핵심 행동을 서로 다른 분모로 나눠 전환율처럼 읽은 문제가 있었다. 같은 코호트 식별자로 이벤트가 연결되지 않았다면 Activation 전환율은 **미측정**으로 둬야 한다.

**의사결정:**
- 가입과 핵심 행동의 `first_*` 이벤트를 같은 코호트 식별자로 연결
- 계측 완성 전에는 단계별 전환율과 병목 원인을 단정하지 않음
- 랜딩 이탈처럼 별도 정의가 있는 지표도 측정 기간, 분모와 변경 전후 조건을 함께 기록

## 코호트 분석

같은 시기에 가입한 사용자 그룹의 행동 패턴을 비교한다.

과거 스냅숏이 현재 코호트 정의와 이벤트 연결로 재현되지 않으면 제품 개선 증거로 사용하지 않는다. 같은 가입 시점, 같은 활성화 정의와 관찰 기간을 갖춘 뒤에야 코호트 차이를 제품 변화나 유입 구성과 연결할 수 있다.

## 사용자 세그먼트 분석

모든 사용자를 동일하게 보지 않고, 행동 패턴에 따라 분류한다.

분석 도구의 맞춤 차원이 조직과 계정의 관계를 제공하지 않으면 세그먼트별 활성 지표를 재산출할 수 없다. 세그먼트 전략은 식별 계측을 고친 뒤 최소 표본, 관찰 기간과 행동 정의를 명시해 다시 검증한다.

## GA4 행동 데이터 활용

제품 내 사용자 행동을 이벤트 단위로 추적한다.

- 특정 콘텐츠 조회와 반복 조회를 행동 신호로 관찰할 수 있다.
- 이 값은 관심 신호일 뿐 조직별 재방문이나 인과를 증명하지 않는다.

**의사결정:** 조회 경험을 가치 가설로 유지하되, 조직 귀속과 반복 방문을 연결하기 전에는 킬러 피처로 확정하지 않는다.

## 설득 도구로서의 데이터: 이해관계 충돌의 중재

데이터의 용도는 내 의사결정만이 아니다. **부서 간 이해가 충돌할 때 서로 다른 추측을 검증 가능한 주장으로 바꾸는 중재 도구**가 된다. 다만 클릭 같은 행동 지표 하나가 가치나 인과를 자동 증명하지는 않는다. 지표 정의, 분모와 대안 설명을 함께 확인해야 논쟁의 범위를 좁힐 수 있다.

- 분석용 데이터는 답을 탐색하고, 설득용 데이터는 **공통 판단 근거를 만든다**. 같은 수치라도 정의와 불확실성을 숨기지 않는다.
- 충돌이 벌어진 뒤 수집한 데이터는 진영 논리로 읽히기 쉽다 — 평소에 깔아 둔 측정이 설득력의 원천. 계측을 미리 심는 것이 정치적 자산이기도 하다.
- 설득에 실패했을 때의 선택지는 포기, 타협, 협상 세 가지인데, 협상의 토대가 곧 논리와 데이터다 — 우기지 말고 모르면 배우고, 근거로 설득한다.

## 이탈 감지와 자동 대응

데이터 기반으로 이탈 위험을 조기 감지하고 자동으로 개입한다.

- 고정 미활동 기간만으로 이탈을 확정하지 않음. 늦은 복귀가 가능한 서비스라면 분포를 먼저 확인해야 함
- 입력 공백, 운영 중단과 영구 이탈을 분리하고 복귀 분포를 다시 산출한 뒤 개입 기준을 정함
- 시스템 알림, 사람 DM과 구체적 사용 안내를 서로 다른 개입으로 측정

## 면접 포인트

Q. 데이터 기반 의사결정 경험이 있는가?
- 서로 다른 분모를 전환율로 읽은 오류를 발견하고 Activation을 미측정으로 되돌림
- 조회 이벤트를 가치 가설의 신호로 사용하되 단체 재방문과 인과가 확인되기 전에는 킬러 피처로 확정하지 않음
- 같은 코호트 식별자와 `first_*` 이벤트를 연결하는 계측을 분석의 선행 조건으로 둠

Q. 어떤 지표를 추적했는가?
- 운영 스냅숏: 활성과 누적, 조직과 개인처럼 단위가 다른 지표를 분리해 기록
- Activation: 가입과 핵심 행동을 같은 코호트로 연결한 뒤 측정
- 행동 신호: 조회 이벤트의 사용자 수와 건수. 조직 귀속 전에는 조직별 활성으로 해석하지 않음
