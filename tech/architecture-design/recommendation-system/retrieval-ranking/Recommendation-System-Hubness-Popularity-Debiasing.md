# 허브니스와 사용자 무관 점수 성분

임베딩 내적으로 후보를 찾거나 점수를 매기는 추천에서 같은 상품이 거의 모든 사용자의 상위에 오르면, 원인은 실제 인기만이 아니라 벡터 공간의 기하일 수 있다. 점수를 사용자에 따라 달라지는 성분과 사용자와 무관하게 상품마다 붙는 성분으로 나눠 보면 진단, 보정과 평가를 따로 설계할 수 있다.

## 허브니스와 인기 편향은 다르다

- **k-occurrence와 허브:** 데이터 집합의 각 점 x가 다른 점들의 k-최근접 이웃 목록에 몇 번 등장하는지를 `N_k(x)`라 한다. 차원이 커지면 `N_k` 분포가 오른쪽으로 크게 치우치고, 매우 많은 k-NN 목록에 등장하는 점, 곧 허브가 생긴다. 반대로 거의 어떤 목록에도 들지 않는 점은 antihub다.
- **고차원의 내재적 성질:** Radovanović 등(JMLR 2010)은 허브니스가 유한 표본이나 특정 데이터의 산물이 아니라 널리 쓰이는 가정 아래 고차원 데이터 분포의 내재적 성질이라고 보였다.
- **중심에 가까운 점이 허브가 된다:** 데이터 중심(평균)과 유사도가 높은 점일수록 같은 분포에서 뽑은 질의에 대해 확률적으로 더 가깝게 나와 허브가 되기 쉽다. Suzuki 등(EMNLP 2013)은 내적 유사도에서 이를 분석했고, 여러 군집으로 이뤄진 데이터에서도 중심과 조금만 더 가까운 점이 허브가 될 수 있음을 보였다. 사용자 벡터로 상품을 찾는 추천에서는 질의 분포의 중심, 곧 사용자 벡터의 평균 방향이 이 중심에 해당한다(해석).

추천에서 두 현상을 구분하면 다음과 같다(해석).

| 구분 | 인기 편향 | 허브니스 |
|---|---|---|
| 성질 | 실제로 많이 클릭되거나 팔린 데이터의 분포 | 모든 사용자 벡터의 평균 방향에 가깝다는 기하학적 위치 |
| 비유 | 많은 사람이 고른 음식 | 100명의 취향 평균에 가까워 누구에게나 무난한 음식 |
| 신호 | 노출 점유가 인기 점유와 비슷하게 큼 | 노출 점유가 인기 점유보다 훨씬 큼 |
| 대응 | 노출 정책, 탐색, 인기 보정 | 중심화, 상품별 편향 분리, 후보 집합 점검 |

## 점수를 두 성분으로 나눈다

```text
score(u, i) = 사용자 의존 성분(u, i) + 사용자 무관 성분(i)
```

사용자 무관 성분은 상품 자체의 분포 특성이나 여러 편향에서 오며, 어느 사용자에게나 같은 방향으로 점수를 올린다. 이 분해는 진단과 보정을 위한 작업 가설이지 모델이 보장하는 구조가 아니다. 아래의 진단, 보정 설계와 지표 문제는 한 커머스 서비스의 발표(아래 사례)에서 가설로 세우고 각각 한두 실험으로 확인한 것이므로, 다른 서비스에서는 같은 측정으로 다시 확인한다.

내적 점수에서는 이 성분을 식으로 볼 수 있다. `s(u, i) = <u, v_i>`이면 사용자 평균 벡터 `ū`에 대해 상품별 전체 사용자 평균 점수는 `<ū, v_i>`이고, 이를 빼면 `<u − ū, v_i>`가 되어 사용자 쪽 벡터를 중심화한 것과 같다(선형성에서 유도한 해석). 다중 관심 모델의 max 집계처럼 점수가 비선형이면 이 등식은 성립하지 않으므로, 전체 사용자 이력을 배치 추론해 상품별 평균 점수를 직접 구하는 경험적 추정이 된다.

## 후보 집합이 허브를 키운다

같은 모델이라도 후보 집합에 따라 사용자 무관 성분의 비중이 달라진다.

- **Retrieval:** 후보가 전체 카탈로그면 평균 방향에 몰린 상품은 일부다.
- **인기 상위 후보의 reranking:** 인기 상위 N개를 후보로 두면 후보 자체가 사용자 평균 방향 쪽에 몰려 있을 수 있다. 그러면 평균 방향과 가까운 관심 벡터나 상품이 순위를 지배할 수 있다.

Retrieval 모델을 reranker로 재사용하기 전에 후보 상품과 사용자 평균 방향의 cosine 분포를 먼저 본다. 양수 쪽에 몰려 있으면 지면별로 보정 강도를 따로 둔다.

## 진단

| 질문 | 측정 | 해석 |
|---|---|---|
| 후보 집합이 평균 방향에 몰렸는가 | 후보 상품 벡터와 사용자 평균 방향의 cosine을 무작위 상품 집합과 비교 | 무작위보다 크면 지면 차이가 후보 집합에서 올 수 있다. 순위에 미치는 영향은 후보 사이의 상품별 평균 점수 `m_i` 편차를 `s(u, i) − m_i`의 편차와 비교해 확인한다 |
| 한 관심 벡터가 순위를 정하는가 | max 집계에서 상위 N개의 점수를 만든 관심의 점유율 | 관심 K개가 균등하면 각 1/K. 한 관심이 과반이면 그 관심이 사용자와 무관한 방향을 담았을 수 있다 |
| 관심 벡터에 입력 무관 성분이 있는가 | 이력을 무작위로 바꿔 관심 벡터를 여러 번 뽑고 정규화한 벡터의 평균 길이를 잰다 | 0에 가까우면 입력을 따르고 1에 가까우면 입력과 무관하게 고정된 방향 |
| 노출이 쏠렸는가 | 상위 N개 상품의 노출 점유, 노출된 고유 상품 수, 노출 점유가 인기 점유의 몇 배인지 | 인기로 설명되지 않는 과노출 상품을 따로 센다 |

## 보정

### 중심화

중심화는 원점을 데이터 중심으로 옮기는 변환 `x_cent = x − x̄`다. 점 사이의 거리는 변하지 않지만 내적과 cosine은 바뀐다. 중심화 뒤에는 모든 점과 중심(영벡터)의 내적이 0이 되어 중심과의 유사도가 같아지고, 중심 근처 점의 벡터가 짧아져 다른 점과의 내적이 작아진다. Suzuki 등은 이 효과로 허브가 준다고 분석했고, 중심 대신 허브 쪽으로 원점을 더 옮기는 weighted centering을 제안했다. 실험한 세 데이터 가운데 두 곳에서 weighted centering이 허브 지표(skewness)를 더 낮췄고, 결론은 일부 경우에 분류 성능을 더 높였다는 수준이다.

서빙 점수에서는 상품별 전체 사용자 평균 점수를 사용자 무관 성분으로 보고 빼는 방식으로 적용할 수 있다. 평균 점수 전체를 빼면 인기 자체도 지워지므로 둘로 나누는 변형이 있다. 아래 식은 발표의 구두 설명에서 재구성한 것이며 슬라이드의 정확한 식은 확인하지 못했다.

```text
m_i         = 상품 i의 전체 사용자 평균 점수(배치 추론)
g(pop_i)    = 인기도가 비슷한 상품들의 평균 점수 중앙값(인기도의 함수)
r_i         = m_i − g(pop_i)                       (인기로 설명되지 않는 잔차)
보정 점수    = s(u, i) − a * r_i − b * g(pop_i)      (a, b는 지면별 계수)
```

잔차는 retrieval과 reranking 모두에서 빼고, 후보가 이미 인기 상품인 reranking에서만 인기 성분을 추가로 빼는 식으로 지면마다 계수를 다르게 둔다.

### 학습 때 상품별 편향을 분리한다

서빙 단계의 보정만으로는 모델이 학습 중에 사용자 무관 성분을 계속 관련성 점수에 섞어 배울 수 있다. 학습 점수에 상품별 학습 편향 `b_i`를 더해 사용자와 상품의 관련성으로 설명되지 않는 클릭 성향을 거기에 흡수시키고, 서빙 때 `b_i`를 뺀다.

MACR(KDD 2021)은 같은 생각을 인과 그래프로 정리했다.

- 기존 추천기의 사용자-상품 matching 점수 `ŷ_k`에 상품 모듈 `ŷ_i`와 사용자 모듈 `ŷ_u`를 더해 학습한다. 학습 점수는 `ŷ_k * σ(ŷ_i) * σ(ŷ_u)`이고 손실은 `L_O + α*L_I + β*L_U`다. 상품 모듈은 인기가 높을수록 큰 값을 내도록 상품 인기의 영향을 담고, 사용자 모듈은 선호와 무관하게 상호작용하는 정도(conformity)를 담는다.
- 추론 때는 `ŷ_k * σ(ŷ_i) * σ(ŷ_u) − c * σ(ŷ_i) * σ(ŷ_u)`로 상품이 점수에 주는 직접 효과(I에서 Y로 가는 natural direct effect)를 빼서 순위를 매긴다. 식은 `σ(ŷ_i) * σ(ŷ_u) * (ŷ_k − c)`와 같아서, 한 사용자 안에서는 `σ(ŷ_u)`가 양의 상수라 순위를 바꾸지 않는다. `c`는 matching 점수의 기준값을 뜻하는 hyper-parameter로 조정해서 정한다(부록 B의 탐색 범위 20~40).
- 상품 모듈은 자유로운 상품별 스칼라가 아니라 상품 embedding을 점수로 투영하는 모듈(MLP로 구현 가능)이고 곱셈으로 결합한다. 학습 편향 `b_i`를 더했다가 빼는 단순한 방식은 이 구조와 같지 않으며, 논문 비교군 가운데 `ŷ_k + b_i` 형태의 baseline에 가깝다.
- 논문의 test set은 상호작용을 상품마다 같은 확률로 뽑아 상품 분포가 균등하게 만든 것이다. 실제 서비스의 노출 분포에서 같은 이득이 나는지는 따로 검증한다.

### logQ 보정과 구분한다

In-batch softmax는 같은 batch의 다른 상품을 negative로 쓴다. 상품이 power-law 분포에서 뽑히면 인기 상품이 negative로 자주 들어가 과하게 벌점을 받는다. Yi 등(RecSys 2019)은 logit을 `s^c(x_i, y_j) = s(x_i, y_j) − log(p_j)`로 고치고(`p_j`는 상품 j가 무작위 batch에 뽑힐 확률), `p_j`는 스트리밍 데이터에서 같은 상품이 다시 뽑히기까지의 평균 step을 추정해 구한다. 이는 학습 손실의 표본 편향을 고치는 것이며, 사용자 무관 성분을 서빙 점수에서 빼는 위의 보정과 목적이 다르다. 둘을 함께 쓸 수 있다.

## 관심을 벌려도 max 집계에서는 한 관심이 지배할 수 있다

다중 관심 벡터 사이의 유사도를 낮추는 정규화만으로는 추천 결과가 다양해지지 않을 수 있다. 점수가 `max_k <u_k, v_i>`이면 상품마다 가장 강한 관심 하나만 반영되므로, 한 관심의 점수 규모가 다른 관심보다 크면 그 관심이 상위 목록을 채울 수 있다. 러닝화, 캠핑, 피규어, 의류 관심이 있어도 러닝화 관심이 러닝화 상품에 내는 점수가 다른 관심의 점수보다 크면 상위에는 러닝화만 보인다.

- 관심 분리를 카테고리 분포로 유도하는 정규화를 더하면 관심이 카테고리별로 나뉘도록 할 수 있다.
- 최종 목록에 카테고리 다양성 후처리를 둔다. ComiRec(KDD 2020)은 관심별로 top N을 검색한 뒤 `Σ f(u,i) + λ Σ g(i,j)`(g는 두 상품의 카테고리가 다르면 1)를 greedy로 최대화하는 controllable aggregation을 제안했다. λ=0이면 정확도 위주의 max 집계, λ가 클수록 다양성 위주다.
- 대조군에 다양성 후처리가 있었다면 실험군에도 같은 후처리를 넣어야 모델 차이만 비교된다.

## 지표가 두 성분을 못 볼 수 있다

- **Recall은 사용자 의존 성분의 감소를 놓칠 수 있다.** 다음 클릭 하나를 맞히는 과제에서는 평균에 가까운 벡터가 유리할 수 있어, 관심이 하나로 붕괴해 다양성이 줄어도 recall이 오를 수 있다.
- **클릭은 사용자 무관 성분의 증가를 놓칠 수 있다.** 과노출 상품이 평균보다 CTR은 높고 CVR은 낮다면, 클릭만 보는 실험은 과노출을 개선으로 착각한다.
- **지면 지표는 지면 설계와 모델 기여를 섞는다.** 카테고리마다 상품 하나를 강제로 보여주는 지면에서 이긴 모델이 그런 규칙이 없는 피드에서 지면, 증명된 것은 관심 다양성이 아니라 카테고리 안의 정확도다.

대응은 다음과 같다.

- Offline에서 recall과 NDCG에 노출 분포 지표(상위 N개 노출 점유, 고유 노출 상품 수, 과노출 상품 수)를 더한다.
- Online에서 클릭과 구매에 과노출의 비열등성 지표를 더하고, 판정 기준을 실험 전에 확정한다.
- 지면의 후처리 규칙과 다양성 처리를 offline 평가에서도 재현해 모델 기여와 분리한다.

## 적용 점검

1. 새 지면에 모델을 붙일 때 후보 상품과 사용자 평균 방향의 cosine 분포를 본다.
2. 모델 채택 기준에 노출 분포 지표를 넣는다.
3. 다중 관심 모델은 무작위 이력으로 관심별 입력 불변성을 확인한다.
4. 사용자 무관 성분을 서빙에서만 빼는지, 학습에서도 분리하는지 정한다.
5. 과노출 상품을 빼면 단기 클릭이 줄 수 있으므로 기대 방향과 guardrail을 미리 합의한다.

## 사례: 커머스 다중 관심 모델의 과노출

NAVER Engineering Day 10th에서 공개된 KREAM 추천 모델의 사례다(서비스명은 발표자의 소속 소개 음성 기준). 수치는 모두 발표 기준이며 외부에서 재현하지 않았다.

- MINER 구조의 다중 관심 모델(관심 4개, 최근 본 상품 최대 50개)을 홈 카테고리 추천과 무한 스크롤 피드의 retriever, 인기 상위 3,000개 상품의 reranker로 함께 썼다. 마지막 클릭 상품의 상태를 집계에 따로 반영한 점이 논문과 다르다. 이전에 쓰던 ComiRec 계열 모델에서 관심 붕괴를 겪어 disagreement 정규화가 있는 MINER를 택했다.
- 같은 상품이 많은 사용자에게 노출되는 현상은 인기 상위 후보를 쓴 reranking 지면에서 두드러졌다. 상위 20개를 정한 관심의 최대 점유는 retriever 38.5%, reranker 52.2%였고(균등이면 25%), 무작위 이력으로 잰 관심 평균 벡터 길이는 0.36~0.51이었다. 노출 점유가 인기 점유의 10배를 넘는 상품을 과노출 상품으로 정의했다.
- 서빙 중심화와 학습 편향 분리를 함께 적용한 A/B 테스트에서 상위 100개 상품의 노출 점유가 줄고 노출 상품 종류가 늘었다. 클릭은 줄었는데, offline recall이 약 4% 낮아진 것과 같은 이유로 과노출 상품이 평균보다 클릭이 높은 상품이었기 때문이며 예상한 결과라 롤아웃했다.
- 관심 사이 cosine 정규화를 100배로 키우자 평균 유사도가 0.65에서 거의 0이 됐지만 관심 하나가 상위의 89%를 정했고 recall이 25% 떨어져 기각했다. 카테고리 정규화는 recall이 약 2% 낮았지만 다른 지표 개선으로 롤아웃했다. 관심을 하나로 강제 붕괴시키자 recall이 11% 올랐다.
- 남은 과제로 reranking 후보 집합 변경, max가 아닌 집계, 이력이 4개 미만인 사용자 대응을 꼽았다.

## 출처

- [Hubs in Space: Popular Nearest Neighbors in High-Dimensional Data — JMLR 11 (2010), Miloš Radovanović 외](https://www.jmlr.org/papers/volume11/radovanovic10a/radovanovic10a.pdf) — 2026-11-14 초록과 1절 대조. k-occurrence, 허브와 antihub 정의, 고차원의 내재적 성질
- [Centering Similarity Measures to Reduce Hubs — EMNLP 2013, Ikumi Suzuki 외](https://aclanthology.org/D13-1058/) — 2026-11-14 PDF 대조. 1~5절의 중심화 식, 거리 불변과 내적 변화, 중심과 유사한 점이 허브가 되는 분석, 다중 군집, 6~7절의 weighted centering과 결과
- [Model-Agnostic Counterfactual Reasoning for Eliminating Popularity Bias in Recommender System — KDD 2021, Tianxin Wei 외](https://arxiv.org/abs/2010.15363) — 2026-11-14 arXiv v2 HTML 3.3~3.4절, 4.1절, 부록 B 대조. 학습과 추론 식, 상품과 사용자 모듈, 균등 test set, `c` 탐색 범위
- [Sampling-Bias-Corrected Neural Modeling for Large Corpus Item Recommendations — RecSys 2019, Xinyang Yi 외](https://research.google/pubs/sampling-bias-corrected-neural-modeling-for-large-corpus-item-recommendations/) — 2026-11-14 PDF 3~4절 대조. In-batch softmax의 편향, logQ 보정 식, 스트리밍 빈도 추정
- [Controllable Multi-Interest Framework for Recommendation — KDD 2020, Yukuo Cen 외](https://arxiv.org/abs/2005.09347) — 2026-11-14 arXiv v2 HTML 3.2~3.3절 대조. 관심별 검색과 controllable aggregation
- [딸깍으로 안되는 Multi-interest 개발기 — NAVER D2, NAVER Engineering Day 10th](https://www.youtube.com/watch?v=8D0CaQrUgCU) — 점수 분해 가설, 진단 측정, 잔차와 인기 성분 보정, 학습 편향 분리, 지표 설계, 적용 점검과 사례 수치의 출처
