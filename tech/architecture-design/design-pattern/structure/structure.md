# 구조 패턴 (structure 인덱스)

구조를 유연하고 효율적으로 유지하면서 객체와 클래스를 더 큰 구조로 조합하는 패턴 모음. 인터페이스 불일치, 접근 제어, 기능을 겹쳐 붙이는 문제, 단일 객체와 객체 조합을 같은 방식으로 다루는 문제를 해결한다. 상위 인덱스는 [[디자인패턴이란|디자인 패턴이란]].
