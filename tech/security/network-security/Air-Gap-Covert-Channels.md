# 에어갭 은닉 채널: 네트워크 없이 자료를 내보내는 물리 경로

에어갭(air gap)은 시스템이나 망을 인터넷을 포함한 외부 네트워크와 물리적으로 연결하지 않는 통제다. 은닉 채널(covert channel)은 시스템 설계자가 통신용으로 만들지 않은 수단으로 정보를 옮기는 경로다. 에어갭 은닉 채널은 이미 격리 시스템 안에 들어온 악성코드가 하드웨어의 전자기파, 소리, 빛, 열 같은 물리 방출을 일부러 조절해 근처 수신기로 자료를 내보내는 방식을 말한다.

한 줄 요약: **에어갭은 네트워크 트래픽을 끊지만 하드웨어가 내는 물리 방출까지 끊지 않는다. 다만 이 채널은 먼저 내부 감염과 근거리 수신기가 있어야 하고 대역폭이 작아, 키와 비밀번호처럼 짧은 비밀이 주된 위험이다.**

## 공격 전제: 두 단계가 모두 필요하다

은닉 채널은 침투 수단이 아니라 이미 침투한 뒤의 유출 수단이다.

1. **침투**: 격리망 안의 시스템을 먼저 감염시킨다. 이동식 저장매체, 내부자, 공급망으로 들어온 소프트웨어처럼 망분리가 막지 못하는 반입 경로를 쓴다([[Network-Separation#무엇을 막고 무엇을 못 막는가|망분리가 막지 못하는 경로]]).
2. **유출**: 감염된 프로그램이 수집한 자료를 물리 신호로 바꿔 보내고, 공격자는 근처에 둔 수신기로 받아 복호화한다.

## 사례: RAMBO, 메모리 버스를 무선 송신기로 쓰기

Ben-Gurion University의 Mordechai Guri가 발표한 RAMBO(arXiv 2409.02292, 2024-09-03 v1, arXiv 설명란에 NordSec 2023 게재본이 있다고 표기)는 RAM 버스의 전자기 방출을 송신기로 쓴다. 아래 수치는 이 논문 v1의 실험 조건 기준이다.

### 신호를 만드는 원리

- **방출원**: 메모리 버스(주로 데이터 버스)로 자료가 오갈 때 전압 변화가 전자기파를 낸다. 주파수는 메모리 클록에 따라 정해지며, 논문은 1.6GHz로 동작하는 DDR4-3200이 약 1.6, 3.2, 4.8GHz 부근에서 방출한다는 예를 든다.
- **변조**: 메모리 쓰기를 집중적으로 일으키는 구간을 1, `sleep()`으로 쉬는 구간을 0으로 두는 OOK(On-Off Keying)다. 쓰기에는 non-temporal store 명령인 `MOVNTI`를 쓴다. 프레임 앞에 `10101010` 프리앰블을 붙이고, 빠른 전송에는 Manchester 부호화를 쓴다. Manchester는 비트마다 전이가 있어 수신 측 클록 동기와 오류 검출에 유리하지만 대역폭을 두 배로 쓴다.
- **수신**: 소프트웨어 정의 라디오(SDR, 실험은 Ettus B210 USRP)와 시판 안테나로 받아 복조한다.
- **권한**: 논문은 송신에 관리자 권한이 필요한지 명시하지 않는다. x86 명령 참조에서 `MOVNTI`는 SSE2 명령이고 예외 목록에 권한 수준(CPL) 조건의 예외가 없어, 일반 사용자 코드에서도 실행할 수 있는 명령으로 읽힌다.

### 측정 결과 (Intel i7 3.6GHz, 16GB RAM, Ubuntu 18.04 PC 3대)

| 비트 시간 | 전송률 | 최대 측정 거리 | 최대 거리에서의 비트 오류율 |
|---|---|---|---|
| 10ms | 100bit/s | 7m | 0% |
| 5ms | 200bit/s | 4.5m | 3~4% |
| 1ms | 1,000bit/s | 3m | 2~4% |

- 위 표는 논문의 측정표(표 2~4) 기준이다. 5ms와 1ms 모두 2m까지는 오류율 0%였고, 4.5m 칸은 PC 3대 중 2대만 값이 있고 나머지 1대는 `-`로 표기돼 있으며 이유는 적혀 있지 않다. 5,000bit/s 이상(비트 시간 0.2ms 이하로 환산)은 표가 아니라 본문 서술로만 나오며, 오류율이 대체로 5%를 넘어 덜 효과적이라고 적는다.
- 유출 시간 표는 128비트 비밀번호를 1ms에서 0.128초(10ms에서 1.28초), 4096비트 RSA 키를 1ms에서 4.096초, 5ms에서 20.48초, 10ms에서 41.96초로 적는다. 키 입력은 키당 16비트로 세 속도 모두 실시간이다. 25,000비트짜리 작은 이미지도 1ms에서 25초로 시간을 적어 두었고, 논문은 이 채널을 짧은 시간에 비교적 짧은 정보를 내보내는 데 쓸 수 있다고 결론짓는다.
- VMware Workstation 16.2.4 가상 머신 안에서 송신한 실험에서도 오류율이 1% 미만이었다. 측정 거리와 비트 시간은 밝히지 않았고, 호스트나 다른 게스트의 부하가 신호 생성을 방해할 수 있다고 적는다.
- 확산 스펙트럼 클로킹(spread-spectrum clocking)을 켠 시스템에서는 방출에 변조 정보가 실리기 어려워진다고 적는다.
- 논문 안의 수치에는 어긋남이 있다. 10ms에서 4096비트 RSA 키의 계산값은 40.96초이고, 요약은 1,000bit/s를, 결론은 수백 bit/s를 말한다.

## 방어 수단과 비용

논문이 정리한 대응과 그 한계는 다음과 같다. 논문은 대응 사이에 우선순위를 매기지 않는다.

| 대응 | 방식 | 한계 |
|---|---|---|
| 구역 분리(zoning, red-black 분리) | 민감 장비 주변에 수신기를 둘 수 없는 거리와 구역을 둔다 | 공간과 비용 |
| 호스트 침입 탐지 | 비정상적인 메모리 접근 패턴을 사용자나 커널 수준에서 감시한다 | 오탐이 많고 실행 부담이 있다 |
| 하이퍼바이저 수준 메모리 접근 감시 | 가상화 계층에서 접근 패턴을 본다 | 오탐 가능성 |
| 외부 스펙트럼 감시 | 주변 무선 대역에서 이상 신호를 찾는다 | 오탐이 많다 |
| 내부 RAM 재밍 | 무작위 메모리 작업으로 신호를 뭉갠다 | 메모리 성능 저하, 권한을 얻은 악성코드가 재밍 프로세스를 끌 수 있다 |
| 외부 무선 재밍 | DDR 대역 전체에 잡음을 낸다 | 전파 간섭, 비용과 전력 |
| 패러데이 차폐 | 장비를 전도성 외함으로 감싼다 | 비용과 유지보수. 논문은 구리박으로 차폐 효과를 분석했다고 적고 전기장 차폐 특성을 100dB 이상으로 언급하며, 표준 규격 1mm(원문 표기는 width) 구리박이 방출을 효과적으로 막는다고 쓴다. 차폐 상태의 SNR이나 오류율 같은 실험 데이터는 제시하지 않는다 |

## 판단과 체크포인트

다음은 위 사실에서 끌어낸 실무 판단이며 논문의 결론이 아니다.

- **반입 경로부터 본다**: 유출 단계만 막으면 첫 단계로 들어온 악성코드는 반출 매체나 내부자 같은 다른 경로를 찾을 수 있다. 매체 통제와 반입 검사를 먼저 검토하고, 메모리 접근 감시는 위 표의 오탐과 실행 부담을 감안해 보조 수단으로 둔다.
- **위협 모델을 먼저 정한다**: 근거리에 수신기를 숨길 수 있는 공격자와 내부 감염이 동시에 성립하는 환경(국가 기반시설, 군, 고가치 키 관리 시설)에서 우선순위가 높다. 일반 기업의 격리망은 매체 통제와 반입 검사를 먼저 검토할 통제로 둔다.
- **짧은 비밀을 기준으로 위험을 잰다**: 비밀번호 같은 짧은 비밀은 1초 안팎, RSA 4096 키는 1,000bit/s에서 약 4초, 100~200bit/s에서 20~41초 걸린다. 논문은 오류 정정이나 재전송을 다루지 않는다. 장기 키를 범용 서버의 메모리에 오래 두지 않고 하드웨어 보안 모듈 안에서만 쓰게 하면 이 채널로 나갈 키 원본이 줄어든다. 다만 키 입력, 비밀번호와 호스트가 다루는 평문은 남는다.
- **가상화가 이 채널을 막는다고 가정하지 않는다**: 한 가상화 구성의 실험에서 게스트 안 송신이 가능했으므로, 같은 하드웨어를 공유하는 논리적 분리를 물리 방출 대책으로 계산하지 않는다.
- **차폐와 구역은 시설 설계의 문제다**: 사후에 장비별로 차폐하기보다 처음부터 민감 장비가 놓일 구역과 출입 통제를 함께 설계한다.

2. RAMBO에서 1과 0은 각각 어떤 메모리 동작으로 만들며, Manchester 부호화를 쓰는 대가는 무엇인가?
3. 전송률을 1,000bit/s로 올리면 최대 측정 거리와 오류율은 어떻게 변하는가?
4. 논리적 망분리 환경에서 가상화 격리를 이 채널의 대책으로 계산하지 않는 이유는?
