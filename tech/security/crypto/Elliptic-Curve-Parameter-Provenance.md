# 타원곡선 파라미터의 출처와 검증 경계

타원곡선의 공개 파라미터를 어떻게 골랐는지와 사용자의 개인키를 알아낼 수 있는지는 다른 질문이다. 공개 파라미터의 생성 경로를 재현해도 개인키 복구나 암호 해독을 뜻하지 않는다.

## seed와 키를 구분한다

NIST SP 800-186은 소수체 위의 의사난수 Weierstrass 곡선에 대해 소수 p, 계수 a와 b, 기준점 G, 차수 n 등과 함께 160비트 Seed를 제시한다. Seed는 부록 C.3의 SHA-1 기반 곡선 생성 절차에 쓰는 공개 입력이다. 곡선 계수의 생성 입력과 기준점, 사용자별 비밀키를 같은 값으로 취급하지 않는다.

검증 질문도 나눈다.

- **값의 일치:** 제시된 생성 절차가 표준에 적힌 공개 seed를 다시 만드는가?
- **선택의 설명:** 가능한 후보 중 특정 후보를 선택하거나 건너뛴 이유까지 확인됐는가?
- **보안성:** 알려진 공격, 구현과 키 관리까지 포함해 안전성을 평가했는가?

첫 질문에 답했다고 나머지 질문까지 해결되지는 않는다.

## 공개 seed 재현 사례

2026-10-16 공개된 NIST 곡선 seed 연구에서 P-256의 20바이트 후보 생성은 `srand48(871696354)`로 초기화한 뒤 `lrand48() >> 23`의 결과를 20개씩 모으는 방식으로 설명된다. 초기값은 1997-08-16 01:52:34 UTC의 Unix timestamp다. 1부터 센 1,842번째 후보는 다음 표준 seed와 일치한다.

```text
C49D3608 86E70493 6A6678E1 139D26B7 819F7E90
```

2026-10-24에 공개된 생성식으로 이 후보를 계산하고 NIST SP 800-186의 P-256 Seed와 대조했다. 이 확인은 한 후보의 값 재현이며, 연구의 역추적 과정 전체나 곡선의 보안성을 독립 증명한 결과는 아니다.

2023-10-05 Filippo Valsorda가 내건 현상금은 seed가 영어 문장의 SHA-1 해시라는 소문을 전제로, 다섯 소수 차수 곡선의 원래 입력(pre-seed)을 찾는 조건이었다. 결과는 seed가 해시 출력이 아니라 PRNG 출력이었음을 보였다. Valsorda는 연구팀이 2026-10-15 01:07:51 UTC에 현상금을 청구했고, Let's Encrypt 운영 비영리 단체 ISRG에 기부해 금액이 36,864달러가 됐다고 발표했다.

## 생성기 상태를 출력에서 복원한다

POSIX는 drand48 계열을 48비트 정수 연산의 선형 합동 생성기로 정의한다. `srand48()`은 인자의 하위 32비트를 상태의 상위 32비트에 넣고 나머지 16비트를 고정값 `0x330E`로 채우며, `lrand48()`은 [0, 2^31) 범위의 정수를 돌려준다. Unix timestamp로 초기화하면 모르는 값은 사실상 그 시각뿐이므로, 상태를 복원하면 생성 시각까지 거꾸로 찾을 수 있다.

- **소수체 곡선:** `lrand48() >> 23`은 출력마다 1바이트만 남기므로 seed 바이트는 상태의 일부만 드러낸다. 연구는 잘린 출력에서 상태를 찾는 문제를 격자 문제로 바꾸어 LLL 기저 축약으로 풀었고, 어느 비트 구간이 드러났는지 몰라 모든 구간에 풀이를 돌렸다.
- **이진체 곡선:** 후보마다 32비트 단어 5개를 쓰고, 단어마다 최상위 비트가 0인 패턴이 31비트 출력과 맞았다. 첫 단어에 숨은 17비트의 2^17가지 값을 모두 넣어 보고 나머지 네 단어가 이어지는지 확인했다. 초기값을 그대로 읽으면 1984년 2월이고 두 배로 하면 1998-04-17이 되어, 연구는 프로그램이 시계 값을 반으로 나눴을 수 있다고 본다.

출력 일부만 공개돼도 선형 합동 생성기의 상태와 초기값이 복원된다는 점이 이 사례의 일반 교훈이다. 비밀이 필요한 난수에는 이런 생성기를 쓰지 않는다.

## 남은 선택 자유도로 조작 가설을 좁힌다

공개 파라미터의 조작 가능성은 생성 과정에서 결과를 고를 수 있었던 범위로 따진다. seed를 바꿔 가며 약한 곡선이 나올 때까지 시도하는 무작위 탐색이라면, 시도할 수 있는 후보 수가 노릴 수 있는 약점의 드문 정도를 정한다. Koblitz와 Menezes의 2015년 논문 3.1절은 이 경로를 이렇게 반박했다. 예를 들어 약점이 소수 차수 곡선의 2^-40을 덮는다면 약 2^48개 seed 시도로 약한 곡선을 얻을 수 있지만, 그만큼 흔한 약점이면 NSA만 아는 약한 곡선이 약 2^209개가 되어 학계가 그동안 찾지 못했을 가능성이 매우 낮다.

같은 논문의 2018년 개정판 Remark 1은 Bernstein과 Lange가 2017년에 설명한 다른 경로를 싣는다. 해시 출력의 절반은 곡선 계수로, 나머지 절반은 약한 곡선을 고르는 난수로 써서 두 집합 사이에 소수인 군 차수가 같은 쌍을 찾고(생일 충돌), 차수가 같은 두 곡선의 동종 사상(isogeny) 류 안에서 무작위 보행으로 곡선 자체가 같아지는 충돌을 찾는 방식이다. 이 경로에서는 약점이 흔할 필요 없이 약한 소수 차수 곡선이 2^61개 이상이면 된다(정확히는 그 군 차수가 Hasse 구간의 소수 약 2^122개 중 2^61개 이상을 덮어야 한다). 군 차수가 소수일 확률이 약 2^-8이므로 약 2^70개 곡선을 탐색해야 한다. 저자들은 난이도를 과장했다는 비판은 타당하다고 인정하면서도, 이 절차에 최소 2^86 비트 연산이 들어 1997년 NSA의 역량 밖이었을 것이고 학계가 모르는 그런 약한 곡선 류를 NSA가 알았을 가능성도 매우 낮다고 평가했다. Valsorda의 2026-10-16 글은 이를 seed 선택의 70비트 자유도로 가상의 약한 소수 차수 곡선 2^61개 류를 겨냥할 수 있었던 기법으로 요약한다.

이번 결과에서 Valsorda는 1997~98년의 아무 timestamp와 소수 차수 후보 중 처음 16개 중 아무것이나 고를 수 있었다고 넉넉히 가정해도 자유도가 30비트 남짓이라고 추정한다. 설명되지 않은 탈락은 이 넉넉한 가정에 포함했다. 2년치 초 단위 timestamp 약 6,300만 개(약 2^26)와 후보 16개(2^4)를 곱하면 약 2^30이다. 이는 위 충돌 탐색에 필요한 약 2^70개 곡선에 크게 못 미치고, 약 2^30개 소수 차수 후보 중에서 약한 곡선을 하나 고르려면 약점이 소수 차수 곡선의 약 2^-30 이상을 덮어야 한다(둘 다 이 문서의 계산).

Valsorda는 이 자유도로는 Bernstein과 Lange의 기법도, 한 당사자만 악용할 수 있는 NOBUS(nobody but us) 백도어도 심을 수 없다고 본다. 30비트는 저자의 추정이며, 모든 형태의 조작이 불가능했다는 증명은 아니다.

## 재현 뒤에도 남는 질문

- P-256에서는 더 이른 876번째 후보도 조건에 맞는 곡선을 만들지만 건너뛴 이유는 확인되지 않았다.
- Valsorda 글은 ANSI X9.62 조건 외에 문서화되지 않은 기준이 둘 있다고 본다. 곡선 차수 n의 비트 길이가 기반체 p의 비트 길이를 넘으면 버리는 기준은 비교적 분명하다(prime239v2는 p < n < 2^239이므로 엄격한 n < p 검사는 아니다). 다른 하나는 아직 설명되지 않았고, 알려진 기준을 적용해도 유효한 seed가 공개된 것의 약 두 배 남는다.
- P-224, P-256, P-384와 P-521의 기준점 생성 방법은 해당 연구에서 미해결로 남았다. Valsorda 글의 추신은 이진체 B 곡선 seed의 생성 방식도 밝혀졌다고 적지만, Anthropic 연구 페이지는 B-233, B-283, B-409, B-571만 설명하고 B-163을 미해결로 둔다.
- 공개된 값만으로 과거에 생성기를 몇 번 실행했는지 알 수 없다.

따라서 생성 경로의 투명성이 높아졌다는 결과를 모든 백도어 가능성의 부재 증명으로 확대하지 않는다. 반대로 예측 가능한 생성기로 공개 seed를 재현했다는 사실을 개인키 난수 생성에도 같은 방식을 써도 된다는 권고로 해석하지 않는다. 변경 판단에서는 공개 파라미터의 출처, 실제 취약점과 구현의 키 관리 문제를 분리한다.

Valsorda는 이 결과 뒤 NIST 곡선을 Curve25519, Ed25519, X25519보다 개인적으로 권한다고 썼다. 개인 견해이므로 곡선 선택 규칙으로 옮기지 않고, 프로토콜 표준, 라이브러리 구현과 양자내성 전환 계획으로 판단한다(이 문서의 해석).
