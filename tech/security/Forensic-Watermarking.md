# 포렌식 워터마킹과 콘텐츠 유출 추적

포렌식 워터마킹은 콘텐츠에 식별 신호를 삽입하고, 나중에 확보한 사본에서 그 신호를 검출해 배포 경로를 조사하는 방법이다. 비가시성 워터마크는 사람이 쉽게 알아채지 못하도록 넣는다. 사본에 추적 신호를 남기는 기능을 복제 자체를 차단하는 기능과 구분한다.

## 배포와 검출의 연결

기본 흐름은 원본 준비, 식별값 삽입, 배포, 의심 사본 확보, 검출과 기록 대조다. 같은 콘텐츠라도 전달 대상별 배포본을 구분할 수 있어야 어느 배포 경로에서 나온 사본인지 조사할 수 있다.

다음은 서비스 설계 제안이다.

- 콘텐츠 버전과 배포본에 대응하는 불투명한 식별값을 사용하고, 실제 수신 대상과의 대응표는 접근을 제한한다.
- 삽입 요청 성공과 워터마크가 들어간 결과 파일의 준비 완료를 구분한다. 배포 직전 표본 검출로 잘못된 파일을 전달하지 않는지 확인한다.
- 검출된 식별값은 배포 기록과 대조한다. 계정 공유나 전달 경로가 더 있을 수 있으므로 특정 배포본과의 연결만으로 사람의 행위를 단정하지 않는다.
- 검출 실패는 추적 신호를 찾지 못한 결과로 남긴다. 누가 배포했는지 또는 허용된 사용인지를 반대로 증명하는 근거로 쓰지 않는다.

## 품질과 변형 내성을 따로 평가한다

눈에 잘 보이지 않는다는 성질과 편집 후에도 검출된다는 성질은 별도다. SaForus의 공개 제품 설명은 압축, 자르기와 부분 편집 뒤 검출을 제시하지만, 모든 파일과 변환에 대한 성공률로 일반화하지 않는다.

도입 시험에서는 다음을 따로 측정한다(검증 제안).

| 축 | 표본과 확인 항목 |
| --- | --- |
| 품질 | 단순한 배경과 복잡한 장면 모두에서 삽입 전후를 비교 |
| 변형 내성 | 압축, 리사이즈, 잘라내기와 재촬영 조건을 분리 |
| 오탐과 미탐 | 표시한 파일뿐 아니라 표시하지 않은 파일도 함께 검사 |
| 처리 비용 | 업로드, 삽입, 결과 수신과 검출의 지연 및 자원 사용 |
| 추적 정확성 | 검출 ID가 해당 콘텐츠와 실제 배포 기록에 대응하는지 확인 |

발표의 화질 수치나 GPU 처리 시간을 일반적인 합격 기준으로 옮기지 않는다. 실제 콘텐츠와 장비, 해상도 및 변형 조건을 고정한 표본으로 판단한다.

## 제품 소개와 실제 통합 범위

2026-10-22 SaForus 공개 홈페이지는 비가시성 워터마킹의 매체로 이미지, 영상, 오디오와 PDF를 소개하지만, 같은 페이지의 업로드 절차는 이미지와 PDF를 명시한다. 기술 전체의 활용 범위와 특정 웹 기능 또는 API에서 바로 처리할 수 있는 형식을 구분한다.

API 통합을 결정할 때는 대상 형식, 크기, 비동기 완료 상태와 검출 경로를 별도로 확인한다. 이 문서는 공개 제품 설명과 발표를 대조했으며 실제 삽입, 검출 성능이나 API 계약 전체를 시험하지 않았다. 생성형 AI 출처 신호는 [[AI-Content-Provenance|AI 콘텐츠 출처 증명]]에서 별도로 다룬다.
