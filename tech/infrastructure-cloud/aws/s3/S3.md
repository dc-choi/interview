# Amazon S3 (Simple Storage Service)

AWS 객체 스토리지. **사실상의 글로벌 표준** — 데이터레이크, 정적 자산, 백업, 아카이브의 기본 저장소. 11 9s 내구성과 강한 일관성을 제공.
