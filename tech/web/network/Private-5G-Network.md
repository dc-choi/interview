# 5G 특화망 (이음5G, Private 5G)

5G 특화망은 건물이나 토지처럼 정해진 구역 안에서만 무선국을 구축하고 운영하는 5G 망이다(과학기술정보통신부 2021-10-28 할당공고의 정의). 한국에서는 이음5G라고 부르며, 통신사가 아닌 기업과 기관도 주파수를 받아 자기 망을 만든다. 이 문서는 공장에서 Wi-Fi나 유선 대신 특화망을 고르는 조건, 코어와 엣지의 배치, 여러 사이트가 코어를 나눠 쓰는 모델, 한국의 주파수 제도와 도입 절차를 다룬다. 인증과 키 계층은 [[5G-Security-Architecture|5G 보안 구조]], 기지국 사이 이동과 IP 유지는 [[Self-Organizing-Network|SON과 무선 자원 관리]]를 따른다.

## 3GPP의 비공중망 두 형태

3GPP Release 16의 Vertical_LAN 작업은 산업용으로 세 가지를 넣었다. 5G 시스템을 IEEE TSN(Time Sensitive Networking)의 브리지로 통합하는 기능, 비공중망(Non-Public Network, NPN), 5G-LAN형 서비스다. NPN은 두 형태로 구축한다.

| 형태 | 정의 | 운영 관점(해석) |
|---|---|---|
| SNPN(Stand-alone NPN) | NPN 운영자가 운영하고 공중망(PLMN)의 네트워크 기능에 의존하지 않는다. PLMN ID와 NID의 조합으로 식별한다 | 데이터와 운영을 직접 통제하는 대신 코어 운영 책임을 진다 |
| PNI-NPN(Public network integrated NPN) | 공중망의 지원을 받아 구축한다 | 운영 부담을 덜지만 공중망의 장애와 정책에 묶인다 |

자기 코어를 두는 이음5G 구축은 SNPN에 가깝다(해석). 한국 제도의 할당과 지정은 주파수를 누가 어떤 조건으로 쓰는지의 구분이고 3GPP의 NPN 분류와 일대일로 대응하지 않는다.

## 공장 무선에 요구되는 것

- **이동 중 연결 유지:** AGV, AMR, 순찰 로봇처럼 움직이는 장비는 셀이나 AP 사이를 옮겨 다닌다.
- **상향 위주 트래픽:** 영상과 센서 데이터를 서버로 올리는 양이 내려받는 양보다 크다.
- **지연의 일정함:** 지연의 절대값보다 지연과 지터가 기대 범위 안에 머무는지가 정밀 제어와 후공정을 좌우한다. 지터 지표는 [[Network-Quality-Metrics|네트워크 품질 지표]]를 따른다.
- **많은 단말과 데이터의 위치:** 센서와 설비를 한 망에 붙이면서 생산 데이터를 사내에 두어야 한다.

3GPP는 5G Time Sensitive Communication을 결정적이거나 등시적인 통신을 높은 신뢰도와 가용성으로 지원하는 서비스로 정의하고, 지연 상한과 신뢰도 같은 QoS로 패킷을 나른다고 설명한다. TSN 시각 동기에서는 5G 시스템 전체를 하나의 IEEE 802.1AS 시간 인식 시스템으로 보고, 가장자리의 TSN 변환기(TT)만 802.1AS를 처리한다. URLLC의 예로 공정 자동화 원격 제어에 99.9999% 신뢰도, 최대 100Mbps의 사용자 체감 속도와 50ms의 종단 간 지연을 들며 이를 특히 엣지 컴퓨팅으로 제공한다고 적는다.

### 기존 방식과 비교

2026년 9월 특화망 공급사 발표의 비교를 정리했다. 장점 칸 가운데 산업용 프로토콜의 현장 제어 적합성과 Wi-Fi의 넓은 단말 생태계는 발표에 없어 보충했다.

| 방식 | 장점 | 한계 |
|---|---|---|
| 산업용 프로토콜 | 현장 제어에 맞춰져 있다 | 배선에 묶여 이동이 안 되고 벤더별 독자 규격이 많으며 대용량 전송에 맞지 않는다. 인증과 암호화는 개선 중이다 |
| 유선 TCP/IP | 인증과 암호화 체계가 성숙했다 | 이동이 안 되고 배치를 바꾸거나 늘릴 때마다 배선 비용이 든다 |
| Wi-Fi | 이동할 수 있고 단말 생태계가 넓다 | 범위가 좁고 실내 위주이며 채널 경쟁으로 지연이 불규칙하다. 간섭과 인증이 취약해 보안 부가 솔루션 비용이 든다 |

같은 발표는 학회 논문을 인용해 Wi-Fi 로밍 중 지연과 로밍 실패가 비계획 생산 중단의 대부분을 차지한 공장 사례를 들었다(원 논문은 대조하지 않았다).

이 비교는 특화망 공급사의 관점이다. Wi-Fi 6 이후의 OFDMA 스케줄링과 6GHz 대역은 혼잡과 지연 문제를 줄인다([[WiFi-Generations|Wi-Fi 세대]], [[Wireless-Multiple-Access|무선 다중접속]]). 선택은 기술 세대가 아니라 실제 이동 경로와 혼잡 시간에 측정한 지터, 핸드오버 중 끊김, 상향 용량과 망을 운영할 인력으로 한다(설계 판단).

발표는 특화망의 수요를 Physical AI로도 설명한다. 인지, 판단, 실행을 묶은 로봇과 에이전트는 상향 위주 트래픽을 버퍼링 없이 확정적으로 보내야 한다는 논지다([[Physical-AI-and-Liquid-Control|Physical AI]]).

## 구성: 코어, 기지국, 엣지를 어디에 두는가

- **5G 코어:** 제어 계층의 AMF가 단말과 기지국의 접속과 이동성을, SMF가 세션을 관리하고, UPF가 사용자 데이터를 나른다(3GPP 5G System Overview).
- **UPF와 엣지 서버:** UPF를 공장 안에 두면 사용자 데이터가 공장 밖으로 나가지 않고 경로가 짧아진다. 그 옆에 GPU 서버를 두면 영상 분석 같은 추론을 현장에서 처리한다.
- **기지국:** 발표의 구성도는 기지국을 DU와 RU로 표기해 현장에 두고, 전국 확산 모델의 구성도에서는 CU를 UPF와 함께(UPF/CU) 표기한다.

발표의 구성 예는 구성도 한 장이다. 공장 1에는 제어와 사용자 계층을 모두 갖춘 코어(CP+UP)와 GPU 엣지, 기지국(DU, RU)을 두고, 공장 1과 연결된 공장 2에는 사용자 계층 코어(UP)와 GPU 엣지, 기지국만 둔다. 엣지와 클라우드의 데이터 흐름은 [[IoT-Edge-Cloud-Pipeline|IoT 엣지와 클라우드 파이프라인]]을 따른다.

## 여러 사이트가 코어를 나눠 쓰는 모델

산업단지처럼 작은 사업장이 모인 곳에서는 사업장마다 코어를 두기 어렵다. 2026년 9월 발표는 춘천 산업단지 사례를 세 단계로 제시했다.

1. **기반 구축:** 거점 산단(후평)과 바이오 선도 공장을 대상으로 특화망 코어를 구축하고 발효와 추출 공정의 IoT와 영상을 실증했다(확산 구성도에서 코어는 후평에 있다).
2. **서비스 연계:** 거점 산단에 통합 관제를 두고 자율주행 순찰 로봇, CCTV 통합 관제와 공유 물류 플랫폼을 붙였다.
3. **코어 공유형 확산(발표 시점의 신규 사업):** 거점의 이중화한 코어를 공유하고, 연계 산단(물류, 관제와 에너지, 바이오 AX)에는 UPF와 기지국, 엣지만 더해 4K CCTV, 순찰 로봇, 무인 지게차, IoT 센서와 디지털 트윈을 붙이는 구성이다.

발표는 기존 코어를 공유하면 연계 산단의 비용이 30% 줄어든다고 했지만 비교 기준은 제시하지 않았다. 전국 확산 모델로는 본부(대구)의 자체 데이터센터나 클라우드에 코어를 두고 지역 산단 통신실에는 UPF와 엣지만 두어 입주사가 별도 코어나 데이터센터 없이 쓰는 구조, 일부 지역에는 지역 코어를 두는 구조를 함께 제시했다.

이 모델의 트레이드오프는 다음과 같다(설계 판단).

- **장애 범위:** 등록과 세션 관리를 중앙의 제어 기능이 맡으므로 중앙 코어와 사이트를 잇는 회선이 모든 사이트의 장애 범위에 들어간다. 연결이 끊겼을 때 기존 세션, 새 접속과 이동이 각각 어떻게 되는지 제품별로 시험하고, 코어와 회선의 이중화, 지역 코어를 둘 기준을 정한다.
- **입주사 분리:** 한 코어를 여러 입주사가 쓰면 데이터 경로, 관제 화면과 장애 공지의 범위를 입주사별로 나눈다.
- **운영 책임:** 주파수를 받은 주체가 망 운영자다. 장애 대응, 보안 점검과 무선국 운용 의무를 누가 지는지 계약으로 정한다.

## 한국의 이음5G 제도

2026-11-23에 대조했다. 주파수, 신청 자격, 이용기간과 개설 의무는 과학기술정보통신부의 2021-10-28 할당공고 기준이며 이후 개정 공고는 대조하지 못했다. 절차, 심사 기간과 공급 현황은 한국방송통신전파진흥원(KCA) 안내 기준이다.

- **주파수(2021-10-28 할당공고 기준):** 4.7GHz 대역 4.72~4.82GHz의 100MHz 폭(10MHz 10개 블록), 28GHz 대역 28.9~29.5GHz의 600MHz 폭(50MHz 12개 블록)이다. 기술 방식은 ITU가 채택한 IMT-2020과 이후 진화 기술이다. 현행 공고의 대역과 조건은 신청 전에 원문으로 다시 확인한다.
- **할당 경로(2021-10-28 할당공고 기준):** 기간통신사업(회선설비 보유 무선사업)을 등록했거나 등록을 신청한 자가 과기정통부에 주파수 할당과 사업 등록을 신청한다. 경매가 아닌 대가 할당이고, 이용기간은 2~5년에서 고르며, 할당일로부터 1년 안에 무선국을 개설해야 한다. 같은 대역의 다른 특화망 이용자와 공동 사용 지침을 지키고 인접 대역 간섭은 시설자끼리 협의해 해결한다. 이 공고는 이동통신용 주파수를 이미 할당받은 자를 신청 대상에서 뺐다.
- **할당 절차(KCA 안내):** 할당심사위원회가 신청일로부터 1개월 안에 심사한다. 할당 뒤 중앙전파관리소에 무선국 개설을 신고하고 KCA가 무선국을 검사하며, 할당 조건에 따른 개설 규모를 점검한다. 갱신은 재할당이다.
- **지정 경로(KCA 안내):** 자가전기통신설비(자가망) 설치자가 과기정통부(전파관리소)에 무선국 개설허가를 신청하면 14일 안에 지정 심사를 하고, 주파수 지정과 동시에 무선국 개설을 허가한다. 갱신은 무선국 재허가(통상 5년 주기)다. KCA 안내의 수요자 유형 칸은 국가, 지자체와 공공기관의 자가망 설치 희망자이지만, 2021-06-29 공급방안 발표는 자가망으로 무선국을 설치하는 경우를 대상 구분 없이 지정 방식으로 설명했다. 민간 기업이 이 경로로 신청할 수 있는지는 저장한 자료로 확정하지 못해 확인이 필요하다(전파관리소나 현행 고시).
- **할당 대가(2021-06-29 발표):** 토지와 건물 면적을 기준으로 하고 인구 50만 명 이상 대도시와 그 밖의 지역을 구분한다. 28GHz 대역은 장비와 단말 생태계를 고려해 4.7GHz의 10분의 1 수준으로 낮게 정했다. 이 비율은 같은 대역폭 기준이고, 2021-10-28 공고의 면적 1㎢, 1년, 1블록당 기준금액은 4.7GHz(10MHz 블록) 100,000원, 28GHz(50MHz 블록) 50,000원이라 블록당으로는 2분의 1이다.
- **공급 현황:** 2025년 말 기준 39개 시설자, 104개소다(KCA).

## 도입 절차

2026년 9월 발표의 구축 절차를 일반화했다.

1. **요구사항:** 서비스 영역, 단말 수, 상향과 하향 용량, 지연과 지터 목표, 이동 경로와 사용할 대역을 정한다.
2. **설계:** 링크 버짓으로 커버리지와 용량을 계산하고, 현장 실사로 안테나 설치 위치와 도면, 무선 환경을 확인한다. 전파를 측정해 전파 모델을 보정하고 커버리지 시뮬레이션으로 기지국 위치를 고른다.
3. **제도:** 할당이나 지정을 신청하고, 할당 경로면 기간통신사업 등록 서류를 준비한다.
4. **구축과 시험:** 장비를 설치하고 단위 시험과 통합 시험, 고정점 시험과 이동 시험으로 현장 품질을 잰다.
5. **최적화:** 파라미터를 조정해 커버리지와 핸드오버를 개선하고 최적화 전후의 KPI를 비교한다.
6. **검사와 운영:** 무선국 검사를 받은 뒤 운영과 유지보수로 넘긴다.

공장 무선의 문제는 주로 이동 중과 혼잡 시간에 드러나므로 고정점 시험만으로 인수하지 않는다. 실제 이동 경로와 교대 시간 부하에서 지터와 핸드오버 끊김을 측정해 인수 기준으로 쓴다(설계 판단).

## 사례: 체외진단 키트 공장 (공단과 공급사 발표)

한국산업단지공단과 삼성SDS의 발표가 든 사례다. 춘천 거두산업단지의 체외진단 키트 제조사는 카트리지 공정 데이터를 중앙 시스템 연동 없이 작업자가 수기로 모았고, 라인 가동률이 85.0% 수준에서 정체했다. 바이오와 식품 공정은 GMP, GDP, HACCP처럼 온습도와 이력까지 남겨야 하므로 무선 끊김이 곧 품질 데이터 유실이라는 것이 도입 이유였다. 발표 슬라이드는 핵심 설비 17대의 실시간 연계(설비 실시간 연계율 60% 이상), 불량 타임라인을 분석한 예지보전과 임계값을 벗어난 자재의 공정 투입을 막는 수입검사 자동화를 들며 라인 가동률 85.0%에서 90.0%, 원자재 손실률 5.0%에서 4.5%라는 수치를 제시했다. 측정된 실적인지 목표인지, 측정 기간과 비교 기준, 네트워크 외 개선 요인의 분리는 밝히지 않았다. 같은 발표는 거두 산단을 3단계 확산(신규 사업) 대상으로 두어, 발표 시점에 이 수치가 측정됐는지도 확인되지 않는다.

## 점검 항목

- 이동, 지터, 상향 용량과 단말 수를 측정해 특화망이 필요한 요구인지 확인했는가
- 코어의 위치와 이중화, 중앙과의 연결이 끊긴 사이트의 동작을 시험했는가
- UPF와 엣지 서버의 위치로 데이터가 어디까지 나가는지 정했는가
- 할당과 지정 중 어느 경로인지 현행 공고와 전파관리소로 확인하고(지정 경로의 민간 신청 가능 여부 포함), 이용기간과 무선국 개설 의무 일정을 계획에 넣었는가
- 단말과 산업용 모뎀이 받은 대역을 지원하는가
- 망 운영자로서 장애 대응, 보안 점검과 무선국 운용 책임의 주체가 정해졌는가
