# React Native

React의 component와 state 모델로 Android/iOS의 네이티브 UI를 구성하는 기술이다. React 공통 개념은 [[React]], Expo 프레임워크와 배포 선택은 [[Expo]]에 연결한다.

React Native 0.87의 가이드, 컴포넌트와 API를 주제별로 읽는다. 아키텍처 문서는 버전 없는 설명을 현재 구조와 대조하며 오래된 예제의 적용 조건은 해당 노트에서 구분한다.
