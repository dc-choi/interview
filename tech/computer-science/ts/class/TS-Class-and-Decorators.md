# TS 클래스와 데코레이터

클래스 선언이 값(생성자)과 인스턴스 타입을 함께 만드는 구조, 그리고 그 정의를 관찰하거나 교체하는 데코레이터를 함께 둔다. 접근 제어자, implements, 데코레이터 실습 코드는 같은 폴더의 `.mts`, `.mjs` 파일에 있다.

- [[TS-Class-Type-System|TS 클래스 타입 시스템]]: 클래스가 만드는 값과 인스턴스 타입, 구조적 호환성의 예외, 접근 제어자의 실행 시점, implements와 parameter property
- [[TS-Decorators|TS 데코레이터]]: proposal decorator와 legacy 방식의 차이, metadata, 클래스/method/property 데코레이터 선택 기준
