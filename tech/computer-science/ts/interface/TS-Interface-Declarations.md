# TS 인터페이스 선언과 병합

객체 형태를 interface로 선언할지 type alias로 선언할지, 그리고 이미 선언된 타입에 멤버를 덧붙이는 선언 병합과 module, global augmentation을 다룬다. 선언 병합과 extends 실습 코드는 같은 폴더의 `.mts` 파일에 있다.

- [[TS-Type-vs-Interface|type vs interface]]: 선언 병합, 유니온과 튜플, 확장 방식과 컴파일 성능 차이, 선택 가이드
- [[TS-Module-Augmentation|Module Augmentation]]: Declaration Merging, declare module, declare global, `.d.ts`와 Express Request 확장 실전 예
