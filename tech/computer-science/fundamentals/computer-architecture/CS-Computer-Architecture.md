# 컴퓨터 구조: 논리회로, 메모리, CPU

불 대수와 게이트로 만든 조합회로와 ALU에서 출발해, 이전 상태를 기억하는 순차회로와 메모리를 거쳐, 명령어를 가져와 해석하고 실행하는 CPU 데이터패스와 제어장치로 올라간다. 마지막 문서는 단순한 교육용 CPU에서 명령을 단계별 제어 신호로 추적한다.
