# 신뢰구간과 표준오차

표본평균은 관측한 데이터의 평균이며 모집단 평균의 추정값이다. 같은 모집단에서 같은 크기의 표본을 다시 뽑아도 표본평균은 달라질 수 있다. 관측값의 퍼짐과 추정값의 불확실성을 구분해야 한다.

## 원자료와 표본평균의 분포

- **원자료의 분포:** 개별 관측값이 어떻게 퍼져 있는가.
- **표본평균의 표집분포:** 같은 표집 절차를 반복할 때 표본평균이 어떻게 달라지는가.

독립이고 동일한 분포를 따르며 유한한 평균과 양의 유한한 분산을 가진 표본에서는, 표본 수가 커질수록 표준화한 표본평균의 분포가 표준정규분포에 가까워진다. 이것이 중심극한정리의 기본 형태다. 원자료 자체가 정규분포로 바뀐다는 뜻은 아니다. 필요한 표본 크기는 원자료의 분포에 따라 달라지므로 특정 개수를 보편적 통과 기준으로 쓰지 않는다.

## SD와 SE

표준편차(SD)는 관측값의 퍼짐을, 표준오차(SE)는 추정량의 표집분포가 얼마나 퍼지는지를 나타낸다. 위의 독립, 동일 분포 조건에서 모집단 표준편차가 `σ`이면 표본평균의 표준오차는 `σ / sqrt(n)`이다. `σ`를 모르면 표본 표준편차 `s`로 대체해 추정한다.

| 표본평균의 SE 추정 예 | 계산 | 결과 |
|---|---|---|
| `s = 2`, `n = 25` | `2 / sqrt(25)` | 0.4 |
| `s = 2`, `n = 100` | `2 / sqrt(100)` | 0.2 |

같은 표준편차를 가정하면 표본 수를 네 배로 늘려야 SE가 절반이 된다. 같은 사용자의 반복 클릭처럼 관측끼리 의존하면 행 수를 그대로 독립 표본 수로 넣지 않는다. 분석 단위는 [[Recommendation-System-Online-Experimentation-Statistics#Randomization 단위와 분석 단위|온라인 실험의 표본 단위]]와 함께 정한다.

## 95%가 설명하는 것은 구간 생성 절차다

빈도주의 신뢰구간에서 모집단 평균은 고정되어 있고 표본에서 계산한 구간이 달라진다. 가정이 맞는 표집과 구간 계산을 반복할 때, 생성된 구간 중 장기적으로 약 95%가 참평균을 포함하는 절차라는 뜻이다. 이미 계산된 특정 구간에 참평균이 들어 있을 확률이 95%라는 해석과 구분한다.

정규 모집단에서 독립 표본을 뽑고 모집단 분산을 모를 때, 평균의 양측 신뢰구간은 다음과 같다.

`x̄ ± t_(1-α/2, n-1) × s / sqrt(n)`

신뢰수준은 `1-α`, 자유도는 `n-1`이다. 같은 표본과 계산 방식에서 신뢰수준을 높이면 구간이 넓어진다. 좁은 구간은 가정 아래의 정밀도를 뜻하며, 표본 선택이 편향되지 않았다는 증거는 아니다. 평균의 신뢰구간을 개별 관측값의 95%가 들어갈 범위로 읽지도 않는다.

## 부트스트랩은 관측한 값을 다시 뽑는다

기본 비모수 부트스트랩은 확보한 표본에서 관측값을 복원 추출하고 매번 관심 통계량을 다시 계산한다. 같은 값이 여러 번 뽑히거나 한 번도 뽑히지 않을 수 있다. 이는 동일한 사람을 다시 조사하는 절차가 아니다.

이렇게 얻은 통계량의 분포로 불확실성을 추정한다. 재표집 횟수를 늘려도 원표본에 없던 집단이나 관측이 새로 생기지는 않는다. 모든 통계량에 같은 방식이 적합한 것도 아니다. 예를 들어 균등분포의 범위처럼 꼬리에 크게 의존하는 통계량은 기본 부트스트랩 적용에 주의한다.

## 이해 확인

1. `s = 3`을 유지하면서 표본 수가 36에서 144로 늘면 SE 추정값은 어떻게 변하는가?
2. 95% 신뢰구간이 개별 관측값의 95%를 포함한다는 설명은 왜 잘못됐는가?
3. 재표집을 만 번 했다는 사실만으로 원표본의 대표성이 좋아졌다고 할 수 있는가?
