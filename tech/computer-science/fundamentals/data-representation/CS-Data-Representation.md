# 데이터 표현: 비트, 인코딩, 무결성 검사

같은 비트열도 비트 폭, 부호 여부, 인코딩과 바이트 순서에 따라 다른 값이 된다. 숫자, 문자와 미디어를 비트로 나타내는 규칙에서 출발해 바이너리를 문자만 받는 필드로 옮기는 Base64, 임의 길이의 데이터를 짧은 고정 길이 값으로 요약해 다시 계산하고 비교하는 체크섬, CRC와 해시로 이어진다.
