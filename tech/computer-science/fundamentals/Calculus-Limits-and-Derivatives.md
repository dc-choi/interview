# 미분: 극한, 연속과 도함수

미적분은 두 질문을 다룬다. 지금 얼마나 빠르게 변하고 있는가(미분)와 그 변화가 구간 동안 얼마나 쌓였는가(적분)다. 이 문서는 미분 쪽을 평균 변화율, 극한, 연속, 도함수, 평균값 정리, 미분 규칙과 최적화 순서로 정리한다. 적분과 두 질문을 잇는 기본정리는 [[Calculus-Integrals-and-Fundamental-Theorem|적분: 리만 합, 정적분과 미적분의 기본정리]]에 있다.

## 평균 변화율에서 순간 변화율로

함수는 입력 하나에 출력 하나를 대응시키는 규칙이다. 서로 다른 입력이 같은 출력을 가져도 되지만(`(−2)² = 2² = 4`), 같은 입력이 두 출력으로 갈라지면 함수가 아니다. `f(2) = 4`는 입력 2의 출력이 4라는 뜻이지 f와 2의 곱이 아니다.

구간 `[a, b]`의 평균 변화율은 `(f(b) − f(a)) / (b − a)`이고, 그래프에서는 두 점을 잇는 할선의 기울기다. 분자와 분모의 순서를 함께 뒤집으면 값이 같고 한쪽만 뒤집으면 부호가 바뀐다. 기울기의 단위는 세로축 단위를 가로축 단위로 나눈 것이라, 세로축이 위치(m)이고 가로축이 시간(s)일 때 기울기가 속도(m/s)가 된다. 축에 무엇을 놓았는지에 따라 기울기의 뜻이 달라진다.

위치가 `s(t) = t²`(m)인 물체는 1, 2, 3초에 1, 4, 9 m에 있고, 시간이 2배가 되면 위치는 4배가 된다. 1초에서 3초 사이 평균 속도는 `(9 − 1) / (3 − 1) = 4` m/s다. 평균은 구간 전체를 한 수로 요약할 뿐이라 그동안 같은 속도로 움직였다는 뜻이 아니다.

한 시각의 순간 변화율을 얻으려면 구간을 줄여야 하지만, 두 시각을 처음부터 같게 두면 `0 / 0`이 된다. 나눗셈 `a / b = c`는 `c × b = a`인 c를 찾는 일인데, b = 0이면 a ≠ 0일 때는 그런 c가 없고 `0 / 0`이면 모든 수가 맞아 답 하나를 정할 수 없다. 그래서 간격을 0이 아닌 채로 줄여 가며 비가 어디로 향하는지를 묻는 극한이 필요하다.

## 극한

`lim_{x→a} f(x) = L`은 x가 a와 다른 값을 유지하며 a에 가까워질 때 `f(x)`가 L에 원하는 만큼 가까워진다는 뜻이다. 정밀한 정의는 다음과 같다. 모든 `ε > 0`에 대해 어떤 `δ > 0`이 있어서 `0 < |x − a| < δ`이면 `|f(x) − L| < ε`이다.

- `0 < |x − a|` 조건 때문에 극한은 a에서의 함숫값을 보지 않는다. 화살표는 등호가 아니라 다가가는 과정이다.
- `f(x) = x + 1`에서 x가 1.9, 1.99, 2.001로 2에 다가가면 출력은 2.9, 2.99, 3.001로 3에 다가간다. 입력 오차가 그대로 출력 오차라 `δ = ε`로 잡으면 정의가 성립한다. 값 몇 개를 표로 계산한 것은 증거일 뿐 증명이 아니다([[Math-Logic-For-Programming|작은 사례와 증명의 구분]]).
- 한쪽 극한 `x → a⁻`와 `x → a⁺`의 위첨자 −, +는 a보다 작은 쪽과 큰 쪽에서 다가간다는 방향이지 답의 부호가 아니다. 양쪽 극한이 모두 있고 같을 때만 극한이 있다. 왼쪽에서 1, 오른쪽에서 3으로 향하면 a에 어떤 값을 찍어도 극한은 없다.
- 극한과 함숫값은 다른 질문이다. 직선 `x + 1`에서 x = 2의 점만 비우거나 그 점의 값을 1로 바꿔도 극한은 그대로 3이다.

`0 / 0` 꼴은 극한이 없다는 결론이 아니라 식의 구조를 더 보라는 신호다. `(x² − 1) / (x − 1)`은 x = 1에서 정의되지 않지만 `x² − 1 = (x − 1)(x + 1)`이고, `x ≠ 1`인 주변에서는 공통인수를 약분해 `x + 1`과 같다. 극한은 그 주변만 보므로 `lim_{x→1} (x² − 1) / (x − 1) = 2`다. 약분은 주변의 움직임을 알아내는 방법일 뿐 원래 함수의 x = 1에 값을 만들어 주지 않는다. 지울 수 있는 것은 곱해진 인수이고 그 인수가 0이 아닐 때뿐이며, 더해진 항을 지우는 것과는 다르다.

## 조임 정리와 연속

**조임 정리**(squeeze theorem, 샌드위치 정리): a를 포함한 열린 구간에서 a를 제외하고 `g(x) ≤ f(x) ≤ h(x)`이고 `lim g = lim h = L`이면 `lim_{x→a} f(x) = L`이다. 두 경계가 같은 값으로 모여야 하고, 부등식이 a 근처에서 실제로 성립해야 한다. 그림이 비슷해 보이는 것만으로는 쓸 수 없다. 아래의 `sin h / h → 1`과 적분의 기본정리 증명이 이 정리를 쓴다.

f가 a에서 **연속**이려면 세 조건이 모두 필요하다. `f(a)`가 정의되고, `lim_{x→a} f(x)`가 존재하고, 둘이 같아야 한다. 점이 비어 있으면 첫 조건이, 왼쪽과 오른쪽 극한이 다르면(점프) 둘째 조건이, 점이 다른 높이에 찍혀 있으면 셋째 조건이 깨진다. 구멍을 극한값으로 채우면 그 점에서 연속이 된다. 끊긴 이유를 조건별로 나누면 처방도 달라진다.

**사잇값 정리**(intermediate value theorem): f가 닫힌 구간 `[a, b]`에서 연속이고 N이 `f(a)`와 `f(b)` 사이의 값이면 `f(c) = N`인 c가 `[a, b]`에 적어도 하나 있다. 기온이 오전 10도에서 오후 20도로 끊기지 않고 변했다면 15도인 순간이 있었다. 이 정리는 존재만 보장하고, c가 하나라거나 어디에 있는지는 알려 주지 않는다. 연속 조건이 없으면 중간값을 건너뛸 수 있다.

`f(a)`와 `f(b)`의 부호가 다르면 `(a, b)` 안에 `f(c) = 0`인 근이 있다. 해를 구하기 전에 해가 있음을 아는 이 성질이 이분법(bisection)의 근거다. 구간 중점의 부호를 보고 부호가 바뀌는 절반을 남기면 n번 뒤 근을 담은 구간의 폭은 `(b − a) / 2ⁿ`이 되어, 폭 1에서 `10⁻⁶` 아래까지 20번이면 된다. [[Binary-Search-and-LIS|이분탐색]]과 같은 절반 버리기지만 판정의 근거가 정렬이 아니라 연속성이다. 연속이 아닌 `1/x`는 `[−1, 1]`의 양 끝에서 부호가 달라도 근이 없다.

## 도함수

a에서의 **미분계수**는 `f'(a) = lim_{h→0} (f(a + h) − f(a)) / h`이고, 이 극한이 있으면 f가 a에서 미분 가능하다고 한다. h는 두 입력 사이의 간격이며 양수 쪽과 음수 쪽 모두에서 같은 값으로 모여야 한다. 그래프에서는 a에서의 접선 기울기다. 미분 가능한 점은 그래프를 충분히 확대하면 직선처럼 보이는 점이고, 미분계수는 그 직선의 기울기다. 입력마다 미분계수를 모은 새 함수 `f'(x)`가 **도함수**다. `dy/dx`와 `d/dx f(x)`도 같은 대상을 가리키며 `d/dx`는 뒤의 함수를 x에 대해 미분하라는 연산이다. `dy/dx`는 처음부터 두 수 dy와 dx를 나눈 분수가 아니라 비의 극한을 적는 기호다.

`f(x) = x²`의 x = 2에서 간격 h인 할선 기울기는 `((2 + h)² − 4) / h = (4h + h²) / h = 4 + h`다(`h ≠ 0`이라 약분할 수 있다). h가 어느 쪽에서 0에 다가가도 4로 가므로 `f'(2) = 4`다. 같은 계산을 임의의 a에서 하면 `((a + h)² − a²) / h = 2a + h → 2a`라서 `(x²)' = 2x`다. 접선 기울기는 x = 1, 2, 3에서 2, 4, 6이고, x = 0에서는 접선이 수평이라 0, 음수 쪽에서는 음수다. 이 기울기들을 새 그래프의 높이로 옮기면 직선 `y = 2x`가 되고, 그것이 도함수의 그래프다.

`f(2) = 4`와 `f'(2) = 4`는 숫자가 같아도 뜻이 다르다. 앞의 4는 높이이고 뒤의 4는 그 점의 기울기다. 위치 `s = t²`에서 `s'(2) = 4` m/s가 2초 시점의 순간 속도다.

## 미분 가능성

`|x|`는 원점에서 끊기지 않지만 오른쪽 할선 기울기는 `|h| / h = 1`, 왼쪽은 `−1`이라 양쪽 극한이 달라 `f'(0)`이 없다. 연속이지만 미분 가능하지 않은 모서리이며, 아무리 확대해도 꺾여 있다. ReLU `max(0, x)`도 0에서 왼쪽 기울기 0, 오른쪽 기울기 1이라 같은 이유로 미분 가능하지 않다. `x^(1/3)`처럼 접선이 수직인 점도 기울기가 유한한 값으로 정해지지 않아 미분 가능하지 않다.

반대 방향은 성립한다. a에서 미분 가능하면 a에서 연속이다. 그러므로 미분 공식을 쓰기 전에 모서리, 점프, 구간의 끝, 조각별 정의의 경계처럼 공식이 성립하지 않는 점을 먼저 찾는다. 한쪽 기울기만 보고 접선이 있다고 판단하지 않는다.

## 평균값 정리

f가 `[a, b]`에서 연속이고 `(a, b)`에서 미분 가능하면 `f'(c) = (f(b) − f(a)) / (b − a)`인 c가 `(a, b)`에 적어도 하나 있다. 곡선을 따라 접선을 옮기면 어딘가에서 두 끝점을 잇는 할선과 평행해진다는 뜻이다. c가 하나뿐이라는 뜻은 아니다.

- `s = t²`의 `[1, 3]`에서 평균 속도 4 m/s와 같은 순간 속도 `2c = 4`는 c = 2에서 나온다. 2차 함수에서는 이 c가 언제나 구간의 중점이다.
- 한 시간 동안 평균 시속 60 km로 달렸다면, 위치가 끊기거나 꺾이지 않고 변하는 한 정확히 시속 60 km인 순간이 있었다.
- 조건이 빠지면 결론도 사라진다. `|x|`의 `[−1, 1]`에서 평균 기울기는 0이지만 기울기가 0인 점은 없다. 원점에서 미분 가능하지 않기 때문이다.

이 정리에서 따름정리가 나온다. 하나의 구간에서 `f'(x) = 0`이면 f는 그 구간에서 상수이고, 두 함수의 도함수가 한 구간에서 같으면 두 함수는 상수만큼만 다르다. 정의역이 끊겨 있으면 조각마다 다른 상수가 될 수 있다. x < 0에서 0, x > 0에서 1인 함수는 정의역 어디서나 도함수가 0이지만 상수가 아니다. 이 사실이 부정적분에 적분상수 C가 붙는 이유다.

## 미분 규칙

| 함수 | 도함수 | 조건과 메모 |
|---|---|---|
| 상수 `C` | `0` | 높이가 변하지 않는다 |
| `mx + b` | `m` | 직선은 어디서나 기울기가 같다 |
| `xⁿ` | `n x^(n−1)` | 양의 정수 n은 전개로 보인다. 다른 실수 지수로도 확장되지만 정의역 안에서만 쓴다(`√x`는 0에서 미분 가능하지 않다) |
| `f + g`, `k f` | `f' + g'`, `k f'` | 다항식을 항별로 미분하는 근거 |
| `f g` | `f' g + f g'` | 곱의 미분은 도함수의 곱이 아니다 |
| `f(g(x))` | `f'(g(x)) g'(x)` | 연쇄 법칙. g가 x에서, f가 `g(x)`에서 미분 가능할 때 |
| `sin x`, `cos x` | `cos x`, `−sin x` | x가 라디안일 때 |
| `eˣ`, `bˣ` | `eˣ`, `bˣ ln b` | `b > 0`, `b ≠ 1` |
| `ln x` | `1/x` | `x > 0` |

- `x³`은 `((x + h)³ − x³) / h = 3x² + 3xh + h²`이라 h → 0에서 `3x²`만 남는다. 양의 정수 n에서는 같은 전개가 `n x^(n−1)`을 준다.
- 곱의 규칙은 변이 u, v인 직사각형으로 볼 수 있다. 변이 Δu, Δv만큼 늘면 넓이는 `v Δu + u Δv + Δu Δv`만큼 는다. Δx로 나누고 극한을 취하면 모서리 조각 `Δu Δv / Δx`는 0으로 가고 두 띠만 남는다.
- 연쇄 법칙은 바깥 함수의 변화율에 안쪽 함수의 변화율을 곱한다. `(2x + 1)²`의 안쪽은 x보다 2배 빨리 변하므로 도함수는 `2(2x + 1) × 2 = 4(2x + 1)`이고, 전개한 `4x² + 4x + 1`을 미분한 `8x + 4`와 같다. `dy/dx = dy/du × du/dx`가 약분처럼 보이는 것은 표기의 장점이지 증명은 아니다.

### 사인과 코사인

반지름 1인 원에서 오른쪽 방향부터 반시계 방향으로 돈 각도를 x라 하면 원 위 점의 세로 좌표가 `sin x`, 가로 좌표가 `cos x`다. 미적분에서는 각도를 라디안으로 잰다. 단위원에서 각이 잘라 내는 호의 길이가 그 각의 라디안 값이라 한 바퀴는 `2π`, 반 바퀴는 `π`, 4분의 1바퀴는 `π/2`다. 사인 그래프의 가로축은 점의 가로 위치가 아니라 돈 각도다.

핵심 극한은 라디안에서 `lim_{h→0} sin h / h = 1`이다. `0 < h < π/2`에서 안쪽 삼각형, 부채꼴, 바깥쪽 삼각형의 넓이를 비교하면 `sin h < h < tan h`이고, 이를 정리하면 `cos h < sin h / h < 1`이다. 양쪽 경계가 1로 모이므로 조임 정리로 결론이 나온다. 실제로 `sin 0.1 / 0.1 ≈ 0.99833`이고 그 아래에 `cos 0.1 ≈ 0.99500`이 있다. 여기에 덧셈 정리 `sin(x + h) = sin x cos h + cos x sin h`와 `(cos h − 1) / h → 0`을 쓰면 `(sin x)' = cos x`가 나온다.

기하학적으로는 아주 작은 각 Δx만큼 돌 때 점이 반지름에 수직인 접선 방향으로 약 Δx 움직이고, 그중 세로 성분이 `cos x × Δx`라서 높이의 변화율이 `cos x`다. 꼭대기(`x = π/2`)에서 높이는 최대인데 기울기는 `cos(π/2) = 0`이다. 값이 크다는 것과 빠르게 변한다는 것은 다른 이야기다.

각을 도(degree)로 재면 `d/dx sin(x°) = (π/180) cos(x°) ≈ 0.01745 cos(x°)`로 계수가 붙는다. 입력 한 칸의 크기가 달라지면 기울기 숫자도 달라진다. 코드에서는 삼각함수가 받는 각도 단위부터 확인한다.

### 지수함수와 e

`2ˣ`은 입력이 1 늘 때마다 출력이 2배가 되는 함수다. 1씩 더하면 증가량이 일정하지만 2씩 곱하면 증가량 자체가 커진다(1에서 2로는 1, 4에서 8로는 4가 는다). 입력이 정수가 아닐 때도 같은 배율 규칙이 이어지도록 값을 정한다. 반 단계씩 두 번 곱해 2가 되어야 하므로 `2^(1/2) = √2 ≈ 1.414`다.

`(b^(x+h) − bˣ) / h = bˣ × (bʰ − 1) / h`에서 뒤의 비는 x와 무관한 상수로 수렴한다. 그래서 지수함수의 순간 증가율은 현재 값에 비례하고, 그 비례 상수가 `ln b`다. b = 2이면 `(2ʰ − 1) / h`가 h = 0.001에서 약 0.69339이고 극한은 `ln 2 ≈ 0.69315`다. 이 상수가 정확히 1이 되는 밑이 자연상수 `e ≈ 2.71828`이고, 그래서 `(eˣ)' = eˣ`다. x = 0에서 높이와 기울기가 모두 1이고, x = 1에서 둘 다 약 2.718이다. 모든 지수함수가 자기 자신을 도함수로 갖지는 않는다. `(2ˣ)' = 2ˣ ln 2`다.

## 이계도함수와 그래프 읽기

도함수를 다시 미분한 `f''`이 **이계도함수**다. 값, 변화율, 변화율의 변화율을 구분하면 그래프를 한 단계 더 읽을 수 있다. 위치 `s = t²`이면 속도는 `s' = 2t`, 가속도는 `s'' = 2`다.

- 한 구간에서 `f' > 0`이면 f는 증가하고 `f' < 0`이면 감소한다.
- `f'' > 0`이면 기울기가 커지는 아래로 볼록(concave up), `f'' < 0`이면 기울기가 작아지는 위로 볼록(concave down)이다.
- `f' > 0`이면서 `f'' < 0`이면 값은 계속 늘지만 증가 속도는 줄고 있다. 누적 조회수처럼 쌓이는 지표가 완만해지는 모양이며, 값이 줄어드는 것과 증가 속도가 줄어드는 것은 다른 신호다.

## 최댓값과 최솟값

구간 안쪽의 점 c에서 극대나 극소이고 f가 c에서 미분 가능하면 `f'(c) = 0`이다(페르마 정리). 그래서 극값 후보는 `f'(c) = 0`인 점과 `f'(c)`가 없는 점, 곧 임계점이다. 거꾸로는 성립하지 않는다. `x³`은 x = 0에서 기울기가 0이지만 계속 증가하므로 극값이 아니다. c 앞뒤에서 `f'`의 부호가 +에서 −로 바뀌면 극대, −에서 +로 바뀌면 극소다.

닫힌 구간 `[a, b]`에서 연속인 함수는 최댓값과 최솟값을 모두 갖는다(최대최소 정리). 이때는 구간 안의 임계점과 두 끝점의 함숫값을 모두 비교한다. 활동량 x의 순편익이 `f(x) = 6x − x²`이고 `0 ≤ x ≤ 5`라 하면 `f'(x) = 6 − 2x`는 x < 3에서 양수, x > 3에서 음수라 x = 3에서 최대 `f(3) = 9`다. 끝점 `f(0) = 0`, `f(5) = 5`와 비교해도 최댓값은 9이고 최솟값은 x = 0의 0이다. `|x|`의 최솟값은 미분 가능하지 않은 x = 0에 있으므로 그런 점을 후보에서 빼면 안 된다. 미분 가능한 내부해에서 이윤 극대화의 1차 조건이 한계수입과 한계비용의 일치로 나오는 것도 같은 구조이고, 교차 방향과 경계해를 함께 확인한다([[Production-and-Cost|생산과 비용]]).

## 접선 근사와 예측의 한계

미분 가능한 점 근처에서는 `f(a + Δ) ≈ f(a) + f'(a) Δ`로 근사한다. `s = t²`를 t = 2에서 근사하면 `s(2.1) ≈ 4 + 4 × 0.1 = 4.4`로 실제 4.41과 가깝다. 같은 직선으로 `s(4)`를 추정하면 12지만 실제는 16이다. 이 함수에서 오차는 정확히 `Δ²`이라 거리가 멀어질수록 빠르게 커진다. 도함수는 지금 모델의 국소적인 변화율을 알려 줄 뿐, 과거의 기울기가 미래에도 이어진다는 보장은 없다.

## 흔한 오해와 조건

- `(a + b)²`은 `a² + b²`이 아니다. `(2 + h)²`에 h = 1을 넣으면 9이고 `2² + 1²`은 5다. 극한 계산의 첫 전개에서 자주 틀린다.
- 극한값과 함숫값은 다르다. 함수가 a에서 정의되지 않아도 극한은 있을 수 있고, 정의되어 있어도 극한과 다를 수 있다.
- `0 / 0`은 값이 아니며 극한이 없다는 뜻도, 1이라는 뜻도 아니다. 약분이나 조임 정리로 구조를 본다.
- 연속이라고 미분 가능하지는 않다(`|x|`, ReLU). 미분 가능하면 연속이다.
- `f'(c) = 0`은 내부 극값의 필요조건일 뿐이다(`x³`). 미분 가능하지 않은 점과 구간의 끝도 후보다.
- 사잇값 정리와 평균값 정리는 존재만 보장한다. 유일성이나 위치는 따로 보여야 한다.
- `(f g)'`은 `f' g'`이 아니고, 사인의 미분 공식은 라디안에서만 그대로 쓴다.
- `f' = 0`이면 상수라는 결론은 하나의 구간 안에서만 성립한다.

## 프로그래밍과 ML에서

- **경사 하강법**: `x ← x − η f'(x)`는 기울기 부호의 반대 방향으로 움직인다. 변수가 여럿이면 각 변수에 대한 편미분을 모은 기울기 벡터(gradient)를 쓴다([[Neural-Network-Fundamentals|신경망 기초]]).
- **학습률과 곡률**: `f(x) = a x²`(`f'' = 2a > 0`)에 경사 하강법을 쓰면 `x ← (1 − 2aη) x`라서 `0 < η < 2 / f''`일 때만 0으로 수렴한다. `f'' = 4`에서 x = 1로 시작해 50번 갱신하면 η = 0.4는 약 `8 × 10⁻¹²`까지 줄고, η = 0.5는 1과 −1을 오가며, η = 0.6은 약 `2 × 10⁷`로 발산한다. 곡률이 큰 방향일수록 허용되는 학습률이 작다. 입력 스케일과 학습률이 수렴 속도를 바꾸는 예는 [[PyTorch-Training-Loop|PyTorch 학습 루프]]에 있다.
- **연쇄 법칙과 역전파**: 층을 쌓은 모델은 함수의 합성이라 손실의 기울기를 연쇄 법칙으로 출력 쪽부터 거꾸로 곱해 구한다. 자동 미분은 기본 연산마다 아는 도함수를 연쇄 법칙으로 이어 붙이므로 간격 h를 고르는 근사 오차가 없고 부동소수점 반올림만 남는다.
- **미분 가능하지 않은 점**: ReLU나 L1 정규화의 `|x|`처럼 꺾인 점에는 도함수가 없으므로 구현이 그 점에서 쓸 값을 관례로 정한다. 그 값을 수학적 도함수로 해석하지 않는다.
- **시계열의 변화율**: 샘플 간 차이를 경과 시간으로 나눈 값은 두 샘플 사이의 평균 변화율이고, 시간 단위에 따라 숫자가 바뀐다. 나노초 간격을 초로 읽으면 10⁹배 어긋난다([[Palantir-FoundryTS-Value-Time-and-Calculus|FoundryTS의 derivative와 integral]]).

### 수치 미분의 오차

전진 차분 `(f(x + h) − f(x)) / h`의 절단 오차는 약 `(h/2) |f''(x)|`로 h에 비례하고(1차 정확도), 중앙 차분 `(f(x + h) − f(x − h)) / (2h)`는 약 `(h²/6) |f'''(x)|`로 h²에 비례한다(2차 정확도). 그런데 h가 작아지면 거의 같은 두 값을 빼는 상쇄 때문에 반올림 오차가 약 `ε |f(x)| / h`로 커진다. binary64의 ε는 `2⁻⁵² ≈ 2.2 × 10⁻¹⁶`이다([[JavaScript-Numbers-Strings-and-Regular-Expressions|Number와 EPSILON]]). `sin`의 x = 1에서 참값 `cos 1`과의 오차를 binary64로 계산하면 다음과 같다.

| h | 전진 차분 오차 | 중앙 차분 오차 |
|---|---|---|
| `10⁻¹` | `4.3 × 10⁻²` | `9.0 × 10⁻⁴` |
| `10⁻⁴` | `4.2 × 10⁻⁵` | `9.0 × 10⁻¹⁰` |
| `10⁻⁶` | `4.2 × 10⁻⁷` | `2.8 × 10⁻¹¹` |
| `10⁻⁸` | `1.4 × 10⁻⁸` | `3.0 × 10⁻⁹` |
| `10⁻¹²` | `4.3 × 10⁻⁵` | `1.2 × 10⁻⁵` |

h를 줄일수록 좋아지다가 다시 나빠진다. 전진 차분은 `√ε ≈ 1.5 × 10⁻⁸`, 중앙 차분은 `ε^(1/3) ≈ 6 × 10⁻⁶` 정도의 h에서 오차가 가장 작고, 차수가 높은 공식이 반올림에도 덜 취약하다. 직접 구현한 역전파는 몇 개의 점에서 중앙 차분과 상대 오차로 비교해 검사한다(gradient check). 단정밀도(float32)의 ε는 `2⁻²³ ≈ 1.2 × 10⁻⁷`이라 같은 h에서도 반올림 오차가 훨씬 크므로 이런 검사는 배정밀도에서 한다.

## 이해 확인 질문

1. `lim_{x→2} (x² − 4) / (x − 2)`를 구하고, 약분이 x = 2의 함숫값을 만들어 주지 않는 이유를 설명한다.
2. 구멍이 있는 함수, 점프가 있는 함수, `|x|`를 연속의 세 조건과 미분 가능성으로 각각 진단한다.
3. `f(x) = x³ − 3x`의 `[−2, 3]`에서 최댓값과 최솟값을 임계점과 끝점 비교로 구하고, 끝점을 후보에서 빼면 무엇을 놓치는지 말한다.
4. 평균 시속 60 km였다는 사실로 순간 속도에 대해 말할 수 있는 것과 없는 것을 평균값 정리의 조건으로 설명한다.
5. 전진 차분에서 h를 `10⁻¹²`까지 줄이면 오차가 다시 커지는 이유를 절단 오차와 반올림 오차의 크기로 설명한다.
6. `f(x) = 3x²`에 경사 하강법을 쓸 때 수렴하는 학습률의 범위를 구한다.
