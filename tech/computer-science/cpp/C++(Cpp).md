# C++

C++ 코딩 테스트에서는 문법 암기보다 값의 범위, 객체 수명, 표준 라이브러리 연산의 의미와 복잡도를 정확히 아는 것이 중요하다. 알고리즘이 맞아도 정수 overflow, iterator 무효화, 경계 조건 하나로 결과가 달라질 수 있다.

## 학습 순서

1. 정수 범위와 객체 수명부터 확인한다.
2. `vector`, `string`, associative container와 iterator 규칙을 익힌다.
3. `sort`, `lower_bound`, `next_permutation` 같은 표준 알고리즘의 계약을 읽는다.
4. 작은 입력과 경계 입력으로 구현 규칙을 검증한다.
