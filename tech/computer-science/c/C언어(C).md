# C

C는 메모리 주소, 객체 수명과 범위 검사를 프로그래머에게 맡긴다. 자료형의 범위, 문자열의 NUL 종단, 포인터와 `malloc`/`free`의 계약을 정확히 알아야 정의되지 않은 동작을 피할 수 있다.

## 학습 순서

1. 빌드 단계와 오류 종류를 구분한다.
2. 자료형의 범위, 연산 규칙과 함수 선언을 익힌다.
3. 배열과 문자열의 메모리 표현을 이해한다.
4. 포인터, 값 전달과 동적 할당의 수명을 다룬다.
5. 입력 크기 제한과 반환값 검사를 습관으로 만든다.
