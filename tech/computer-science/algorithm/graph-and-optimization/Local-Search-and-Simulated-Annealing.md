# 지역 탐색과 담금질 기법

지역 탐색은 현재 상태 하나를 들고 이웃 상태로 옮겨 가며 더 나은 해를 찾는다. [[Search-Problem-Formulation|BFS나 A*]]처럼 여러 경로를 함께 관리하거나 탐색 트리를 두지 않고, 현재 상태와 그 값만 기억한다. 목표에 이르는 경로가 아니라 해 자체가 답인 문제에 쓴다. 병원 위치 선정, 작업 배치와 외판원 순회처럼 어떤 구성이 좋은지를 찾는 일이 핵심인 경우다. 최적해를 보장하지 않는 대신 큰 상태 공간에서도 적은 계산으로 쓸 만한 해를 찾는다.

## 상태 공간 지형

- 상태마다 값을 매긴다. 최대화하는 함수를 목적 함수, 최소화하는 함수를 비용 함수라고 부르며 부호를 바꾸면 같은 문제다.
- 이웃은 현재 상태를 조금 바꾼 상태다. 병원 배치라면 병원 하나를 한 칸 옮긴 배치, 순회라면 간선 두 개를 바꾼 순회다. 이웃 정의가 좁으면 두 번 바꿔야 좋아지는 해에 닿지 못한다. 한 번 바꾼 중간 상태가 현재보다 좋지 않으면 언덕 오르기는 그쪽으로 가지 않기 때문이다.
- 전역 최적은 모든 상태 중 값이 가장 좋은 상태이고, 국소 최적은 이웃보다 좋지만 전역 최적은 아닌 상태다.
- 평평한 국소 최적(고원)은 같은 값의 상태가 이어지고 그 둘레가 모두 더 나쁜 구간이다. 어깨는 같은 값이 이어지지만 둘레에 더 좋은 이웃과 나쁜 이웃이 함께 있는 구간이라, 더 오를 수는 있어도 진행이 느려지기 쉽다.

## 언덕 오르기

```text
current = 초기 상태 (주어지지 않으면 무작위)
반복:
  neighbor = current의 이웃 중 가장 좋은 상태 (동점이면 무작위)
  neighbor가 current보다 좋지 않으면 current 반환
  current = neighbor
```

**예: 1차원 지형.** 상태 1~7의 값이 [1, 3, 2, 1, 4, 6, 5]이고 이웃은 양옆 상태라고 하자(가상 예). 상태 1~3에서 출발하면 상태 2(값 3)의 국소 최대에서 멈추고, 4~7에서 출발해야 상태 6(값 6)의 전역 최대에 닿는다. 출발점을 무작위로 고르면 한 번에 성공할 확률은 4/7이다.

| 변형 | 다음 상태 고르기 | 특징 |
|---|---|---|
| 최급 상승(steepest-ascent) | 가장 좋은 이웃 | 기본형. 매번 이웃을 모두 평가한다 |
| 확률적(stochastic) | 더 좋은 이웃 중 무작위 | 가장 가파르지 않은 쪽으로도 진행한다 |
| 첫 선택(first-choice) | 처음 찾은 더 좋은 이웃 | 이웃을 다 보지 않아 평가 수를 줄일 수 있다 |
| 무작위 재시작(random-restart) | 무작위 출발점에서 여러 번 실행해 최선을 고름 | 위 예에서 5번이면 성공 확률 `1 − (3/7)^5 ≈ 98.6%` |
| 지역 빔(local beam) | `k`개 상태의 이웃 전체에서 상위 `k`개 | 좋은 상태 주변으로 탐색이 모인다. 서로 정보를 나누지 않는 재시작 `k`번과 다르다 |

모든 변형이 나빠지는 이동을 하지 않으므로 국소 최적과 고원에 갇힐 수 있다. 무작위 재시작은 실행 횟수를 늘릴수록 전역 최적을 만날 가능성을 높이지만, 정해진 횟수 안에 찾는다는 보장은 없다.

연속 변수의 손실을 기울기 반대 방향으로 줄여 가는 [[Neural-Network-Fundamentals#경사 하강법과 배치 크기|경사 하강법]]도 목적 함수를 최대화하는 대신 최소화한다는 점만 다른 같은 발상이다.

## 담금질 기법

금속을 높은 온도에서 천천히 식히는 공정에서 이름을 땄다. 처음에는 나빠지는 이동도 자주 받아들여 국소 최적을 벗어나고, 온도를 낮추며 점점 개선하는 이동만 받는다.

```text
current = 초기 상태
t = 1부터 max까지:
  T = Temperature(t)                       # 시간이 갈수록 작아진다
  neighbor = current의 무작위 이웃
  ΔE = value(neighbor) - value(current)    # 최대화 기준, 양수면 개선
  ΔE > 0이면 current = neighbor
  아니면 확률 e^(ΔE/T)로 current = neighbor
current 반환
```

나빠지는 이동(`ΔE < 0`)의 수락 확률 `e^(ΔE/T)`는 0과 1 사이이며, 덜 나쁠수록, 온도가 높을수록 커진다.

| ΔE | T = 2 | T = 0.5 |
|---|---:|---:|
| -1 | 약 0.61 | 약 0.14 |
| -3 | 약 0.22 | 약 0.002 |

앞의 1차원 예에서 상태 2에 있어도 상태 3으로 내려가는 이동(`ΔE = −1`)을 `T = 2`에서는 약 61% 확률로 받아들이므로, 골짜기를 지나 상태 6으로 오를 기회가 생긴다. 온도가 0에 가까우면 나빠지는 이동을 거의 받지 않아 개선만 받는 언덕 오르기처럼 동작한다.

온도 일정은 문제마다 정하며, 남은 반복 비율에 비례해 줄이는 단순한 일정도 쓴다. 온도를 충분히 천천히 낮추면 전역 최적에 도달할 확률이 1에 가까워진다는 결과가 있지만, 이는 냉각 속도에 대한 조건이다. 제한된 반복에서 멈춘 결과를 최적해로 부르지 않는다.

## 유전 알고리즘

유전 알고리즘은 지역 빔 탐색처럼 무작위로 만든 상태 `k`개(개체군)에서 시작하지만, 다음 세대를 두 부모를 섞어 만든다.

1. 각 개체를 적합도 함수로 평가한다.
2. 적합도에 비례하는 확률로 부모 둘을 뽑는다.
3. 교차점에서 두 부모의 문자열을 잘라 한쪽의 앞부분과 다른 쪽의 뒷부분을 잇는다(교차).
4. 자식마다 독립된 확률로 일부 값을 무작위로 바꾼다(돌연변이).

8퀸이라면 열마다 퀸이 놓인 행을 숫자 8개로 적고, 서로 공격하지 않는 퀸 쌍의 수를 적합도로 쓴다(8개에서 둘을 고르는 28쌍이 최댓값). 왼쪽 네 열에 충돌이 없는 배치와 오른쪽 네 열에 충돌이 없는 배치를 넷째 열 뒤에서 이으면, 두 절반 사이에도 충돌이 없을 때 한 번에 해가 나온다. 퀸 하나씩 옮기는 언덕 오르기에는 없는 이동이다. 교차는 부모가 가진 값을 다시 배치할 뿐이므로 어느 부모에도 없는 값은 돌연변이로만 들어온다.

### 새 방법은 단순한 기준선과 먼저 겨룬다

아래는 열마다 퀸 하나를 무작위로 놓은 8퀸 배치에서 직접 실행한 결과다(2026-11-24, 파이썬, 난수 시드 20261124). 공격하는 쌍이 0이 되면 성공으로 셌고, 푼 문제 하나당 평가 수는 실패한 실행까지 합친 총 평가 수를 성공 수로 나눈 값이다.

| 방법 | 설정 | 성공 | 푼 문제 하나당 평가한 배치 |
|---|---|---|---|
| 최급 상승 언덕 오르기 | 이웃 56개 중 가장 좋은 쪽, 나아지지 않으면 멈춤 | 146/1,000 | 단독으로는 해를 보장하지 않음 |
| 무작위 재시작 | 멈추면 새 무작위 배치에서 다시 오름 | 1,000/1,000, 평균 6.91번 시도 | 1,629 |
| 담금질 | 무작위 이웃 하나, 시작 온도 1, 단계마다 0.999배, 0.01 미만이면 멈춤 | 989/1,000 | 1,140 |
| 유전 알고리즘 | 개체 50, 적합도 비례 선택, 한 점 교차, 자식의 20%에 돌연변이, 최대 1,000세대 | 164/200 | 30,687(성공한 실행만 보면 중앙값 17,925, 357.5세대) |

이 설정에서 유전 알고리즘은 성공률(82%)이 재시작이나 담금질보다 낮았고 푼 문제 하나당 담금질의 약 27배를 평가했다(성공한 실행의 중앙값으로도 약 16배). 개체 수, 돌연변이 확률과 선택 방식을 바꾸면 결과가 달라지므로 방법 자체의 우열로 일반화하지 않는다. 이름이 그럴듯한 방법일수록 같은 문제와 같은 평가 예산에서 무작위 재시작이나 담금질 같은 단순한 기준선과 먼저 비교하고, 설정과 시드를 함께 기록한다.

후보를 시뮬레이션으로 평가할 수 있는 설계 문제에 진화 알고리즘을 쓴 사례로 NASA ST5 임무의 안테나가 있다. 자동 설계한 안테나가 임무 요구사항을 충족했고, 설계와 제작에 약 3인월이 들어 기존 방식으로 설계한 안테나의 약 5인월보다 적었다(Hornby 외 2006).

## 외판원 문제에 적용하기

- 상태는 모든 도시를 한 번씩 돌고 돌아오는 순회 하나, 비용은 총 거리다.
- 2-opt 이웃은 인접하지 않은 간선 두 개를 지우고, 그 사이 구간의 방향을 뒤집어 다시 잇는다. 도시가 `n`개면 이런 이웃이 `n(n−3)/2`개다. 평면 거리에서는 서로 교차한 두 간선을 이렇게 풀면 순회가 길어지지 않는다(삼각 부등식).
- 어떤 2-opt 이동으로도 짧아지지 않는 순회는 2-opt 기준의 국소 최적일 뿐 전역 최적이라는 보장은 없다. 도시가 적고 최적해가 필요하면 [[Bitmask-DP-and-TSP|Held-Karp DP]]를 쓰고, 도시가 많으면 지역 탐색이나 담금질로 좋은 순회를 찾는다. 외판원 최적화 문제는 NP-hard다([[Algorithm-Complexity#P, NP, NP-hard, NP-complete|복잡도 문서]]).

## 트레이드오프와 적용 점검

- 해의 품질은 이웃 정의, 출발점, 반복 횟수와 온도 일정에 달려 있다. 같은 문제와 같은 제한 시간에서 여러 난수 시드로 비교하고 시드와 설정을 기록한다.
- 지역 탐색의 결과는 최적성 증명이 아니다. 하한이나 최적성 차이가 필요하면 [[Linear-Programming|선형 계획법]]의 완화 문제나 MIP 같은 정식 해법의 한계값과 비교한다([[Constraint-Based-Resource-Placement|제약 기반 자원 배치]]).
- 제약이 있으면 이웃이 제약을 깨지 않게 정의하거나, 위반한 제약 수를 비용으로 삼는다. 후자는 [[Constraint-Satisfaction-Problem|제약 충족 문제]]의 최소 충돌 방법과 같은 발상이다.

## 이해 확인

1. 1차원 예에서 상태 3에서 출발한 최급 상승은 어디서 멈추나? 이웃 중 값이 큰 상태 2로 올라가 그 국소 최대에서 멈춘다.
2. 담금질에서 같은 `ΔE = −1`이라도 초반과 후반의 수락 확률이 다른 이유는? 온도 `T`가 시간에 따라 작아지기 때문이다.
3. 도시 10개인 순회의 2-opt 이웃은 몇 개인가? `10 × 7 / 2 = 35`개다.
4. 8퀸에서 교차가 한 번에 해를 만드는 경우와, 어느 부모에도 없는 행 값이 들어오는 경로는? 충돌 없는 두 절반 사이에도 충돌이 없을 때 한 번에 해가 나오고, 없는 값은 돌연변이로만 들어온다.
