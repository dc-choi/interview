# 개인 코딩 선호의 확인 사례

사용자 선호의 정본은 [tech/AGENTS.md](../../../AGENTS.md#개인-코딩-선호)다. 이 목차는 2026-09-12 대화에서 확인한 사례와 적용 범위로 안내한다.

자료 역할은 사용자 선호의 확인 기록이다. 연결된 학습 문서 전체를 사용자 규칙이나 모든 프로젝트의 채택 결정으로 해석하지 않는다. 현재 요구사항과 대상 프로젝트의 규칙을 확인해 적용한다.

## 갱신 기준

새 선호나 변경이 사용자 답변으로 확인되면 `tech/AGENTS.md`의 정본과 하위 문서의 관련 사례를 함께 갱신한다. 미확인 항목은 기존 학습 지식이나 AI 제안만으로 확정하지 않는다.
