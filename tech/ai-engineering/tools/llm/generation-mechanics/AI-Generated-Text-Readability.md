# AI 생성 글의 처리 난도 — 정보 밀도 압력과 심리언어학 지표

최근 LLM이 쓴 글이 읽기 어렵다는 인상은 사람의 문장 처리 난도와 상관이 알려진 언어 특징의 빈도로 잴 수 있다. 이 문서는 Clark, Martin, Mahowald의 arXiv 논문(2026-10-21 제출)을 2026-10-27에 대조해, 무엇을 쟀고 어떤 가설을 세웠는지와 실무 글쓰기에서 무엇을 점검할지 정리한다. 논문은 영어만 다뤘고 독자의 읽기 시간이나 이해도를 직접 잰 실험은 없다. 상위: [[LLM-Generation-Mechanics|LLM 동작 원리]].

## 처리 난도의 대리 지표

| 지표 | 내용 | 예시(이 문서가 만든 예) |
|---|---|---|
| 드문 단어 조합 | 기준 말뭉치에 나오지 않는 2어절 조합의 비율과 3어절 perplexity | 문서에서 처음 보는 연어 |
| 의존 거리 | 문장 길이로 표준화한 구문 의존 관계의 길이 | 주어와 동사 사이에 긴 수식이 끼어 있는 문장 |
| 목적격 관계절 | 관계사가 있는 형태와 생략된 축약형을 나눠 센다 | the bug the patch introduced |
| 명사 연쇄 | 세 개 이상의 명사가 수식 관계로 이어진 복합 명사 | cache invalidation policy update |
| 명사 파생 동사 | 명사에서 온 동사 | footnote를 동사로 쓰는 경우 |
| 무생물 주어 | 보통 생물 주어를 받는 동사에 무생물 주어를 붙인다 | The function wants a string |

## 비교 기준: 사람 글과 왕복 번역

- **사람 글**: 대화는 OpenSubtitles, 코딩 설명은 StackExchange, 에세이는 PERSUADE 2.0 학생 에세이(6~12학년, 총점 5~6점)를 쓰고 Wikipedia도 비교했다.
- **왕복 번역**: 문장마다 영어를 일본어로 번역했다가 다시 영어로 옮긴다(NLLB-200 3.3B, 부록에서 러시아어 경유와 TranslateGemma 4B도 확인). 뜻은 두고 표현만 바뀐 짝이므로, 왕복 뒤 줄어드는 특징은 다른 표현이 가능했는데도 모델이 고른 것으로 해석한다.
- **수집 대상**: 최상위와 준최상위 모델 9개(Claude Sonnet 5, Opus 5, Opus 5.5, Fable 5, GPT-5.6 Luna, Terra, Sol, Kimi K2.5, GLM 5)와 작은 공개 모델(Llama 3.1 8B 기본과 Instruct, Olmo 3 7B 기본, Instruct, Think)의 대화, 코딩, 에세이 출력이다. 대화는 주제 10개, 코드는 저장소 5개를 시드로 썼다.

## 결과

- **사람 글과의 비교**: 9개 모델 모두 무생물 주어와 생물 동사의 결합, 드문 n-gram을 사람보다 많이 썼다. 대화에서는 대부분의 모델이 더 긴 의존 거리, 더 많은 명사 연쇄와 축약된 목적격 관계절을 보였다.
- **왕복 번역과의 비교**: 대부분의 최상위 모델이 드문 2어절 조합이 많고 n-gram perplexity가 높았으며, 명사 파생 동사, 무생물 주어와 축약 목적격 관계절도 늘었다. 관계사 that이나 which가 있는 목적격 관계절은 덜 써서 생략할 수 있는 단어를 빼는 쪽을 택했다.
- **모델 간 차이**: Llama와 Olmo의 기본, Instruct 모델은 왕복 번역 전후 차이가 가장 작았다. Olmo Think는 최상위 모델과 같은 쪽에 섰고 효과는 기본, Instruct, Think 순으로 커졌다. Claude Opus 5.5는 처리 난도 관련 비교 21개 중 19개에서 직전 Opus 5보다 낮았다.
- **장르 차이**: 에세이는 대화와 코딩보다 효과가 작았다. 논문은 에세이가 여러 턴이 아니라 단일 프롬프트로 만들어진 점을 이유로 추정한다.

## 가설: 정보 밀도 압력

사람의 언어는 의사소통의 성공으로 다듬어지지만, 수학, 코드와 추론 과제에서 검증 가능한 보상으로 후학습한 모델은 명료함이 아니라 정답에 보상을 받는다. 논문은 이것이 적은 토큰에 정보를 담는 압력으로 작용해 처리하기 어려운 표현을 늘린다는 가설을 세운다. 사람 피드백 학습은 오히려 긴 출력을 보상한다는 선행 결과가 있어, 압축 압력은 검증 가능한 보상 학습과 더 관련이 있다고 본다. 후학습 단계의 구분은 [[LLM-Generation-Mechanics-Training#사전학습 이후의 조정|사전학습 이후의 조정]]을 따른다.

개념 증명 실험은 Qwen2.5-1.5B-Instruct를 JSON 형식의 사건 설명을 영어 문장으로 바꾸는 과제에 GRPO로 강화학습하면서 KL 페널티와 길이 페널티를 바꿨다.

- KL 정규화가 없을 때 길이 페널티가 0이면 짧은 변형을 고르는 비율이 시드에 따라 0%에서 100%까지 갈렸다. 페널티가 0보다 크면 모든 시드가 짧은 변형을 범주적으로 골랐고, 학습한 두 that 생략 교체에서 98% 넘게 짧은 쪽이었다.
- KL 정규화를 두면 길이 페널티에 따라 짧은 변형 선호가 더 완만하게 올랐다.
- 학습하지 않은 가까운 교체(예: so that의 that 생략)로는 선호가 옮겨 갔지만, 먼 교체 넷 가운데서는 KL 없는 조건의 속격 교체 하나에서만 나타났다.

논문은 이 실험을 최상위 모델의 실제 기제를 보인 결과가 아니라 개념 증명으로 둔다.

## 한계

- 영어만 분석했고 모델 일부만 다뤘다.
- 대화와 코드의 시드가 적다.
- 최상위 모델의 인과를 확인하려면 후학습 과정 자체를 연구해야 하는데 규모상 어려워 대리 지표에 기댔다.
- 독자 실험이 없다. 지표는 처리 난도와 상관이 알려진 특징이며 실제 이해도를 잰 값이 아니다.

## 실무 점검(적용 제안)

사람이 읽을 문서, 고객 안내와 코드 설명을 모델에게 맡길 때 아래를 편집 점검 항목으로 쓴다. 논문이 검증한 개선 방법은 아니다.

- 사물이 주어로 와서 사람의 행동을 하는 문장은 행위자를 드러내는 문장으로 바꿀지 본다.
- 세 개 이상 이어진 명사 연쇄는 전치사나 관계절로 풀어 쓴다.
- 생략된 관계사와 접속어를 되살려 문장 구조를 드러낸다.
- 처음 보는 단어 조합은 기준 문서에서 쓰는 표현으로 바꾼다.
- 짧게 쓰라는 지시가 압축된 표현을 늘리지 않는지 같은 내용의 긴 판과 비교해 본다.
