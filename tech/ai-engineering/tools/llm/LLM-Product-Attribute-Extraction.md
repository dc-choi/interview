# LLM 상품 속성 추출과 결과 검증

상품 상세 이미지에 있는 치수와 소재는 사람이 읽을 수 있어도 검색 필터나 비교 화면에서 바로 조회할 수 있는 데이터는 아니다. 속성 추출은 이미지와 설명을 구조화된 값으로 바꾸는 처리다. 이미지의 의미를 벡터로 검색하는 일과도 구분한다.

## 입력 선별, 추출과 검증을 나눈다

| 단계 | 처리 | 확인할 실패 |
|---|---|---|
| 자료 수집 | 대표 이미지, 상세 이미지, 상품명과 카테고리 연결 | 다른 상품이나 오래된 이미지가 섞임 |
| 전처리 | 긴 이미지를 분할하고 OCR로 텍스트와 표 후보 선별 | 표의 제목, 단위나 일부 행이 잘림 |
| 추출 | 치수표와 검색용 속성을 정해진 형식으로 변환 | 숫자 오독, 속성 누락과 근거 없는 값 생성 |
| 후처리 | 값과 의미를 검사하고 불확실한 결과 보류 | 형식이 맞지만 다른 의미의 숫자가 통과 |
| 활용 | 검증한 값을 저장하고 화면과 검색에 연결 | 검증 전 결과가 사용자에게 노출 |

입력 선별, few-shot 예시와 후처리를 함께 사용하는 흐름은 공개 상품 속성 추출 사례에서 확인된 패턴이다. 위 실패 항목은 이 패턴을 적용할 때의 점검 제안이다. 특정 모델이나 오케스트레이터가 필수인 구조는 아니다.

## 전처리는 정보량보다 필요한 근거를 보존한다

길이가 긴 상세 이미지는 구간을 나누고, 치수 추출에 필요한 텍스트와 표를 선별할 수 있다. OCR은 후보를 찾는 단계로 쓰며, 숫자가 검출됐다는 사실만으로 올바른 치수표라고 판정하지 않는다.

분할 높이나 숫자 개수 같은 임계값은 대상 이미지로 평가한다. 한 사례의 픽셀 기준을 모든 이미지와 모델에 적용하지 않는다. 표를 자를 때 단위와 열 제목이 남는지도 함께 본다.

## 형식과 의미는 다른 검사다

치수표는 표 형태로, 검색용 소재와 패턴은 구조화된 필드로 다룰 수 있다. 출력 형식을 맞췄어도 내용이 맞는지는 별도로 검증한다. 활용할 근거가 없으면 실패나 검토 대기 상태로 두고 값을 추정해 채우지 않는다.

설명용 예시로 상세 페이지에 상품 총길이와 착용 모델의 키가 함께 있으면 둘 다 길이 단위의 숫자다. 키를 상품 치수로 저장하면 파서와 숫자 범위 검사를 통과해도 잘못된 결과다. 값뿐 아니라 측정 대상과 부위까지 확인해야 한다.

Few-shot 예시는 입력과 기대 출력의 값이 일치하는지 먼저 검토한다. 공개 발표자료의 예시에도 입력과 출력 숫자가 다른 부분이 있어 그대로 평가 정답으로 사용할 수 없다. 예시를 추가하는 것과 검증된 정답을 추가하는 것은 다르다.

## 보류 규칙과 평가 범위를 함께 정한다

다음은 공개 사례의 전처리, few-shot 보정과 불용어 기반 실패 처리를 적용한 평가 제안이다.

1. 브랜드와 레이아웃이 다른 표, 줄글형 치수와 치수 정보가 없는 입력을 평가셋에 넣는다.
2. 치수, 단위와 측정 부위의 정답을 확인하고 프롬프트 작성용 예시와 평가용 입력을 분리한다.
3. 착용 모델 정보처럼 오인하기 쉬운 내용이 나오면 재검토하거나 보류한다. 불용어 규칙으로 정상 값까지 버리지 않는지도 확인한다.
4. 통과한 결과의 정확도와 전체 입력 중 통과한 비율, 잘못 보류한 비율을 함께 본다.
5. 프롬프트, 모델이나 입력 분할 방식을 바꾸면 같은 평가셋으로 다시 확인한다.

보류를 늘리면 통과한 결과의 정확도가 높아질 수 있다. 따라서 정확도만으로 전체 추출 품질을 판단하지 않는다. 발표에서 제시한 정확도와 구매 전환 개선 수치는 표본과 측정 조건을 확인하기 전까지 다른 서비스의 기대 성능이나 인과 효과로 사용하지 않는다.

## 적용할 때의 최소 기록

아래는 오류를 다시 확인하기 위한 설계 제안이다. 공개 사례의 실제 저장 스키마를 재현한 것은 아니다.

- 상품과 입력 이미지의 버전, 추출에 사용한 구간
- 원래 값과 정규화한 값, 단위와 측정 대상
- 추출 설정의 버전, 통과 또는 보류 상태와 사유

재처리 시 같은 결과를 중복 저장하지 않는 계약은 [[LLM-Failure-Handling|LLM 실패 처리]]와 연결한다. 저장할 필드와 오류 비용이 분명하면 고정 파이프라인부터 검토하고, 반복 추출을 이유로 자율 에이전트를 필수로 두지 않는다.
