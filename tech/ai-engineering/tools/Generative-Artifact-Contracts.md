# 생성형 시각 산출물의 내용, 디자인과 편집 계약

시각 산출물 생성에서는 내용의 정확성, 디자인과 수정 가능성을 별도 계약으로 둔다. 이미지는 스타일과 구도를 전달하기 좋고 HTML/CSS는 문구, 데이터와 구조를 검사하고 편집하기 좋다.

## 참조 이미지는 내용의 정본과 구분한다

AesCode는 참고 이미지에서 미적 단서를 얻어 편집 가능한 HTML/CSS를 생성하는 Microsoft 연구 프로젝트다. 2026-10-16 공식 저장소 대조 기준, **프롬프트가 내용의 정본이고 이미지는 레이아웃과 스타일의 참고**다. 이미지 속 잘못된 숫자나 문구를 그대로 복제하지 않도록 학습 목표를 분리한다.

설계 그래프는 텍스트, 표, 차트와 영역 및 정렬 관계를 표현한다. 실행, 정확한 문구, 경계, 표와 차트 데이터, 의미 배치 및 여백을 개별 검증하고 나머지 시각 속성도 평가한다. 제공 발췌는 HTML 표와 ECharts 차트를 출력해 데이터를 확인하고 수정하는 방식을 설명한다. 이번에 전체 학습과 생성 결과를 재현하지 않았다.

적용 순서는 내용과 데이터를 먼저 확정하고, 참조 디자인을 분리해 전달한 뒤, 브라우저에서 렌더링한 결과와 문구 및 데이터의 원본을 대조하는 것이다. HTML이 유효하다는 것과 읽기 좋은 디자인이라는 것은 다른 합격 조건이다.

## Krea 3의 부분 편집과 피사체 보존

2026-10-16 공식 발표 대조 기준, Krea 3는 상품과 인물의 일관성을 유지하는 이미지 편집을 겨냥한다. 공식 소개 가격은 2K 한 장당 $0.06이고 1K는 $0.03이며 실제 채널별 가격은 사용 전 확인한다. 벤더가 제시한 속도와 일관성은 자체 측정 및 시연이며 모든 입력의 보장은 아니다.

**참조 이미지 수는 공식 발표 기준 최대 6개**다. 제공된 2026-10-16 GeekNews 발췌의 최대 8개와 달라 공식 표기를 우선했다. 발췌의 변경 영역 탐지 후 렌더링, 별도 편집 학습과 색상 코드 지정 설명은 내부 구현 전체를 확인한 내용이 아니다. 이 세부는 기술 문서나 후속 발표로 대조할 항목이다.

모델의 보존 주장을 실제 픽셀 보존과 구분한다. 배경만 바꾸는 작업도 로고, 작은 글씨, 부품과 피사체 경계를 원본과 비교한다. 반복 편집에서는 바로 앞 결과만 기준으로 삼지 않고 최초 승인본과 함께 대조한다.

## 기계 설명도는 그림과 동작 모델을 함께 검수한다

2026-10-22 공식 저장소 README 대조 기준, Anatomy는 기술 개념을 작동하는 기계에 빗대어 설명하는 상호작용 등각 그림을 생성하는 Agent Skill이다. SVG를 바탕으로 WebGL 효과와 선택적 3D 표현을 더하며, 독립 HTML, SVG 파일 또는 React 컴포넌트를 산출물로 삼는다. 좌표축과 데이터 계열을 그리는 차트 라이브러리와는 용도가 다르다.

입력에는 설명할 개념, 실제 개수와 임계값, 움직여야 할 부분과 배치할 화면을 함께 적는다. 예를 들어 연결 풀을 기계로 표현할 때는 연결 수, 대기 조건과 반환 시점을 먼저 정한다. 이 예시는 설명도를 검수하는 기준이며 특정 구현의 동작을 재현했다는 뜻은 아니다.

기하 검사는 부품의 연결과 겹침을, 브라우저 캡처는 화면과 움직임을 확인하는 수단이다. 그림이 정상 렌더링돼도 비유가 실제 시스템의 동시성이나 실패 처리를 올바르게 설명하는지는 별도로 대조해야 한다. README는 3D 모드를 beta로 표시하고 검증 사례의 범위를 제한한다. 이번 확인에서는 설치, 생성과 브라우저 실행을 시험하지 않았다.

## 산출물별 검수 기준

| 산출물 | 검수 |
|---|---|
| 대시보드와 슬라이드 HTML | 수치와 단위, 차트 데이터, 잘림과 글자 크기 |
| 상품 이미지 | 형태, 색, 로고, 문구와 보이지 않는 면의 생성 |
| 반복 캠페인 변형 | 기준 이미지와 시리즈의 피사체 일관성 |
| 인쇄용 결과 | 실제 크기, 해상도, 재단과 색상 규격 |

이번 확인은 공식 자료 대조다. 이미지 생성과 성능 측정, HTML 렌더링 품질 시험은 수행하지 않았다.
