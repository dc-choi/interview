# 한국어 TTS의 학습 범위와 평가

TTS(Text-to-Speech)는 텍스트를 음성으로 바꾼다. 한국어 상담에 적용할 때는 문장을 정확히 읽는지, 억양과 쉼이 자연스러운지, 같은 화자의 목소리를 유지하는지를 나누어 평가한다. 한 축의 개선이 다른 축의 개선을 보장하지 않는다.

이 문서는 2026-10-22에 공개 논문을 대조한 구조 설명과 2026-10-14 공개 발표의 사례를 구분한다. 특정 벤더의 현재 한국어 성능 순위나 공개되지 않은 최종 모델 구조를 확정하지 않는다.

## 음성을 표현하는 방식부터 구분한다

| 방식 | 생성과 복원 | 확인할 경계 |
|---|---|---|
| 신경망 코덱의 이산 토큰 | VALL-E는 기존 오디오 코덱의 이산 코드를 이용해 TTS를 조건부 언어 모델링으로 학습한다 | 생성 모델의 예측 품질과 코덱의 복원 품질을 따로 확인한다 |
| 연속 음향 표현 | F5-TTS는 멜 스펙트로그램을 flow matching으로 생성하고 보코더로 파형을 만든다 | 연속 표현을 쓴다는 이유만으로 단조로운 음성이 나온다고 단정하지 않는다 |

VALL-E의 공개 논문은 영어 음성 6만 시간 학습을 명시한다. 이 수치로 다른 모델의 한국어 학습량이나 성능을 추정하지 않는다. SpeechTokenizer는 RVQ의 서로 다른 층에서 의미 정보와 음향 정보를 계층적으로 나누는 설계를 제시한다. 음성 토큰이라는 이름이 같아도 담는 정보와 학습 목표가 같지는 않다.

진단 절차로는 같은 한국어 녹음을 코덱에 넣어 복원한 소리와, 텍스트에서 새로 생성한 소리를 비교할 수 있다. 복원 단계부터 발음이나 음색이 무너지면 생성 모델만 조정하는 실험으로 원인을 분리하기 어렵다. 이는 병목을 찾기 위한 실험 제안이며 특정 모델에서 코덱 문제가 확인됐다는 뜻은 아니다.

## LoRA와 전체 미세조정은 비교 실험으로 선택한다

LoRA는 기반 가중치를 고정하고 저랭크 변화량을 학습한다. 전체 미세조정은 기반 모델의 가중치도 갱신한다. LoRA 논문은 자신이 평가한 언어 모델 과제에서 전체 미세조정과 비슷하거나 더 나은 결과를 보고한다. 따라서 LoRA가 한국어를 충분히 학습할 수 없다는 일반 법칙으로 설명하지 않는다.

다음은 한국어 TTS에 적용할 비교 실험의 제안이다.

1. 같은 기반 모델과 학습 자료에서 LoRA와 전체 미세조정을 비교한다. 학습 시간, 학습률과 LoRA rank를 함께 기록한다.
2. 목표 화자의 음색 적응과 한국어 발음, 구어체 운율 적응을 별도 항목으로 평가한다.
3. 두 방식 모두 개선이 멈추면 데이터 분포, 음향 표현과 복원 모듈을 분리해 조사한다.
4. 자연스러움이 개선돼도 숫자 누락, 반복, 화자 일관성과 서빙 지연이 악화되지 않았는지 확인한다.

## 사례: 학습 범위 변경 뒤에도 남은 병목

2026-10-14 토스 공개 발표에서는 상담용 한국어 TTS에 외부 API, 공개 모델의 LoRA, 전체 미세조정을 차례로 검토한 경험을 공유했다. 해당 팀의 내부 청취 비교에서는 전체 미세조정이 더 자연스러웠지만, 추가 학습 뒤에도 한계가 남아 음성 표현과 모델 구조를 다시 검토했다고 설명했다.

이 사례는 해당 데이터와 설정에서 관찰한 결과다. 전사문만으로는 평가 표본, 학습 조건과 최종 구조를 재현할 수 없다. 따라서 벤더 간 현재 우열, 전체 미세조정의 보편적 우위, 특정 토크나이저나 teacher의 한국어 결함으로 확대하지 않는다. 슬라이드의 세부 수치와 전사로 식별이 불명확한 모델명은 여기서 사용하지 않는다.

## 평가 설계

F5-TTS 논문은 WER, 화자 유사도, RTF와 청취 평가를 함께 사용한다. 한국어 제품에 옮길 때의 점검 항목은 다음과 같다.

| 축 | 평가 제안 | 해석의 한계 |
|---|---|---|
| 내용 정확도 | 같은 문장의 합성 음성을 재전사해 WER/CER를 비교하고 숫자, 고유명사와 반복 구절을 직접 듣는다 | 재전사 오류가 TTS 오류처럼 섞일 수 있다 |
| 자연스러움 | 모델명을 가린 청취 비교에서 억양, 강세와 쉼을 평가한다 | 소수의 좋은 샘플만으로 서비스 전체를 대표하지 않는다 |
| 화자 일관성 | 짧은 문장과 긴 발화에서 음색 유지와 화자 유사도를 확인한다 | 유사도가 높다고 내용이 정확한 것은 아니다 |
| 지연 | 모델의 생성 시간과 사용자가 첫 소리를 듣는 시점을 따로 측정한다 | 처리량이나 전체 음성 생성 속도만으로 첫 응답 지연을 대신하지 않는다 |

F5-TTS의 평가는 영어와 중국어 자료를 사용하므로 논문 점수를 한국어 품질의 증거로 옮기지 않는다. 한국어 평가 문장, 청취자와 실제 재생 경로는 별도로 준비한다. 턴 종료, 끼어들기와 작업 취소는 [[Realtime-Voice-Architecture|실시간 음성 에이전트]]에서 다룬다.

## 공개 가중치 모델도 표현 제어와 사용 조건을 따로 평가한다

2026-10-26 Fish Audio의 Drama 3 발표, 모델 카드와 배포 라이선스를 대조했다. Drama 3는 여러 화자와 긴 콘텐츠를 대상으로 하며, 대괄호 안의 자연어 지시로 발화의 감정과 표현을 제어하는 공개 가중치 TTS다. 감정 지시를 지원한다는 사실과 한국어 발음 정확도, 긴 발화의 일관성 및 다른 상용 모델보다 낫다는 평가는 별개다.

비교 실험에서는 같은 문장을 중립 발화와 감정 지시를 넣은 발화로 각각 생성해 내용 누락, 숫자 발음과 화자 유지를 확인한다. 이는 평가 제안이며 여기서 음성을 생성하거나 청취 비교하지 않았다. 공개 모델 카드의 H200과 Seed-TTS 영어 프롬프트 기반 서빙 측정도 한국어 품질이나 다른 GPU의 지연으로 옮기지 않는다.

**가중치 공개는 제한 없는 상업 이용을 뜻하지 않는다.** Fish Audio Community License v1.0(2026-10-13)의 주요 배포 구분은 다음과 같다.

- 제한된 상업 이용 허가는 사용자와 계열사의 직전 12개월 전체 매출 합계가 50만 달러 미만인 경우를 대상으로 한다. 특정 고객에게 모델을 설치하거나 전달하는 경우에는 그 고객의 매출 조건도 적용한다. 기준 도달 시 통지와 전환 기간은 III(b)를 따로 확인한다.
- 제3자가 제공한 텍스트나 음성으로 직접 생성할 수 있게 하는 Hosted Service는 매출과 목적에 관계없이 별도 서면 계약이 필요하다. 완성 음성만 납품하는 제작 서비스와 비상업 연구 데모 등 III(c)의 제외 항목은 구분한다.
- 배포와 제품 표시 의무, 음성 모사의 동의 또는 다른 법적 권한 등 나머지 조건도 따른다. 모델 카드 상단의 라이선스 메타데이터만 보지 않고 함께 배포된 `LICENSE`의 버전과 본문을 확인한다.

위는 도입 전 확인할 조건이며 특정 사업의 이용 허용 여부를 판정한 결과는 아니다. 모델 이름, 평가 언어와 조건, 배포 라이선스를 고정한 뒤 성능과 운영 비용을 비교한다.
