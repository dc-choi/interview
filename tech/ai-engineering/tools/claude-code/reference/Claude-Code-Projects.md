# Claude Code Projects의 조율과 작업 격리

Projects는 목표를 중심으로 작업을 여러 스레드에 나누고 결과를 모으는 작업 공간이다. 아래 제품 동작은 2026-09-17 베타 발표를 2026-10-24에 대조한 범위다. 현재 계정의 제공 여부나 이후 기능 확대를 확인한 기록은 아니다.

## 조율, 실행과 기억을 나눈다

| 구성 | 역할 |
|---|---|
| 코디네이터 | 요청 범위를 정하고 새 스레드나 기존 스레드에 위임하며 결과를 검토하고 합침 |
| 작업 스레드 | 별도 브랜치와 저장소 사본을 가진 Claude Code 클라우드 세션 |
| 공유 메모리 | 스레드들이 프로젝트 맥락을 기록하고 다시 참조 |
| 라이브러리 | 사용자가 추가한 파일과 생성한 산출물을 모음 |

스레드는 필요하면 서브에이전트, 루프와 워크플로우로 작업을 더 나눌 수 있다. 메인 대화에서 진행을 조율하거나 개별 스레드에 들어가 방향을 바꾼다.

## 격리와 충돌 해결은 별개다

각 스레드가 별도 사본을 써도 같은 코드를 바꾸면 일반 PR처럼 병합 충돌을 해결해야 한다. 코디네이터가 있다는 사실을 충돌 방지나 통합 정확성의 보장으로 해석하지 않는다.

운영 시에는 파일별 담당 범위, 통합 순서와 테스트를 먼저 정하는 방법을 제안한다. 공유 메모리의 결정도 현재 소스와 승인 상태에 대조하고, 결과 보고와 실제 테스트 통과를 구분한다.

## 병렬 실행의 비용과 제공 범위

스레드마다 전체 세션이 실행되므로 병렬화하면 사용량 한도에 더 빨리 닿을 수 있다. 발표는 프로젝트별 사용량 확인과 코디네이터, 작업 스레드의 모델 및 effort 선택을 안내한다.

발표 당시에는 클라우드 실행만 제공했고 로컬 실행은 예정이었다. 초기 베타도 일부 Pro와 Max 사용자 대상이었다. 이 발표만으로 현재 로컬 실행이나 플랜별 지원을 단정하지 않고 도입 시 최신 문서와 계정 화면을 확인한다.
