# AI 인용과 통계의 원출처 검증

인용 링크의 존재, 인용 페이지에 숫자가 있는지, 원연구가 같은 주장을 지지하는지는 서로 다른 검사다. 검색과 RAG로 실제 문서를 찾았어도 그 문서와 무관한 결론을 붙일 수 있다.

## 검증 단위

| 검사 | 확인할 내용 |
|---|---|
| 출처 식별 | 실제 문서, 저자, 발행일과 개정판이 있는가 |
| 주장 대응 | 주장에 해당하는 문장, 표와 분모가 있는가 |
| 원출처 추적 | 재인용 페이지를 넘어 측정 또는 연구를 수행한 자료에 도달하는가 |
| 맥락 보존 | 조사 대상, 국가, 시점, 질문과 측정 단위가 같은가 |
| 적용 가능성 | 관찰 결과를 인과관계나 다른 모집단의 예측으로 확대하지 않았는가 |

숫자 자체가 같아도 대상이 직원에서 관리자, 시점이 일간에서 연간으로 바뀌면 다른 주장이다. 여러 AI의 일치는 독립 검증이 아니다. 같은 재인용 페이지를 반복 참조했을 수 있다.

## 통계 인용 추적의 사례와 한계

2026-10-28 Trakkr의 Zombie Stats 조사는 5개 AI 서비스에 200개 질문을 주고, 인용된 통계 1,285건을 표본으로 골라 최대 5페이지까지 추적했다. 연구 도달과 내용 일치가 40%, 연구에는 도달했으나 내용이 달라진 경우가 8%였다. 40%는 잠기거나 사라진 자료 등으로 확인하지 못했고, 11%는 원연구를 찾지 못했으며 1%는 로딩 실패였다.

이는 나머지 60%가 거짓이라는 뜻이 아니다. 서비스별 인용량에 따른 가중치와 AI 판정, 사람의 표본 재검토를 거친 추정치다. 모든 AI 답변이나 모든 분야의 정확도로 일반화하지 않는다. 같은 조사에서 인용 페이지에 숫자가 있는 비율은 82%, 최초 인용 페이지가 원연구인 비율은 21%였다. 이는 원연구까지 추적해 내용이 일치한 비율과 다르다. 원연구에 도달한 통계 중 변형 비율은 17%로, 전체 표본을 분모로 삼은 8%와 혼동하지 않는다.

## 문체 탐지와 내용 검증

위키백과의 WikiProject AI Cleanup은 AI 사용 추정과 지침 위반 콘텐츠의 정리를 다룬다. 상투어, 반복 구조와 작성 속도는 조사 단서다. 그것만으로 작성 도구나 허위를 확정하지 않는다. 실제 출처가 본문을 뒷받침하는지와 문서 정책을 충족하는지 확인하는 편이 삭제나 수정 판단에 직접 연결된다.

제공된 2026-10-28 GeekNews 발췌의 Pangram 탐지 비율(2025년 말 약 20%, 2026년 초 15~16%)은 원자료와 표본을 확보하지 못했다. 정책 효과, 탐지 성능 변화와 실제 작성 비중 변화 중 무엇인지 미확인이다. 이 수치는 실제 AI 문서 비율의 확정값으로 사용하지 않는다.

## 기록 절차

1. 주장, 숫자, 단위와 분모를 분리한다.
2. 원문 표나 절을 찾아 재인용 전후 표현을 비교한다.
3. 원자료 접근 실패와 내용 불일치를 별도 상태로 남긴다.
4. 확인 가능한 범위만 지식 본문에 쓰고 미확인 수치는 출처와 후속 확인 항목으로 보존한다.
