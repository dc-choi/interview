# 합성 비전 데이터와 인식 모델 평가

합성 이미지는 드물거나 확보하기 어려운 상황의 학습 데이터를 보충하는 수단이다. 이미지 생성 성공과 그 이미지로 학습한 인식 모델의 성능 향상은 서로 다른 결과다.

## 생성 모델과 인식 모델을 구분한다

먼저 실제 데이터에서 부족한 조건을 찾는다. 생성 모델은 해당 조건의 이미지를 만들고, 인식 모델은 검수한 실제 이미지와 합성 이미지를 이용해 객체나 결함을 구별하도록 학습한다. 두 모델의 입력, 출력과 평가 기준을 따로 둔다.

합성 방식에는 기존 이미지에 객체를 넣는 방식과 이미지 및 객체를 변형하는 방식이 있다. Superb Curate의 공식 가이드는 두 방식을 제공하며, 생성 이미지와 annotation을 검토하고 필요하면 수정하도록 안내한다. 합성 데이터 추가 후에도 일부 데이터셋에서 성능이 개선되지 않는 예를 함께 제시한다.

## 제어할 조건을 정한다

Titan Image Generator G1 V2의 공식 서비스 카드에서 확인한 기능과 한계다. 카드 자체의 적용 기준은 2024-12-03이며, 현재 리전별 제공 여부나 모델 수명주기를 검증한 문서는 아니다.

| 방식 | 제어하는 대상 | 검수할 부분 |
|---|---|---|
| Text-to-image | 문장으로 지정한 장면 | 실제 작업 환경과 객체가 표현됐는가 |
| Image conditioning | 참조 이미지의 구성과 윤곽 | 유지해야 하는 위치와 형상이 바뀌지 않았는가 |
| Inpainting | 마스크 영역의 객체 교체나 제거 | 경계, 라벨과 주변 장면이 일관되는가 |

생성기는 명시적인 3D 물체 모델이나 조명 물리를 갖는 시뮬레이터가 아니다. 그럴듯한 이미지에도 비현실적인 형태나 조명이 생길 수 있다. 따라서 화면 품질만으로 물리적 타당성이나 학습 적합성을 판정하지 않는다.

## 인식 성능으로 채택 여부를 정한다

다음은 합성 데이터 도입을 평가하기 위한 실험 설계 제안이다.

1. 실제 데이터만 학습한 모델을 기준선으로 두고, 합성 데이터를 추가한 모델과 비교한다.
2. 생성이나 튜닝에 사용하지 않은 실제 평가 데이터를 분리한다. 같은 원본 이미지에서 만든 변형이 학습과 평가 양쪽에 들어가지 않게 한다.
3. 전체 평균과 함께 부족했던 조건, 흔한 정상 조건의 오탐과 미탐을 나누어 확인한다.
4. 합성량을 단계적으로 바꾸고 생성, 라벨 검수, 재학습 비용까지 기록한다. 특정 사례의 혼합 비율을 보편적인 최적값으로 사용하지 않는다.

합성 이미지의 모양을 잘 구별하는 모델과 현장의 결함을 잘 구별하는 모델은 다를 수 있다. 채택 기준은 생성량이나 임베딩 분포의 유사성만이 아니라 실제 평가 데이터에서의 개선과 회귀 여부다. 이 문서는 실험 방법을 정리한 것이며 모델을 직접 학습하거나 사례의 개선율을 재현한 기록은 아니다.
