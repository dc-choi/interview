# 헬름홀츠 머신과 wake-sleep 학습

헬름홀츠 머신은 관측 데이터를 잠재 표현으로 바꾸는 인식 모델(recognition model)과, 잠재 표현에서 데이터를 만들어 내는 생성 모델(generative model)을 한 신경망 안에 함께 두고, 각 입력의 원인을 알려 주는 교사 없이 학습하는 구조다. Dayan, Hinton, Neal, Zemel이 1995년 Neural Computation에 발표했다. 논문은 헬름홀츠를 따라 인간의 지각 체계를 감각 입력의 그럴듯한 원인을 추론하는 통계적 추론 엔진으로 본다고 밝힌다. 두 모델을 번갈아 학습시키는 방법이 같은 해 Hinton, Dayan, Frey, Neal이 Science에 발표한 wake-sleep 알고리즘이다.

## Mental model

- 생성 모델은 세계에 대한 가설이다. 상위 잠재 원인에서 하위 관측으로 내려가며(top-down) 데이터가 어떻게 만들어지는지를 확률로 표현한다.
- 인식 모델은 그 가설을 거꾸로 쓰는 빠른 추론기다. 관측에서 위로 올라가며(bottom-up) 이 데이터를 만들었을 법한 잠재 원인의 분포를 바로 출력한다.
- 한 패턴을 설명할 수 있는 원인의 조합이 지수적으로 많아, 정확한 사후분포 p(원인 | 데이터)를 계산하거나 우도를 직접 최대화하기 어렵다. 인식 모델은 데이터마다 반복 계산을 돌리는 대신 한 번의 상향 계산으로 근사 사후분포를 낸다. 지금 용어로는 상각 추론(amortized inference)에 해당한다.
- 학습 목표는 계산하기 쉬운 관측 확률의 하한을 최대화하는 것이다. wake-sleep 논문은 같은 목표를 입력을 전달하는 데 드는 설명 길이(description length)의 최소화로 쓰며, 그 비용이 물리계의 헬름홀츠 자유 에너지와 같은 꼴이라고 설명한다. 설명 길이와 실제 음의 로그 확률의 차이는 인식 분포와 진짜 사후분포 사이의 KL 발산이다.

## wake-sleep 알고리즘

| 단계 | 데이터 출처 | 고정하는 쪽 | 갱신하는 쪽 |
| --- | --- | --- | --- |
| wake | 실제 관측 데이터를 인식 모델에 넣어 잠재 상태를 표본 추출 | 인식 가중치 | 생성 가중치: 각 층이 아래층 활동(최하층은 관측)을 더 잘 재구성하도록 |
| sleep | 생성 모델이 무작위로 만든 공상(fantasy) 데이터 | 생성 가중치 | 인식 가중치: 공상 데이터를 만든 실제 잠재 상태를 맞히도록 |

- 두 단계 모두 국소적으로 얻을 수 있는 정보만 쓰는 델타 규칙으로 가중치를 고친다. 논문은 지도학습의 두 문제, 곧 원하는 출력을 지정하는 교사가 필요하다는 점과 오차 정보를 모든 연결에 전달할 방법이 필요하다는 점을 모두 피한다고 설명한다.
- 논문이 스스로 밝힌 약점은 sleep 단계가 학습 데이터가 아니라 공상 데이터에 맞춰 인식 가중치를 최적화한다는 점이다. 학습 초기에는 공상 데이터의 분포가 학습 데이터와 크게 다르다.
- 두 단계가 하나의 비용을 함께 줄이지는 않는다. wake 단계는 하한의 비용을 낮추지만 sleep 단계는 인식 분포와 사후분포의 자리를 바꾼 KL 발산을 줄이며, 헬름홀츠 머신 논문도 두 절차가 줄이는 단일 비용 함수는 없다고 밝힌다.
- 인식 분포는 아래층 상태가 주어지면 같은 층의 단위들이 서로 조건부 독립인 곱 분포(factorial)라서, 대체로 진짜 사후분포를 정확히 맞출 수 없다. 위층의 단위 a나 b 중 하나만 켜서 설명할 수 있고 둘 다 켜서는 안 되는 explaining away 효과를 담지 못하는 것이 예다. 대신 wake 단계가 생성 모델을 사후분포가 거의 곱 분포가 되는 쪽으로 이끌어 손실을 줄인다.
- 손글씨 숫자 실험에서는 숫자별로 하나씩, 모두 10개의 모델을 따로 학습한 뒤, 새 숫자를 가장 짧게 설명하는 모델을 골라 인식했다. 모든 숫자로 학습한 큰 네트워크 하나도 새 숫자를 숫자별 네트워크들에 가깝게 압축했다. 학습 규칙 자체에는 레이블이 없지만, 숫자별 모델을 나눈 분류 실험은 숫자 구분 정보를 써서 데이터를 나눈 것이므로 정답을 전혀 쓰지 않은 인식 실험으로 요약하지 않는다.

## 이후 모델과의 관계

- 변분 오토인코더(VAE)도 인식 모델 q(z|x)와 생성 모델 p(x|z)를 함께 두지만, 변분 하한을 재매개변수화한 추정량 하나로 두 모델의 매개변수를 함께 학습한다. Kingma와 Welling은 wake-sleep을 같은 부류의 연속 잠재 변수 모델에 쓸 수 있는 온라인 학습법으로 소개하고, 두 목적함수를 동시에 최적화하며 그 둘이 함께 주변 우도(의 하한) 최적화에 대응하지 않는다는 점을 단점으로, 이산 잠재 변수 모델에도 쓸 수 있다는 점을 장점으로 든다.
- 인식 모델과 생성 모델을 함께 학습하는 구성은 위의 VAE로 이어진다. 그보다 넓은 생성 모델 계열로의 계보는 이 문서의 출처로 확인하지 않았다. GPT 같은 자기회귀 언어 모델은 다음 토큰을 예측하는 단일 생성 모델로 학습하며, 인식 모드와 생성 모드를 번갈아 학습하지 않는다. 역사적 영감과 구조적 동일성은 구분한다.

## 학습 체크포인트

- 인식 모델과 생성 모델 각각의 입력, 출력과 방향을 말할 수 있는가?
- wake 단계와 sleep 단계에서 어떤 데이터로 어느 가중치를 갱신하는지 구분할 수 있는가?
- 정확한 사후분포 대신 인식 모델을 쓰는 이유(계산 비용, 상각 추론)를 설명할 수 있는가?
- VAE가 wake-sleep과 무엇을 공유하고 무엇을 바꿨는지 한 문장으로 말할 수 있는가?
