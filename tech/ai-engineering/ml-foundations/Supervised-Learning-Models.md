# 지도학습의 기본 모델과 손실 함수

지도학습은 입력과 정답(라벨) 쌍으로 이루어진 데이터에서 입력을 출력으로 대응시키는 함수를 추정한다. 실제 관계 `f`는 알 수 없으므로 데이터로 가설 함수 `h`를 고르고, 학습에 없던 입력에서도 `h`가 `f`와 같은 답을 내기를 기대한다. 출력이 비와 비 아님, 위조와 정상처럼 이산 범주이면 분류(classification), 광고비에 따른 매출처럼 실수이면 회귀(regression)다.

이 문서는 고전 모델이 판단 경계를 정하는 방식, 학습이 줄이려는 손실 함수, 과적합을 막는 정규화를 다룬다. 성능을 확인하는 데이터 분할(holdout, k-fold 교차 검증)과 평가 지표는 [[Supervised-Learning-Validation-and-Metrics|지도학습 검증과 평가 지표]]에 있다.

## 모델별 판단 방식

| 모델 | 새 입력을 판단하는 방식 | 강점 | 주의할 점 |
|---|---|---|---|
| k-최근접 이웃(k-NN) | 가까운 학습 표본 k개의 다수결 | 학습은 저장뿐이고 경계 모양을 가정하지 않는다 | 예측마다 거리를 계산하고 특징 단위에 민감하다 |
| 선형 분류기(perceptron) | 가중합의 부호로 경계의 어느 쪽인지 정한다 | 계산이 싸고 가중치로 해석할 수 있다 | 직선(초평면)으로 나뉘지 않는 데이터를 못 맞춘다 |
| 로지스틱 회귀 | 가중합을 logistic 함수에 넣어 0과 1 사이 값을 낸다 | 확신 정도를 함께 낸다 | 경계는 여전히 선형이다 |
| 서포트 벡터 머신(SVM) | 두 클래스와의 거리(마진)가 가장 큰 경계를 고른다 | 마진으로 일반화를 꾀하고 커널로 비선형 경계를 만든다 | 커널과 `C`를 골라야 한다 |

어느 모델도 모든 데이터에서 낫지 않다. 예측하려는 실제 함수의 모양과 데이터의 잡음에 따라 맞는 모델이 다르므로, 후보를 같은 분할과 지표로 비교해 고른다.

## k-최근접 이웃

1-최근접 이웃은 새 입력과 가장 가까운 학습 표본 하나의 클래스를 그대로 쓴다. 가장 가까운 점 하나가 잡음이나 예외라서 주변 다수와 클래스가 다르면 그 점을 따라가므로, k-NN은 가까운 k개 중 가장 많은 클래스를 고른다. scikit-learn `KNeighborsClassifier`의 기본값 `weights='uniform'`은 이웃마다 같은 표를 주고, `weights='distance'`는 거리의 역수에 비례한 가중치를 준다. k는 검증 데이터로 고르는 하이퍼파라미터다.

- **모델 대신 표본을 저장한다:** 일반화된 내부 모델을 만들지 않고 학습 표본을 저장해 두었다가 예측 때 계산한다(instance-based learning). 단순 구현(brute force)은 질의마다 모든 표본과 거리를 계산하므로 질의 시간이 `O[D N]`이다(D는 특징 수, N은 표본 수).
- **검색 구조로 줄인다:** K-D tree는 저차원(대략 D < 20)에서 빠르지만 차원이 커지면 비효율적이 된다(차원의 저주). Ball tree는 고차원에서 K-D tree보다 나을 수 있지만 실제 성능은 데이터 구조에 달려 있다. 대규모 벡터에서 근사 최근접 이웃을 찾는 색인은 [[Vector-Similarity-Search|벡터 유사도 검색]]에서 다룬다.
- **특징 단위를 맞춘다:** 0~1,000 범위의 특징과 1~10 범위의 특징을 그대로 쓰면 거리가 앞의 특징에 좌우되고 뒤의 특징은 사실상 무시된다. 표준화하면 두 특징이 비슷하게 반영되지만, 범위가 작아 묻혀 있던 특징이 예측에 쓸모없는 잡음이면 스케일링이 오히려 과적합을 늘릴 수 있다.

## 선형 분류기와 perceptron 학습 규칙

습도 `x1`과 기압 `x2`로 비를 예측한다면, 각 입력에 가중치를 곱해 더한 값이 0 이상이면 1(비), 아니면 0(비 아님)을 낸다.

- 가중치 벡터 `w = (w0, w1, ..., wn)`와 입력 벡터 `x = (1, x1, ..., xn)`로 쓰면 판단식은 두 벡터의 내적 `w0 + w1 × x1 + ... + wn × xn`이 0 이상인지다. 입력 앞에 상수 1을 붙여 절편(bias) `w0`를 다른 가중치와 같은 방식으로 다룬다.
- 내적이 0인 점들이 결정 경계다. 특징이 둘이면 직선, 셋 이상이면 초평면이다. 경계의 기울기와 위치는 입력이 아니라 가중치가 정한다.

perceptron 학습 규칙은 무작위 가중치에서 시작해 학습 표본 `(x, y)`를 하나씩 보며 가중치를 고친다. `h(x)`는 현재 가중치의 예측(0 또는 1)이다.

`w_i ← w_i + α × (y − h(x)) × x_i`

- 예측이 맞으면 `y − h(x) = 0`이라 가중치가 그대로다.
- 실제는 1인데 0으로 예측하면 각 가중치에 `α × x_i`를 더해 이 입력의 내적을 키운다. 실제는 0인데 1로 예측하면 같은 양을 빼서 내적을 줄인다.
- α(학습률)가 클수록 표본 하나가 가중치를 크게 바꾼다.

데이터를 여러 번 반복해 보며 가중치가 안정되기를 기대하지만, 어떤 직선으로도 두 클래스를 완전히 나눌 수 없으면(선형 분리 불가능) 매 반복마다 틀리는 표본이 남아 가중치가 계속 바뀐다. 실제 데이터는 잡음과 이상치 때문에 선형 분리 가능하지 않은 경우가 많다.

## 확신 정도: hard threshold와 logistic 함수

0 아니면 1만 내는 계단형 판단(hard threshold)은 경계 바로 옆의 점과 멀리 떨어진 점을 똑같이 확신한다. 계단 모양이라 미분을 이용해 가중치를 조정하기도 어렵다.

로지스틱 회귀는 가중합 `z`를 logistic(sigmoid) 함수 `1 / (1 + e^(−z))`에 넣어 0과 1 사이의 실수를 낸다(soft threshold). 경계에서 멀수록 0이나 1에 가까워지므로 0.7 같은 값을 확신 정도로 읽을 수 있다. 다만 이 값을 실제 빈도와 맞는 확률로 쓰려면 보정(calibration)을 따로 확인한다([[Supervised-Learning-Validation-and-Metrics#임계값, ROC와 유병률|임계값과 보정]]).

## SVM: 마진이 가장 큰 경계

학습 데이터를 완벽히 나누는 직선은 여럿이다. 한쪽 클래스에 바짝 붙은 경계는 학습 데이터를 모두 맞혀도, 그 클래스 근처에 새로 들어온 점을 반대쪽으로 분류하기 쉽다.

- SVM은 각 클래스의 가장 가까운 학습 표본과의 거리(마진)가 가장 큰 초평면, 곧 최대 마진 분리자를 고른다. scikit-learn 문서는 일반적으로 마진이 클수록 분류기의 일반화 오차가 낮다고 설명한다.
- 결정 함수는 학습 데이터의 일부인 서포트 벡터에만 의존한다. 선형 분리 가능하면 마진 경계 위의 표본, 그렇지 않으면 마진 안쪽의 표본이 서포트 벡터다.
- 완벽히 나눌 수 없는 데이터는 일부 표본이 마진을 넘도록 허용하고 그 거리에 벌점을 준다. `C`가 벌점의 세기이며 정규화 강도의 역수처럼 동작해, `C`를 줄이면 정규화가 강해진다.
- 선형, 다항식, RBF, sigmoid 같은 커널 함수를 쓰면 더 높은 차원의 특징 공간에서 경계를 찾는 효과가 있다. 한 클래스가 다른 클래스에 둘러싸여 원 안쪽에 몰린 데이터처럼 직선으로 나눌 수 없는 경우도, 원래 공간에서는 곡선인 경계로 나눈다.

## 회귀

회귀는 입력을 연속값으로 대응시킨다. 지난 달들의 광고비와 매출을 점으로 찍고, 새 광고비의 예상 매출을 읽을 수 있는 직선(선형 회귀)을 찾는 것이 예다. 분류가 클래스를 나누는 경계를 찾는다면 회귀는 점들의 관계를 근사하는 선을 찾으며, 어떤 선이 좋은지는 다음 절의 손실로 정한다.

## 손실 함수

손실 함수는 가설이 얼마나 나쁜지를 수로 나타낸다. 표본마다 실제값과 예측값으로 손실을 계산해 모두 더한 값이 경험 손실(empirical loss)이며, 학습은 이를 줄이는 가설을 찾는 최적화 문제다.

| 손실 | 표본 하나의 값 | 쓰임과 성질 |
|---|---|---|
| 0-1 손실 | 맞으면 0, 틀리면 1 | 분류. 합이 틀린 표본 수다 |
| L1 손실 | `abs(실제 − 예측)` | 회귀. 오차 크기에 비례해 벌한다 |
| L2 손실 | `(실제 − 예측)^2` | 회귀. 오차를 제곱해 큰 오차를 훨씬 무겁게 벌한다 |
| Huber 손실 | 오차 `e`의 절댓값이 δ보다 작으면 `0.5 × e^2`, 아니면 `δ × (abs(e) − 0.5 × δ)` | 회귀. 0 근처에서는 L2처럼 매끄럽고 큰 오차는 δ배한 L1처럼 선형으로 벌해 L2보다 이상치에 덜 끌려간다. PyTorch `HuberLoss`의 δ 기본값은 1이다 |

오차가 1인 표본 둘과 오차가 2인 표본 하나는 L1 합이 모두 2지만 L2 합은 2와 4다. 이상치의 큰 오차까지 줄이는 것이 중요하면 L2가 맞고, 이상치가 많고 그것을 모델링할 필요가 없으면 L1이 이상치에 덜 끌려간다. 평가 지표 MAE와 MSE는 각각 L1과 L2 손실의 평균이다([[Supervised-Learning-Validation-and-Metrics#회귀 지표와 로그 오차|회귀 지표]]).

## 과적합과 정규화

과적합(overfitting)은 모델이 학습 데이터에 너무 가깝게 맞춰져 다른 데이터로 일반화하지 못하는 상태다. 이상치 하나까지 피해 가는 구불구불한 경계나 모든 점을 지나는 회귀 곡선은 학습 손실이 0이어도, 새 데이터에서는 이상치를 무시한 직선보다 나쁠 수 있다. 손실만 최소화하면 이런 가설이 선택된다.

정규화(regularization)는 비용에 가설의 복잡도를 더해 더 단순한 가설을 선호하게 만든다.

`cost(h) = loss(h) + λ × complexity(h)`

- λ가 클수록 복잡한 가설이 비싸진다. λ가 0이면 손실만 본다.
- 복잡도를 무엇으로 잴지는 모델에 맞게 정한다. 선형 모델에서는 가중치의 크기(L1, L2 정규화)를 쓰고, SVM에서는 위의 `C`가 같은 역할을 거꾸로 맡는다.
- 학습 데이터의 손실만 보면 λ = 0이 언제나 유리하므로, λ는 학습에 쓰지 않은 데이터로 일반화를 확인하는 holdout이나 k-fold 교차 검증으로 고른다([[Supervised-Learning-Validation-and-Metrics#세 데이터의 역할|세 데이터의 역할]]).

## 이해 확인

1. 가장 가까운 점 하나는 빨강이지만 가까운 다섯 점 중 넷이 파랑인 입력을 1-NN과 5-NN이 각각 어떻게 분류하는지 설명한다.
2. perceptron 규칙에서 예측이 맞은 경우, 실제 1을 0으로 예측한 경우, 실제 0을 1로 예측한 경우의 가중치 변화를 `α = 0.1`, `x = (1, 2, 3)`으로 계산한다.
3. 오차가 `[1, 1, 10]`인 예측의 L1 합과 L2 합을 구하고, 10짜리 오차가 측정 오류일 때 어느 손실이 학습을 덜 왜곡하는지 설명한다.
4. λ를 0으로 둘 때와 매우 크게 둘 때 각각 어떤 가설이 선택되는지, λ를 학습 손실이 아니라 검증 데이터로 골라야 하는 이유와 함께 설명한다.
