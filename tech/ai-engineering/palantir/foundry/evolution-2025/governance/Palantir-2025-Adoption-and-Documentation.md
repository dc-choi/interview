# 2025 문서, Walkthrough와 교육 콘텐츠의 역할

2025년 공식 release note의 변경 이력을 정리한다. 2026년 현재 지원/요금/수명주기 보장이 아니며, 실제 적용 전 해당 버전의 정본 문서와 enrollment 설정을 확인한다.

## 사용자 제작 문서와 공식 정본

3월 deprecated legacy documentation archive가 Custom documentation에서 제거됐다. public platform docs와 enrollment `/docs` mirror, 사용자가 repo에서 만든 custom documentation은 영향이 없었다. Legacy API/Management archive를 최신 reference로 간주하지 않는다.

3월 Previous/Next navigation, 4월 tabbed language 선택 기억, Org platform title을 반영한 custom documentation 이름과 launcher 진입점은 발견성을 개선했다. 내용의 현재성이나 권한이 자동 바뀌는 기능은 아니다.

## Walkthrough와 Flow Capture

- 3월 Walkthrough GA 공지는 3월 17일 주 default enable을 알렸다. 사용자/그룹별 Control Panel 제한이 가능하며 published walkthrough와 관련 resource 모두에 Viewer 권한이 필요하다.
- 여러 app에 걸친 targeted tutorial, media와 progress resumption, metrics, Workshop 특정 widget highlight가 포함됐다.
- 6월 Carbon module highlight, 10월 단일 resource walkthrough가 확대됐다. Walkthrough start checkpoint는 시작 사실과 사용자 응답을 기록하지만 실제 숙련을 입증하지 않는다.
- 10월 Flow Capture는 workflow 수행 화면/음성에서 초안을 만들고 screenshot을 검열/편집해 Notepad/Walkthrough 등으로 export하는 경로였다. 초안 내용과 자동 설명은 실제 절차와 대조해야 한다.

## 학습 자료의 범위

2월 Learn 공지는 Quiver 분석, 데이터 보호 Deep Dive와 business process mining, 첫 Ontology Function Speedrun을 소개하고 persona별 training track과 one-page guide를 연결했다. 11월 Foundry Aware와 인증 eligibility, agentic human/AI 과정과 data science fundamentals 등이 확대됐다.

이 공지는 과정의 존재와 당시 분량/조건의 증거다. 사용자가 수강했거나 숙달했다는 기록이 아니며, 당시 무료/인증 자격 조건을 현재 상시 정책으로 기록하지 않는다. 학습 목적은 분석, 보호, 프로세스와 Function 구현으로 나눠 실제 적용 과제로 이해를 확인한다.
