# 커머스 핵심 도메인 영역

커머스 시스템 기획과 설계의 고민이 나뉘는 4개 영역. 네 문서는 서로 물려 있어 따로 설계할 수 없다 — 회원 등급이 가격을 바꾸고, 상품의 배송 정책이 주문 상태를 갈라놓는 식이다.

## 목차

- [x] [[Commerce-Member|회원(Member)]] — 구매자와 판매자, 멤버십, 계정 정책, SSO와 데이터 통합, 마이페이지
- [x] [[Commerce-Product|상품(Product)]] — 상품 정보 4분류, 상품상세 페이지 복잡성, 품목 vs 전시 카테고리, 기획전, 물류와 배송, 오프라인 바코드의 한계
- [x] [[Commerce-Pricing|가격(Pricing)]] — 기준가와 판매가, 세일과 쿠폰, 딜, 적립금, 카드 행사, 무료배송의 경제학
- [x] [[Commerce-Order|주문(Order)]] — 주문 상태 머신, 장바구니와 위시리스트와 주문서, 클레임
