# AI 소프트웨어 복제와 기술 실사

소프트웨어의 관찰 가능한 동작을 다시 만드는 비용과 고객이 안심하고 업무를 옮기는 비용은 다르다. AI가 구현 비용을 낮추더라도 호환성, 데이터 이전, 성능, 운영 책임과 고객 신뢰를 따로 평가한다. 재구현이 쉬운 제품도 유통과 운영에서 가치가 있을 수 있고, 코드가 복잡한 제품도 수익성이 없을 수 있다.

## 기능 동등성과 업무 대체 가능성

| 확인 층위 | 확인할 내용 |
|---|---|
| 화면과 기능 목록 | 메뉴와 버튼이 존재하는가 |
| 실제 동작 | 같은 입력에서 원하는 결과가 나오는가 |
| 경계 조건 | 큰 파일, 장시간 작업, 실패와 복구에서도 동작하는가 |
| 호환성 | 파일 왕복 저장과 외부 연동에서 정보가 보존되는가 |
| 전문 업무 | 색상, 글꼴, 접근성, 감사와 지원 조건까지 충족하는가 |
| 총비용 | 구축, 검수, 수정과 운영까지 감당하는가 |

비슷한 화면을 빠르게 만든 데모와 전문 사용자의 전환 가능성을 같은 지표로 재지 않는다. 바이너리 크기와 코드 줄 수도 실제 메모리, 지연과 안정성의 대용 지표로 고정하지 않는다.

## 해자가 남는 조건

- **책임:** 실패 시 누가 복구하고 배상하는지, 그 약속을 지킬 품질 체계와 재원이 있는지 본다.
- **지속적으로 생성되는 데이터:** 데이터를 보유했다는 사실보다 적법한 접근권, 갱신 과정과 개선 효과를 본다.
- **유통과 신뢰:** 고객의 조달, 보안 심사와 업무 흐름에 자리 잡았는지 확인한다.
- **실물 운영:** 설치, 물류나 현장 지원은 코드 재생성만으로 복제되지 않는다. 인건비와 자본 부담도 함께 생긴다.

기능 복제의 비용 하락이 모든 해자의 소멸을 뜻하지는 않는다. 고객이 결과를 얻도록 책임지는 모델은 차별화 후보지만 책임 비용이 가격을 넘으면 성립하지 않는다.

## AI 기업의 기술 실사

재무 실사는 실제 매출, 유지율과 고객 집중도를 검증한다. 기술 실사는 그 매출을 앞으로도 유지할 시스템과 권리를 검증한다. 둘 중 하나를 다른 하나로 대체하지 않는다.

1. 외부 모델, 프롬프트, 자체 코드와 데이터가 각각 어떤 결과를 만드는지 실제 호출 경로로 확인한다.
2. 모델 가격 상승, API 중단, 품질 하락과 공급사 변경을 가정해 대체 비용과 마진을 계산한다.
3. 학습, 검색과 고객 데이터의 사용권, 갱신권과 계약 종료 시 처리 조건을 확인한다.
4. 핵심 인력이 빠져도 배포, 장애 복구와 평가를 재현할 수 있는지 확인한다.
5. 대표 고객 과제를 재현해 동작과 비용을 비교한다. 화면을 복제했다는 사실만으로 전체 사업을 복제했다고 판단하지 않는다.

얇은 API 연결 코드도 특정 고객 문제를 잘 풀면 유용하다. 인수 가격에서 독자 기술의 프리미엄을 주장할 때는 실제 차별성의 증거가 필요하다. 코드 줄 수를 자산 가치의 기준으로 삼지 않는다.

## 사례와 확인 수준 (2026-10-16)

- **Photoshop 복제 앱 비교:** 제공된 2026-10-13 GeekNews 발췌에는 8K × 8K 이상 캔버스의 브러시 지연, 복사와 실행 취소의 멈춤, 색상과 인쇄 프로파일 및 파일 호환성 문제가 기록돼 있다. 비교 글은 확인했지만 해당 앱을 직접 실행하지 않았다. 개발비 최소 2,000달러와 대안 구독료 비교는 글의 사례 수치이며 현재 가격이나 모든 복제 앱의 성능으로 일반화하지 않는다.
- **경쟁 해자 논쟁:** PhotoCraft가 공개 명세와 관찰된 동작으로 구현됐다는 설명과, 기능 수준이 Photoshop의 절반 미만이라는 추정이 함께 제시된다. 후자는 비교자의 추정이며 코드 독립성, 전체 기능과 법적 적법성을 검증한 결과가 아니다. 재구현 비용 하락과 전문 제품 대체를 구분하는 사례로 사용한다.
- **인수 실사 일화:** ARR 420만 달러, 성장률 40%, 약 600줄의 연결 코드로 된 기업의 인수를 철회했다는 소셜 게시물 발췌를 확보했다. 대상 회사, 계약과 코드에 접근하지 못해 독립 검증하지 않았다. 매출의 실재와 기술적 차별성이 다른 질문이라는 학습 후보로 보존한다.

후속 확인은 앱 버전과 동일한 파일을 고정한 성능 비교, PSD 왕복 저장 검증, 인수 사례의 공개 근거 대조다. 이 기록은 해당 제품을 사거나 팔라는 투자 판단이 아니다.
