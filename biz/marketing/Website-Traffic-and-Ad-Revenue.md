# 웹사이트 트래픽과 광고 수익

무료 도구 사이트의 방문 규모는 수요를 조사할 단서다. 외부 서비스가 추정한 트래픽, 운영자가 측정한 이용량과 광고 수익을 구분해야 수익성을 과대평가하지 않는다.

## 방문자, 방문과 페이지뷰를 구분한다

Similarweb의 Total Visits는 방문(session)의 합계다. 한 번의 방문에 여러 페이지뷰가 포함될 수 있다. 따라서 방문 횟수를 고유 방문자 수나 사람 수로 바꾸어 읽지 않는다.

`페이지뷰 = 방문 수 × 방문당 페이지뷰`는 같은 기간, 기기와 지역 범위의 지표를 사용한다는 조건에서 적용하는 계산이다. 고유 방문자 수에 방문당 페이지뷰를 곱하면 분모가 맞지 않는다. 외부 추정값으로 계산한 결과도 실측값으로 바뀌지는 않는다.

## Page RPM으로 계산해도 수익은 가정에 의존한다

Google AdSense의 정의는 `Page RPM = 예상 수입 ÷ 페이지뷰 × 1,000`이다. 같은 보고 범위의 값을 사용하면 `예상 수입 = 페이지뷰 ÷ 1,000 × Page RPM`으로 정리할 수 있다. 외부 서비스의 전체 페이지뷰 추정치를 AdSense 보고서의 페이지뷰와 같다고 가정하지 않는다.

계산 예로, **가정한** 페이지뷰가 100만이고 Page RPM이 2달러라면 예상 수입은 2,000달러다. 이는 특정 사이트의 수익이나 일반적인 RPM을 뜻하지 않는다. RPM을 모르면 트래픽만으로 실제 광고 수입을 확정할 수 없다. 수입에서 호스팅, 제작과 유지보수 비용을 빼는 사업성 판단도 별도로 필요하다.

## 외부 사이트 사례를 검토하는 순서

다음은 지표 정의에서 도출한 조사 절차다.

1. 대상 도메인, 조회 기간, 지역, 기기와 지표 이름을 확인한다.
2. 고유 방문자, 방문, 페이지뷰와 방문당 페이지뷰를 나누고 실제 보고서와 추정 서비스를 구분한다.
3. 수익 자료가 없으면 RPM을 여러 가정으로 두어 시나리오만 계산한다.
4. 자체 실험에서는 이용량과 광고 보고서, 비용을 함께 비교한다. 다른 사이트의 트래픽을 새 사이트의 예상 성과로 옮기지 않는다.

2026-10-18 공개된 무료 바코드 사이트 소개 영상은 외부 추정 기준 월 약 50만 방문자와 1인당 2페이지 이상을 언급한다. 확보한 전사문만으로는 대상 도메인, 측정 기간과 실제 지표명이 확인되지 않는다. 월 100만 페이지뷰와 온라인 자산 가치는 검증된 사실로 사용하지 않으며, 설명란에 연결된 전체 영상에서 측정 화면과 조건을 추가로 확인해야 한다.

## 반복 작업의 불편을 기능 가설로 바꾼다

무료 도구의 출발점은 기존 서비스의 매출 추정만이 아니라 사용자가 반복하는 작업일 수 있다. 예를 들어 바코드를 하나씩 입력하고 생성하는 작업은 여러 값을 한 번에 처리하는 기능의 후보가 된다. 다만 자신이 겪은 불편 하나가 충분한 시장 수요나 광고 수익을 입증하지는 않는다.

다음은 도구 사이트에 적용할 검증 제안이다.

1. 기존 작업에서 반복 입력과 결과 저장에 드는 시간을 관찰한다.
2. 일괄 처리처럼 불편을 줄일 기능 하나를 만들어 같은 작업의 완료 시간과 오류를 비교한다.
3. 기능을 쓴 사람이 다시 사용하는지 확인하고, 광고 승인과 유입 및 수입은 별도로 측정한다.

Google의 AdSense 준비 안내는 방문자에게 관련 있는 독자적 콘텐츠와 좋은 사용 경험을 요구한다. 2026-10-26 해당 안내를 대조했으며, 위의 기능 실험은 이를 도구 사이트에 적용한 제안이다. 기능 개선만으로 승인이나 수익이 보장된다는 뜻은 아니다.

## 광고 심사와 수익 예측을 분리한다

2026-10-24 Google 공식 안내 대조: 검색에서 AI 콘텐츠를 다루는 기준과 AdSense 광고 게재 정책은 적용 대상이 다르다. Google Search는 순위 조작이 목적이 아닌 적절한 AI 활용을 허용하지만, 그 설명을 광고 승인 보장으로 옮기지 않는다. 게시자 정책은 콘텐츠가 없거나 가치가 낮은 화면, 공사 중인 화면의 광고를 금지하고, 사람의 검토나 선별을 거치지 않은 자동 생성 콘텐츠에도 광고를 두지 않도록 안내한다.

신청 전에는 방문자에게 필요한 독자적인 내용과 사용하기 쉬운 탐색 구조를 점검한다. 다른 사이트의 글이나 삽입한 동영상 같은 외부 자료를 이용할 때는 전문 지식, 개선 제안, 리뷰나 개인적인 의견처럼 자체 내용을 보탠다. 메뉴의 정렬, 글자 가독성과 기능도 확인한다. 확인한 준비 안내에는 글 개수나 글자 수로 승인 여부를 정하는 합격선이 없다.

콘텐츠 부족과 콘텐츠 품질 문제는 점검 항목을 나누어 본다. 2026-11-03 대조한 Google의 미승인 안내는 콘텐츠 부족에 대해 제목만 나열하지 말고 완전한 문장과 문단을 제공하며, 제작 중인 템플릿이나 광고 코드만 있는 빈 테스트 페이지로 신청하지 않도록 설명한다. 콘텐츠 품질 문제에는 방문자가 찾아올 이유가 되는 독자적이고 관련 있는 내용이 필요하다고 안내한다. 심사 범위는 광고 코드를 둔 신청 URL 하나에 한정되지 않고 사이트의 모든 페이지를 포함할 수 있다.

따라서 문장을 늘리는 형식적 보완과 이용자가 얻는 고유한 가치를 따로 점검한다(적용 제안). 이미지나 도구에 실제 사용 설명을 더할 수 있지만, 문단을 추가했다는 사실만으로 품질 문제를 해결하거나 승인을 보장하지 않는다. 개별 거절 사유는 해당 계정의 안내에서 확인한다.

사례로, 한 운영자가 AI로 만든 자신의 두 사이트 결과를 비교했다(2026-10-22 공개 영상). 승인되지 않은 반려견 여행 사이트는 장소 정보 대부분이 공공 데이터였고, 여행 코스에는 직접 방문한 후기가 아니라고 적혀 있었다. 승인된 시계 도구 사이트는 도구 아래에 사용법 안내와 자주 묻는 질문을 두고, 혼자 운영하며 쓰다가 불편한 점을 고쳐 왔다는 제작 방식과 도구가 하지 못하는 일을 적었다. 운영자는 여행 사이트에 자신만 줄 수 있는 내용이 빠져 있었다고 보면서도, 이 차이가 승인 결과의 원인 전부라고 단정하지 않았다.

게시자 정책은 다른 곳의 콘텐츠를 논평이나 선별 없이, 또는 다른 방식으로 가치를 더하지 않고 옮겨 온 화면에 광고를 허용하지 않는다. 확인한 게시자 정책과 AdSense 도움말은 공공 데이터가 이 복제 콘텐츠에 해당하는지 따로 정하지 않으므로, 공공 데이터를 다시 정리하기만 한 페이지가 위험하다는 판단은 조건부다. 방문하지 않았다는 표기는 정직하지만 그 표기만으로 자체 내용이 생기지는 않는다. 표기를 지우거나 경험을 지어내기보다 실제로 확인한 내용과 해석을 더하는 편이 정책의 방향에 맞다(적용 제안). 사용법과 한계를 직접 적은 도구 페이지는 그 도구에서만 얻을 수 있는 설명을 갖춘 쪽에 가깝지만, 이 비교는 승인 기준을 입증하지 않는다.

사이트의 승인 상태와 `ads.txt` 상태도 별개다. `Needs attention`은 해결할 문제가 있다는 뜻이고, `Getting ready`는 확인 중인 상태다. `Ready`는 광고를 게재할 준비가 됐다는 뜻이며 계속 정책을 준수해야 한다. `ads.txt`의 `Authorized`는 게시자 ID를 찾았다는 뜻이므로 콘텐츠 심사 통과와 같다고 보지 않는다.

적용 제안: 도구 사이트에는 실제 동작, 사용법과 한계를 검토하고 빈 페이지와 작동하지 않는 메뉴를 먼저 고친다. 경험을 지어내거나 페이지 수만 늘리는 방식으로 빈틈을 채우지 않는다. 심사 통과, 실제 유입, 광고 수입과 비용을 뺀 이익을 서로 다른 단계로 기록한다.

검색 쪽 기준은 따로 본다. Google Search Central의 콘텐츠 자기 점검 안내는 제품을 실제로 써 보거나 장소를 방문한 것 같은 직접 경험의 전문성이 드러나는지 묻는다. 누가 만들었는지가 방문자에게 분명한지 묻고, 자동화로 콘텐츠를 상당 부분 만들었다면 그 사용 사실이 드러나는지, 어떻게 썼고 왜 유용했는지 배경을 설명하는지도 묻는다. AI 사용 공개는 어떻게 만들었는지 궁금해할 만한 콘텐츠에 권하는 사항이고, 지어낸 작성자 프로필은 기만으로 본다. 이는 검색 품질의 자기 점검 질문이므로 AdSense 승인 요건으로 옮기지 않는다.

### 검토 대기와 계정 준비를 구분한다

2026-11-04 한국어 공식 도움말 대조: `준비 중`의 검토는 일반적으로 며칠이며 경우에 따라 2~4주가 걸릴 수 있다. 이 기간은 승인 보장이나 고정 기한이 아니다. 계정의 필수 설정 작업을 끝내지 않으면 검토가 시작되지 않은 채 준비 중으로 남을 수 있으므로 홈페이지의 미완료 작업도 확인한다. 사이트를 삭제했다가 다시 제출하면 처리가 지연될 수 있다.

문제를 고쳐야 하는 상태는 확인한 한국어 도움말에서 `확인 필요`로 표시한다. 영상이나 다른 언어 화면의 상태명만 대조하기보다 해당 사이트의 상세 안내를 확인한다. 한국어 자격 요건은 만 19세 이상과 제출할 사이트의 HTML 소스 접근, 독창적 콘텐츠와 정책 준수를 안내한다. AI로 만들었다는 사실만으로 코드 접근이나 콘텐츠 요건 충족을 보장하지 않는다. 이 절만 부분 대조했으며 기존 수익 지표와 사례 전체의 검증일은 유지한다.

### 신청 전 접근성과 유입 경로를 확인한다

2026-11-04 Google의 사이트 추가, 미승인 대응과 프로그램 정책을 부분 대조했다. 사이트 연결, 콘텐츠 심사와 트래픽 적격성은 따로 확인한다.

- **연결:** 사이트 추가 안내에는 AdSense 코드, `ads.txt`, 메타 태그 방식이 있다. 연결을 확인한 뒤 검토를 요청하며, 연결 성공을 콘텐츠 승인으로 해석하지 않는다. 플랫폼 연동 사이트는 해당 플랫폼 설정 절차를 따른다.
- **접근:** 제출 URL이 실제 공개되어 있고 AdSense가 비밀번호 없이 접근할 수 있는지 확인한다. `robots.txt`에서는 검색용 Googlebot만 확인하지 않고 광고 크롤러의 접근도 점검한다. 사이트 추가 안내가 명시한 크롤러는 `Mediapartners-Google`과 `Google-Display-Ads-Bot`이다. 계정 활성화 뒤 로그인 보호 페이지에 광고를 표시하기 위한 크롤러 로그인 설정은 별도 절차다.
- **유입:** 자신의 광고 클릭, 반복 수동 클릭과 노출, 봇이나 자동 도구로 광고 클릭과 노출을 부풀리는 행위는 금지된다. paid-to-click, paid-to-surf, autosurf와 클릭 교환 서비스도 금지 대상이다. 유료 유입 전체를 같은 것으로 보지는 않는다. 온라인 광고로 유입시키는 경우에는 방문 페이지가 광고의 약속을 충족하는 등 Google의 방문 페이지 품질 기준을 따라야 한다.

이는 신청과 운영의 점검 항목이며, 방문자 수나 연결 방식만으로 승인 가능성을 계산하는 기준은 아니다. 기존 수익 추정과 운영자 사례 전체를 다시 검증한 것은 아니므로 문서의 기존 검증일은 유지한다.
