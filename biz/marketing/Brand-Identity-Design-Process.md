# 브랜드 정체성 설계 과정

브랜드 정체성을 설계하는 일은 고객에게 어떤 약속을 할지와 그 약속을 제품, 언어와 시각 요소로 어떻게 전달할지 정하는 과정이다. 로고가 바뀌는지보다 고객의 선택과 경험에 어떤 변화가 필요한지를 먼저 확인한다.

## 사업 과제를 디자인 과제로 옮긴다

브랜드를 새로 정비하기 전, 현재 고객과 새로 만나려는 고객, 유지할 자산과 바꿀 경험을 구분한다. 이름, 로고나 색상은 이미 쌓인 인지도와 신뢰를 가질 수 있으므로 일괄 교체를 전제로 시작하지 않는다.

| 확인할 것 | 사용할 근거 | 남길 산출물 |
|---|---|---|
| 사업의 방향 | 목표, 제품 범위와 현재 문제 | 이번 변경의 목적과 제외 범위 |
| 고객의 선택 | 구매/이탈 데이터, 설문과 인터뷰 | 구매 동기, 장애물과 고객 여정 |
| 경쟁 대안 | 고객에게 의미 있는 속성의 비교 | 포지셔닝 가설과 차별화 근거 |
| 전달 방식 | 기존 접점과 사용 장면 | 개선할 디자인 과제와 판단 기준 |

경쟁 대안을 속성 축에 배치하는 지도는 관점을 비교하는 자료다. 비어 있는 위치를 발견했다고 수요가 있거나 그 자리를 차지할 능력이 확인된 것은 아니다. 실제 고객의 선택 이유와 제품이 제공할 수 있는 가치로 다시 확인한다.

## 기능, 감정과 사회적 의미를 구매 상황에 연결한다

JTBD는 고객이 특정 상황에서 이루려는 진전을 기능적, 감정적, 사회적 차원으로 살핀다. 인구통계나 제품 속성만으로 선택 이유를 설명하지 않고, 실제 구매 전후의 사건과 대안을 확인한다. 같은 사람도 상황이 달라지면 다른 진전을 원할 수 있다.

다음은 이 관점을 브랜드 조사에 옮긴 질문이다. 특정 성별이나 연령의 보편적 소비 성향을 뜻하지 않는다.

| 차원 | 조사 질문 | 디자인에 연결할 가설 |
|---|---|---|
| 기능 | 어떤 일을 끝내려고 구매했는가 | 필요한 정보와 사용 순서를 더 쉽게 찾게 한다 |
| 감정 | 선택할 때 무엇이 불안했고 어떤 상태를 원했는가 | 설명과 지원 방식으로 실제 불안을 줄인다 |
| 사회 | 누구와 함께 쓰거나 누구에게 보여 주는 선택인가 | 해당 관계와 장면에 맞는 표현과 접점을 비교한다 |

분위기, 패키지와 공유하기 좋은 경험은 이 가설을 시험할 수단이다. 촬영이나 공유 증가만으로 구매 이유와 매출 효과를 확정하지 않는다. 고객이 표현을 이해했는지, 실제로 선택했는지, 사용 뒤 약속한 가치를 경험했는지를 나누어 관찰한다. 이는 검증 방법의 제안이며 특정 디자인의 성장 배수나 성별 지출 비중을 입증한 결과가 아니다.

2026-10-22 JTBD의 정의와 상황별 선택 설명을 Christensen Institute 자료와 대조했다. 기존 리브랜딩 사례 전체를 다시 검증한 기록은 아니다.

## 탐색과 수렴을 반복한다

Design Council의 Double Diamond는 문제를 넓게 탐색하고 좁혀 정의한 뒤, 여러 해결안을 만들고 시험하는 과정이다. 네 단계는 일직선으로 끝나지 않으며 새 근거에 따라 앞 단계로 돌아간다. 아래는 공식 정의를 2026-10-10에 대조하고 영상의 브랜드 리프레시 사례에 연결한 작업 흐름이다. 단계 순서만으로 성과를 보장하지 않는다.

1. **Discover:** 사업, 고객과 시장의 근거를 넓게 모은다. 현재 고객의 목소리만으로 잠재 고객의 요구를 대체하지 않는다.
2. **Define:** 발견한 문제와 패턴을 디자인 과제로 좁힌다. 무엇을 유지하고 바꿀지, 방향을 고르는 기준을 명시한다.
3. **Develop:** 서로 구분되는 방향을 시안으로 만들고 같은 기준으로 비교한다.
4. **Deliver:** 해결안을 작은 규모로 시험하고 작동하지 않는 안을 버리며 나머지를 개선한다. 브랜드 작업에서는 선택한 방향을 사용 규칙과 접점에 적용하고 결과를 관찰한다.

## 추상적인 속성을 접점의 시안으로 비교한다

따뜻함, 전문성 같은 속성만 나열하면 팀마다 다른 이미지를 떠올린다. Stylescape는 서체, 색상, 이미지와 접점 예시를 한 화면에 구성해 방향을 구체적으로 비교하는 보드다.

- 서로 다른 방향은 동일한 제품과 접점에 적용해 비교한다.
- 의견은 마음에 드는지에서 끝내지 않고 정한 고객, 약속과 디자인 과제에 맞는지로 연결한다.
- 여러 안의 요소를 결합할 때는 결과의 일관성을 다시 본다. 좋아하는 요소를 모두 추가하는 것이 목적은 아니다.
- 화면뿐 아니라 패키지와 인쇄물처럼 실제 사용할 매체에서 확인한다.

웹사이트가 큰 접점이라면 사이트맵으로 주요 고객 여정을 확인하고 대표 화면 소수에서 서체, 색상, 버튼과 이미지의 관계를 먼저 검증할 수 있다. 그 뒤 같은 원칙을 나머지 화면으로 확장한다.

### 채널 배너는 생성 뒤 실제 표시 조건을 확인한다

생성 도구로 시안을 만들었더라도 업로드 규격과 기기별 잘림을 따로 확인한다. 2026-10-30 YouTube 공식 도움말 기준, 일반 크리에이터 채널 배너는 같은 이미지를 컴퓨터, 모바일과 TV에서 다르게 표시한다.

- 최소 업로드 크기는 2048 × 1152px, 화면비는 16:9다. 이 최소 크기에서 글자와 로고의 안전 영역은 1235 × 338px다.
- 권장 크기는 2560 × 1440px이며 파일은 6MB 이하여야 한다. 큰 이미지 전체가 모든 기기에서 보인다고 가정하지 않는다.
- 시안 선택 뒤 미리보기에서 잘림을 확인하고 핵심 글자와 로고의 위치를 조정한다.

이는 플랫폼 규격을 납품 점검에 적용한 기준이다. 생성 속도나 개별 외주 견적만으로 브랜드 적합성, 수정 비용과 고객 성과를 판단하지 않는다. 특정 생성 도구의 품질과 비용 절감 효과는 검증하지 않았다.

## 타이포그래피 시안의 선택 이유를 설명한다

글자 형태를 직접 설계하는 작업에서도 기획서와 브랜드의 기존 표현을 먼저 읽는다. 다음은 원더키 디자이너의 공개 인터뷰에서 다룬 기획서 조사와 제안서 설명을 외주 작업에 적용하는 제안이다. 시안 채택률이나 매출을 높인다고 검증된 공식은 아니다.

1. **조사 근거:** 고객이 제공한 기획서와 공개 콘텐츠에서 반복되는 색깔, 분위기와 전달할 의미를 추린다. 관찰한 사실과 디자이너가 해석한 방향을 구분한다.
2. **형태 선택:** 레퍼런스의 결과물을 복제하기보다 어떤 형태와 리듬이 해당 의미를 전달하는지 설명하고, 서로 다른 시안으로 시험한다.
3. **제안서 연결:** 예쁜 결과물만 나열하지 않고 기획의 요구, 조사 근거, 형태를 고른 이유와 적용 장면을 함께 보여준다. 추상적인 속성과 실제 시안 사이의 판단 과정을 드러낸다.
4. **피드백 기준:** 고객의 수정 요청을 처음 합의한 목적과 대조하고, 취향 차이인지 전달할 의미나 적용 조건의 문제인지 나누어 다음 시안을 정한다.

레퍼런스를 많이 모은 것과 직접 스케치하고 형태를 다듬는 능력은 별개다. 조회수와 팔로어 증가도 제안서의 설득력이나 납품 품질의 증거로 대신 쓰지 않는다. 인터뷰의 AI 품질 전망과 저작권 위험 언급은 특정 도구의 현재 성능이나 법적 판단으로 일반화하지 않는다.

## 체계를 전달하고 적용 상태를 따로 확인한다

가이드에는 로고 사용, 서체의 역할, 색상, 사진 원칙, 문체와 메시지 예시를 포함한다. 확정 규칙과 향후 탐색용 접점 예시는 구분한다. 탐색 시안을 그대로 납품 완료로 취급하지 않는다.

디자인 가이드 완성, 실제 제품과 화면에 적용, 고객 경험의 변화, 사업 성과는 별도의 상태다. 배포와 관찰 기간이 부족하면 리브랜딩의 성과는 미확인으로 남긴다.

영상의 리브랜딩 사례는 22:31 시점에 사업 효과가 아직 평가되지 않았다고 설명한다. 사례의 작업 과정과 매출 증가의 증거를 혼동하지 않는다. 자막을 바탕으로 정리했으며 화면 속 디자인 파일과 실제 배포 결과는 직접 확인하지 않았다.

## 브랜드 약속을 진행 상태 안내까지 연결한다

제품과 서비스의 전달 과정도 고객 접점이다. 고객이 직접 확인하는 상태 화면과 변경을 알려 주는 알림을 구분하고, 화면과 고객 지원에서 같은 최신 상태를 제공한다. 현재 상태뿐 아니라 이전 변경 시각도 남기면 고객이 지연 상황을 설명하거나 다음 행동을 고르는 데 도움이 된다.

브랜드 가이드를 실제 운영에 적용할 때는 배송이나 작업 진행의 표현, 안내 채널과 책임자를 함께 정하는 방법을 검토한다. 아래는 NN/g의 상태 추적 지침을 적용한 점검 제안이다.

- 고객에게 보이는 단계가 실제 작업 상태와 연결되는가?
- 알림에서 해당 건의 상세 진행 상황을 확인할 수 있는가?
- 공급자와 자사 안내가 중복되거나 서로 다른 상태를 전하지 않는가?
- 고객이 원하는 안내 방식과 빈도를 선택할 수 있는가?

2026-10-23 공개 지침을 대조했다. 상태 안내가 불확실성을 줄이는 원칙과, 배송 지연보다 안내 부재가 언제나 더 큰 불만을 만든다는 비교 주장은 구분한다. 후자는 이번 확인으로 검증되지 않았다. 경쟁사의 접점을 그대로 늘리기보다 실제 고객 질문과 선택에 필요한 정보를 확인한다.

## 생산 역량과 브랜드 무형자산을 구분한다

제품을 생산하는 능력과 고객이 그 제품을 구별하고 선택하게 만드는 자산은 겹치지만 같은 것은 아니다. 제조 가치사슬에는 노동과 설비뿐 아니라 기술, 디자인과 브랜드 같은 무형자산도 기여한다. 생산 국가만으로 브랜드의 소유권이나 가치의 귀속을 판단하지 않는다.

WIPO의 2017년 연구는 제조 가치사슬의 무형자산을 분석하며 커피 시장에서 브랜드 평판과 이미지가 차별화에 기여하는 사례를 다뤘다. 이는 특정 지역이 지식재산을 독점한다거나 시간이 지나면 신생 브랜드가 명품이 된다는 증거는 아니다.

이 구분을 브랜드 설계에 적용하면 다음 세 가지를 따로 확인할 수 있다. 아래는 연구의 개념을 적용한 조사 질문이다.

- **생산과 제공:** 어떤 품질과 납기, 지원을 반복해서 제공할 수 있는가?
- **차별화:** 고객이 어떤 이름, 디자인, 기술과 경험을 식별하고 선택 이유로 드는가?
- **권리와 통제:** 그 자산의 권리자는 누구이며 계약이 끝나도 사용할 수 있는가? 구체적인 상표 확인은 [[Trademark-and-Brand-Clearance]]를 따른다.

2026-10-22 무형자산의 범위와 커피 사례를 WIPO의 연구 발표와 대조했다. 개별 브랜드 가치나 국가별 명품 생산 비중을 검증한 것은 아니다.

### 새 유통 접점에서도 브랜드 약속을 구체화한다

브랜드 협업은 이름을 함께 표시하는 일 외에 제품을 새 구매 환경에 맞추는 일도 포함한다. 고객이 기억하는 특징과 달라지는 제공 방식을 나누어 확인한다.

GS리테일의 2026-09-03 발표는 디저트 브랜드 한정선, 제조사 로로멜로와 GS25의 협업 제품을 소개한다. 매장의 대표 메뉴를 편의점 냉동 디저트로 바꾸면서 맛과 단면의 시각적 특징을 연결한 사례다. 이 발표는 협업과 제품 기획의 공개 근거이며, 관련 회사의 지분 관계나 수익성 및 성공의 원인을 입증하지 않는다.

다음은 이 사례를 브랜드 접점 설계에 적용한 질문이다.

- 새 판매 방식에서도 유지해야 할 맛, 형태, 사용 경험은 무엇인가?
- 보관과 사용 조건이 달라졌을 때 고객에게 무엇을 안내해야 하는가?
- 브랜드, 제조와 유통의 담당 범위 및 품질 문의의 책임자는 정해졌는가?

인지도, 공급 능력과 유통 접근성을 따로 살피며, 유명한 브랜드와의 협업만으로 판매나 이익을 예측하지 않는다. 2026-10-26 발행사 보도자료를 확인했으며 실제 제품 품질과 재구매 효과는 확인하지 않았다.

## 확인 질문

- 바꾸려는 것은 고객의 어떤 문제이며, 현재 근거는 무엇인가?
- 기존 자산에서 유지할 것과 바꿀 것의 이유가 각각 있는가?
- 대표 접점에서 방향을 비교하고 판단한 이유를 설명할 수 있는가?
- 가이드 완료와 실제 적용, 성과 확인을 구분했는가?
