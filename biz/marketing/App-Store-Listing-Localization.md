# 앱스토어 등록 정보의 기본 언어와 현지화

앱 이름, 부제, 설명, 스크린샷 같은 스토어 등록 정보의 언어는 판매 국가만으로 정해지지 않는다. Apple은 스토어 지원 언어, 기기 언어, 등록한 현지화와 기본 언어를 함께 고려하고, Google Play는 제공하지 않은 번역을 자동 번역으로 볼 수 있는 선택지를 제공한다. 해외 사용자에게 소개하려면 기본 언어, 현지화, 판매 국가를 각각 정하고 실제 표시 결과를 확인한다. 언어가 전환율에 미치는 영향은 방문과 설치 데이터로 따로 검증한다.

## 동작 방식

### Apple App Store

- App Store Connect에서 앱마다 기본 언어(Primary Language)를 하나 정하고 언어별 현지화를 추가한다.
- 사용자의 언어 설정과 맞는 현지화가 있으면 그 현지화를 보여 준다. 맞는 것이 없으면 다음으로 관련성이 높은 현지화를 쓰고, 그것도 없는 국가나 지역에서는 기본 언어로 보여 준다.
- 국가별 스토어마다 기본 언어와 추가 지원 언어가 정해져 있다. 예를 들어 한국 스토어는 한국어를 기본으로, 영어(영국)를 추가 언어로 지원한다(2026-10-07 확인). 이 표의 스토어 기본 언어와 개발자가 앱에 지정하는 Primary Language는 서로 다른 설정이다.
- 기본 언어가 영어이고 영어만 입력하면 모든 국가와 지역에서 영어로 보인다. 여기에 한국어 현지화를 더하면 한국어 설정 사용자에게는 한국어가 보인다.
- 기본 언어 변경 전에는 해당 언어가 이전 버전에 추가되고 현지화와 모든 지원 플랫폼의 스크린샷이 심사 승인을 받아야 한다. 스크린샷 크기도 현재 기본 언어와 맞아야 하며, 다른 언어에서 가져온 스크린샷이었다면 새 이미지를 직접 올려 승인받은 뒤 후속 업데이트에서 변경한다. 맞춤 제품 페이지가 있으면 각 페이지에도 해당 언어 스크린샷이 필요하다.
- 새 현지화를 추가하면 설명과 키워드를 제외한 속성과 스크린샷은 기본 언어에서 가져온다. 언어를 추가한 것만으로 모든 문구와 이미지가 번역됐다고 간주하지 않는다.

### Google Play

- 스토어 등록 정보에 기본 언어와 언어별 번역을 둔다.
- 번역하지 않은 언어의 사용자는 자동 번역본을 볼 수 있고, 페이지 상단에 자동 번역이라는 안내와 기본 언어로 보기 선택지가 붙는다. 일부 언어는 자동 번역을 지원하지 않는다.
- 텍스트만 번역하고 현지화한 그래픽을 추가하지 않으면 기본 언어의 그래픽이 표시된다. 설명 번역과 스크린샷 안의 문구 번역을 따로 점검한다.
- 자동 번역은 품질과 검색 키워드를 통제할 수 없으므로, 주력 시장은 직접 번역한 등록 정보를 두는 편이 낫다.

## 권장 구성

| 목표 | 구성 |
|---|---|
| 한국 전용 | 기본 언어 한국어. 해외 노출을 원하지 않으면 판매 국가도 한국으로 제한한다. |
| 한국 우선, 해외는 열어 둠 | 기본 언어 영어와 한국어 현지화를 후보로 둔다. 한국 거주 여부만으로 한국어 표시를 보장하지 않으므로 스토어와 기기 언어 조합별로 확인한다. |
| 특정 해외 시장 공략 | 위 구성에 주력 시장 언어를 현지화로 더하고, 앱 이름, 부제, 키워드를 그 언어의 검색어로 따로 쓴다. |

## 트레이드오프와 주의점

- 기본 언어를 영어로 두면 영어 스크린샷과 설명을 계속 함께 관리해야 한다. 한국어만 갱신하고 영어를 방치하면 해외 페이지가 오래된 정보로 남는다.
- 스토어 등록 정보와 앱 바이너리의 현지화는 별개다. 등록 정보만 영어이고 앱 안이 한국어뿐이면 사용에 어려움이 생길 수 있으므로, 앱 내부와 결제, 고객 응대 언어의 범위를 함께 정한다.
- 판매 국가를 넓히면 국가별 세금, 결제, 개인정보, 콘텐츠 규제를 확인해야 한다. 노출 범위는 운영할 수 있는 범위와 맞춘다.
- 직역한 표현이 현지 검색어와 맞는지 확인한다. 앱 이름, 부제, 키워드의 현지화가 검색 노출을 늘리는지는 실제 유입 데이터로 검증한다.

## 적용 점검

- 기본 언어가 무엇이고, 현지화가 없는 스토어에서 어떤 언어로 보이는지 알고 있는가.
- 판매 국가 설정과 등록 정보 언어가 해외 진출 의도와 맞는가.
- 영어 등록 정보를 누가, 어떤 주기로 갱신하는가.
- 스토어 언어와 앱 내부 언어가 어긋나지 않는가.
