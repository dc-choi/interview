# 판촉물의 제작, 납기와 성과 확인

판촉물은 상품 선택뿐 아니라 배포 목적, 실물 품질과 도착 시점을 함께 정하는 마케팅 실행 과제다. 다음은 주문과 운영을 위한 점검 제안이며, 판촉물의 매출 효과나 시장 성장률을 입증한 자료는 아니다.

## 제작 전에 결정할 것

| 구분 | 확인할 내용 |
|---|---|
| 목적 | 누구에게 어떤 상황에서 주고 어떤 후속 행동을 기대하는가 |
| 실물 | 소재, 크기, 마감, 인쇄 위치와 색상을 어떻게 확인하는가 |
| 일정 | 행사일, 필요한 도착일, 시안 확정과 제작 시작 시점이 구분되는가 |
| 총비용 | 상품, 인쇄, 포장과 배송을 포함한 견적이며 남은 재고도 감당할 수 있는가 |
| 문제 대응 | 지연과 불량의 판정 기준, 책임 주체와 보상 절차가 무엇인가 |

AI 상품 추천은 후보를 고르는 보조 수단으로 사용한다. 추천 결과를 확정된 재고, 제작 가능 여부와 납기 약속으로 간주하지 않고 견적과 시안을 확인한다.

## 배송 약속의 조건을 읽는다

2026-10-23 기프트코의 공개 책임배송 안내는 다음을 표시한다.

- 약속한 납기를 지키지 못하면 주문금액의 100%를 현금으로 보상하되, 업체 책임 기준인 경우라는 조건을 둔다.
- 로고 인쇄나 제품 불량 등의 품질 문제가 발생하면 전체 수량을 다시 제작해 발송한다고 안내한다.
- 샘플비 지원은 1만원 이하 제품과 사업자 등록 회원이라는 조건이 있다.

이는 해당 업체의 공개 안내를 확인한 것이며 실제 배송 이행률이나 보상 처리 결과를 검증한 것은 아니다. 주문 시 적용되는 책임 기준과 예외, 재제작 후 도착일을 확인한다. 현금 보상과 행사 당일 물품 확보는 같은 결과가 아니므로 일정 여유와 대체 수단도 검토한다(운영 제안).

## 배포와 효과를 구분한다

다음은 측정 제안이다. 주문 수량, 실제 배포, 남은 수량과 후속 문의 또는 구매를 따로 기록한다. 배포 수량을 광고 노출이나 신규 고객 수로 바꾸어 세지 않는다. QR이나 쿠폰으로 추적한 전환도 판촉물 때문에 추가로 발생한 전환과 같지는 않다. 증분 효과의 구분은 [[Metrics-Framework|지표 설계]]를 따른다.
