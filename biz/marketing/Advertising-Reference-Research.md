# 광고 레퍼런스 조사

광고 레퍼런스는 메시지, 표현과 매체 선택을 비교하는 자료다. 광고 영상, 캠페인 기사와 수상작 모음은 보여 주는 정보가 다르므로 조사 목적에 맞춰 고른다. 사례를 발견한 것과 그 광고의 판매 효과를 검증한 것은 구분한다.

## 조사 목적에 맞는 자료를 고른다

아래 수록 범위와 이용 안내는 2026-11-02 운영 사이트의 공개 본문에서 확인했다. 비교 질문은 자료를 실제 기획에 적용하기 위한 제안이다.

| 조사 목적 | 자료와 확인한 범위 | 비교할 질문 |
|---|---|---|
| 국내 광고의 영상과 제작 정보 | TVCF: 국내 방송, 디지털 광고와 해외 CF 구분, Video와 Image, 광고주와 대행사 등의 Portfolio 메뉴 | 같은 브랜드의 메시지와 표현이 매체에 따라 어떻게 달라지는가? |
| 영상 밖의 캠페인 발상 | Famous Campaigns: Advertising, OOH, Experiential, PR, Social Media 등 분류와 캠페인 기사 | 옥외 공간이나 참여 행동을 메시지 전달에 어떻게 이용하는가? |
| 일본 광고 업계의 맥락 | AdverTimes.: 센덴카이기가 운영하는 광고 뉴스, 캠페인 정보와 칼럼 사이트 | 표현뿐 아니라 광고주, 매체와 시장 맥락에서 확인할 조건은 무엇인가? |
| 광고제 수상작 탐색 | Unblock Coffee: 수상 광고 라이브러리, Campaigns, Awards, Brands, Agencies 탐색 메뉴 | 어떤 문제를 어떤 아이디어와 실행 방식으로 풀었는가? |

TVCF의 광고 분류와 제작자 정보는 소재를 찾는 출발점이다. Famous Campaigns와 AdverTimes.의 기사도 캠페인 탐색에 쓸 수 있지만, 기사에 소개된 성과 수치까지 이 표에서 확인한 것은 아니다. 성과를 인용하려면 광고주나 실행 주체의 공개 자료에서 측정 기간, 지표와 비교 기준을 다시 확인한다.

Unblock Coffee의 공개 안내는 무료 계정에 주당 캠페인 5개 열람, 유료 플랜에 무제한 접근을 제시한다. 이는 확인일의 안내이며, 계정 가입 뒤 실제 제한 동작이나 유료 기능은 시험하지 않았다. 다른 사이트의 요금과 전체 열람 범위는 이번 확인에 포함하지 않았다.

## 사례를 비교 가능한 질문으로 바꾼다

### 광고 사례와 창작 포트폴리오를 나눠 읽는다

광고 집행 사례와 창작자의 포트폴리오는 확인할 근거가 다르다. 노트폴리오는 운영사 스터닝이 포트폴리오 발견과 창작자 연결을 제공하는 플랫폼으로 소개한다(2026-11-04 운영사 공개 안내 확인). 표현과 제작 역량을 탐색할 후보로 쓸 수 있지만, 작품 등록이 광고 집행이나 판매 성과를 입증하지는 않는다. 개별 작품의 제작 과정, 실제 사용 여부와 성과는 이번 확인에 포함하지 않았다.

자료를 모을 때는 **완성 표현, 기획 설명, 집행 결과**를 구분해 기록하는 방법을 제안한다. 색상과 구성만 보이는 작품에서 고객 조사나 전환 효과까지 추정하지 않는다. 여러 분야의 큐레이션을 참고하더라도 실제 기획에 쓸 때는 제작자나 브랜드의 공개 원자료로 돌아가 목적, 제약과 결과를 확인한다. 계정 추천 목록을 많이 확보한 것과 이러한 대조를 마친 것은 다르다.

### 기획에 적용할 비교 절차

다음은 광고 자료를 기획에 옮기는 작업 제안이다. 특정 사이트가 입증한 성과 개선 절차는 아니다.

1. **고객과 행동을 먼저 정한다.** 누구에게 무엇을 이해시키고, 조회 뒤 어떤 행동을 기대하는지 한 문장으로 적는다.
2. **비교 단위를 좁힌다.** 첫 장면, 핵심 문구, 제품 시연, 참여 방식이나 행동 유도 중 지금 결정할 요소를 고른다.
3. **관찰과 해석을 나눈다.** 화면에 실제 나온 문구와 행동은 관찰로, 그것이 관심을 끌 것이라는 설명은 가설로 적는다.
4. **적용 조건을 비교한다.** 제작비, 매체, 고객의 사전 지식과 브랜드 인지도가 다른 사례를 그대로 성공 기준으로 삼지 않는다.
5. **자기 제안으로 작은 시안을 만든다.** 고객 문제와 제공 가치를 유지하면서 표현을 바꿔 보고, 실제 문의나 구매 같은 목표 행동으로 확인한다.

예를 들어 홈페이지 제작 서비스의 광고를 준비한다면 유명 브랜드의 영상미보다 고객이 겪는 문제를 드러내는 방식, 작업 결과를 보여 주는 근거와 문의 동선을 비교할 수 있다. 이는 적용 예시이며 특정 표현이 전환을 높인다는 검증 결과는 아니다.

## 수록, 수상과 사업 성과를 구분한다

- 사이트에 실렸거나 광고제에서 수상했다는 사실을 매출 증가의 증거로 대신하지 않는다.
- 조회수, 공유와 고객 문의, 계약은 서로 다른 결과다. 어떤 행동을 측정했는지 구분한다.
- 완성된 광고만으로 제작비, 배포량과 실패한 시안을 알 수는 없다. 확인되지 않은 조건을 작은 사업에도 재현 가능한 성과로 가정하지 않는다.
- 사례를 참고하는 단계와 이미지, 영상, 음악이나 문구를 가져다 쓰는 단계는 구분한다. 실제 재사용 전 해당 자료의 이용 조건을 별도로 확인한다.

## 추가 확인 후보

Lürzer's Archive는 광고 자료 탐색 후보로 남긴다. 이번 조회에서는 공식 사이트의 본문을 확보하지 못했으므로 수록 범위, 제작 정보와 유료 구독 조건을 확정하지 않았다. 접근이 가능할 때 운영 안내와 열람 조건부터 확인한다.
