# 창업자 배경과 역량 공백

구현 도구가 바뀌면 제품을 시작할 수 있는 사람의 범위도 달라질 수 있다. 출신 유형의 우열을 정하기보다 고객 문제 발견, 구현, 판매와 운영 중 가진 자산과 남은 공백을 따로 확인한다.

## 같은 도구가 주는 이득과 남는 과제

| 출발 자산 | 가능한 이득 | 확인할 공백 |
|---|---|---|
| 1인 실행 | 조율 비용을 줄이며 초기를 빠르게 실험 | 고객 접점, 지원과 중요한 결정의 용량 |
| 비개발 분야 경험 | 기존 업무의 불편을 직접 제품으로 시험 | 신뢰성, 보안과 규모가 커질 때의 기술 판단 |
| 도메인 전문성 | 실제 문제와 구매 조건을 잘 앎 | 기존 관행을 바꿀 대안과 외부 시각 |
| 학생과 초기 사용자 경험 | 또래의 수요와 사용 문화에 가까움 | 산업 관계, 고용과 사업 운영 |
| 콘텐츠와 독자 기반 | 초기 배포와 반응 확인 경로가 있음 | 지속 사용, 지불과 장기 제품 운영 |

이는 투자자의 유형별 가설을 실무 점검으로 옮긴 표다. 유형별 성공률, 투자 적합성이나 개인의 능력을 판정하는 점수표가 아니다. AI로 초안을 만들 수 있어도 영업, 채용, 가격, 운영 책임과 고객 유지가 자동으로 해결되지는 않는다.

## 검증 방식

1. 자기 배경을 강점이라는 말 대신 접근 가능한 고객, 자료와 직접 수행한 일로 적는다.
2. 첫 제품에서 반드시 필요한 역량과 외부 도움으로 채울 부분을 나눈다.
3. 실제 사용, 재사용과 지불을 관찰하며 가설을 고친다.
4. 고객과 운영의 요구가 커지면 혼자 유지할 범위와 협업 구조를 다시 정한다.

Andrew Chen의 2026-10-27 에세이는 기술과 유통의 변화가 기존 창업자 선별 관행을 바꿀 수 있다는 전망이다. AI의 100배 배수는 설명을 위한 가정이며 측정된 생산성 수치로 쓰지 않는다. 다양한 출발점의 가능성과 공동창업 팀의 이득을 함께 검토하며 어느 유형이 이제 무조건 유리하다는 결론을 피한다.

## 업무 경험을 재사용 가능한 절차로 바꾼다

도메인 경험은 제품 아이디어뿐 아니라 반복 업무의 판단 기준으로도 남길 수 있다. 고객에게 무엇을 물어보고 어떤 결과를 검수하는지 표준 운영 절차(SOP)에 적으면, 사람이나 AI에게 일을 넘길 때 필요한 입력과 완료 기준을 설명하기 쉬워진다.

다음은 업무 경험을 절차 자산으로 바꾸는 적용 제안이다.

1. 실제로 반복 수행하는 업무 하나를 고르고 입력, 판단 순서와 산출물을 적는다.
2. 제품, 대상 고객과 포지셔닝 같은 공통 맥락과 업무별 절차를 나눈다. 서로 다른 업무가 같은 전제를 다시 입력받거나 다르게 해석하는지 확인한다.
3. 초안과 실제 결과를 비교해 빠진 조건을 보완한다. 한 번의 예외를 모든 고객에게 적용하는 규칙으로 확대하지 않는다.
4. 절차를 재사용한 뒤에도 결과 검수 시간, 오류와 고객 행동을 확인한다. 문서 수나 도구 사용량을 매출과 고객 유지의 증거로 삼지 않는다.

공개 사례인 Marketing Skills는 마케팅 업무별 스킬이 제품, 고객과 포지셔닝의 공통 맥락을 먼저 참조하는 구성을 안내한다(2026-11-04 공식 README 확인). Corey Haines의 공개 발표는 기존 업무 절차를 AI 스킬로 옮긴 경험을 보여준다. 이는 경험을 전달하는 방식의 사례이며, 비개발 출신의 성공률이나 자동화 효과를 입증한 비교 연구가 아니다. 스킬 실행과 권한 통제의 기술 조건은 [[Agent-Skills|에이전트 스킬]]에서 다룬다.

## 학력과 문제 해결 경험을 따로 확인한다

창업자의 역량을 점검할 때는 학력과 함께 직접 정의한 문제, 실행한 실험, 실패 후 바꾼 판단을 확인한다. 배경의 명칭만으로 고객 문제를 풀 능력까지 입증했다고 보지 않는다. 이는 위 역량 공백 점검을 구체화한 적용 기준이다.

공개 관점 사례로, SK의 2026-10-18 강연 소개는 졸업장보다 실제 문제 해결 경험을 중시하고 학교를 도전과 실험의 장소로 바꾸자는 제안을 담는다. 이는 교육과 인재에 대한 경영자의 견해이며, 학위의 효과를 측정한 연구나 채용, 진학 요건의 폐지를 뜻하지 않는다. 창업 역량을 경험으로 확인하자는 제안과 개인의 자퇴 여부는 별도 판단이다. 2026-11-03 공식 소개의 교육 관련 문단을 대조했으며 강연 전체 영상은 확인하지 않았다.
