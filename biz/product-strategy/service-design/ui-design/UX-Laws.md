# UX 심리학 10가지 법칙 (Laws of UX)

인지 심리학 연구를 UI 설계 원칙으로 정리한 법칙 모음. 이론 암기로는 실무에서 떠오르지 않는다 — 구체적 서비스 사례에 대입해 체득해야 설계할 때 무의식적인 감으로 작동한다.

## 10가지 법칙

| 법칙 | 정의 | 적용 예 |
|---|---|---|
| 제이콥의 법칙 | 사용자는 다른 서비스에서 익힌 UI 패턴을 기대한다 | 상품 상세를 일반 커머스와 같은 레이아웃으로 — 학습 비용 제거 |
| 피츠의 법칙 | 타겟 도달 시간은 거리와 크기의 함수 | 참여 기능(댓글, 작성)을 엄지가 닿는 중하단에 배치 |
| 힉의 법칙 | 선택지가 늘면 탐색과 결정 시간이 늘 수 있다 | 열린 질문 대신 사전 정의된 선택지 제공 (거래 후기) |
| 밀러의 법칙 | 7±2는 역사적 추정치이며 작업과 청킹 조건에 따라 용량이 달라진다 | 항목을 의미 단위로 묶고 실제 사용성으로 검증 |
| 포스텔의 법칙 | 원전은 입력을 폭넓게 받고 출력을 보수적으로 만들라는 견고성 원칙 | 동등한 날짜 입력 형식을 받아 정규화하고 표준 형식으로 출력 |
| 피크엔드 법칙 | 경험에 대한 회고적 평가는 강한 순간과 마지막 순간의 영향을 받을 수 있다 | 작성 완료 시 뱃지 보상, 거래 후 상호 후기로 끝맛 설계 |
| 심미적 사용성 효과 | 아름다운 디자인은 더 쓰기 쉽다고 인지된다 | 오류 페이지에 캐릭터를 넣어 부정 경험을 완화 |
| 폰 레스토프 효과 | 비슷한 것들 사이 다른 하나가 기억된다 | 핵심 액션에만 포인트 컬러 — [[Visual-Hierarchy\|시각적 위계]] |
| 테슬러의 법칙 | 일부 복잡성은 사용자와 시스템 사이에서 이동한다는 설계 휴리스틱 | 동네 범위를 직접 고르게 하지 않고 슬라이더로 — 복잡성을 시스템이 흡수 |
| 도허티 임계 | 0.4초는 역사적 상호작용 연구에서 나온 휴리스틱이지 보편적 제한이 아니다 | 제품별 측정으로 응답 목표를 정하고 지연 시 진행 상태 제공 |

## 피츠의 법칙을 적용할 때: 보이는 크기와 입력 영역

아이콘의 시각적 크기와 실제 클릭하거나 터치할 수 있는 영역은 다를 수 있다. 작은 아이콘을 유지하면서 주변 여백을 같은 동작의 입력 영역으로 포함하면 조작하기 쉬워진다. Android 접근성 가이드는 24×24dp 아이콘에 여백을 더해 48×48dp 터치 영역을 만드는 예를 들며, 48×48dp 이상과 인접 영역 사이 8dp 이상의 간격을 권한다. 영역을 넓힐 때는 옆 버튼과 겹쳐 잘못된 동작이 선택되지 않는지 확인한다.

웹의 WCAG 2.2 성공 기준 2.5.8(AA)은 기본적으로 24×24 CSS px 이상의 포인터 입력 영역을 요구한다. 더 작은 대상은 bounding box 중심의 지름 24 CSS px 원이 다른 대상이나 다른 작은 대상의 원과 겹치지 않는 간격 예외를 적용할 수 있다. 같은 페이지의 동등한 다른 컨트롤, 문장 안 링크, 작성자가 크기를 바꾸지 않은 사용자 에이전트 컨트롤, 본질적으로 필요하거나 법적으로 요구되는 표현도 예외가 있다. Android의 dp 권장치와 웹의 CSS px 준수 기준을 같은 규격으로 취급하지 않는다.

확인 범위(2026-10-15): Google과 W3C의 입력 영역 설계 지침을 대조했다. 특정 스마트폰 키보드의 예측 알고리즘과 도입 연도는 이 설명의 근거에 포함하지 않는다.

## 자이가르닉 효과: 중단한 과제의 기억과 재개

자이가르닉 효과는 기억 우위의 근거가 약하고 엇갈려 위 10가지 법칙 표에 넣지 않고 따로 다룬다.

| 효과 | 정의 | 적용 예 |
|---|---|---|
| 자이가르닉 효과 | 중단한 과제를 완료한 과제보다 더 잘 기억한다는 가설로, 2025년 메타분석은 가장 흔히 쓰인 지표(38편)에서 이 기억 우위를 찾지 못했다. 기회가 생기면 중단한 과제를 다시 하려는 경향은 오브시안키나(Ovsiankina) 효과로 구분한다 | 가입이나 견적 요청 양식의 진행 막대, 온보딩 체크리스트가 이탈한 사용자의 재방문이나 완료를 늘린다고 전제하지 않고, 단계별 완료율과 재개율로 검증할 가설로 둔다 |

Ghibellini와 Meier(2025)의 정리에 따르면 Zeigarnik(1927)은 참가자에게 여러 과제를 주며 일부를 중단시켰고, 참가자들은 완료한 과제보다 중단된 과제를 더 많이 회상했다. 이 메타분석은 중단 과제의 회상이나 재개를 다룬 출판물 59편을 모아, 미완료 과제의 기억 우위는 찾지 못했지만 과제를 재개하려는 일반적 경향은 찾았다고 결론지었다. 가장 흔히 쓰인 지표인 중단 과제와 완료 과제의 평균 회상 수의 비는 0.99(38편)로 두 과제가 비슷하게 회상됐고, 회상한 과제 가운데 중단 과제의 비율은 49.43%(14편)였다. 효과 크기는 대부분의 연구가 보고하지 않았거나 계산할 정보를 주지 않았고, 구할 수 있었던 8편의 d_z는 0.15로 작은 효과였다. Zeigarnik이 쓴 참가자별 비의 평균은 1.13(7편)이었지만, 저자들은 이 지표가 극단값에 크게 영향을 받아 효과를 과대 추정하며 Zeigarnik의 원래 계산 값도 부풀려졌다고 봤다. 논의 절은 상황 요인과 개인차를 고려하지 않으면 현재 결과가 중단 과제의 기억 우위를 뒷받침하지 않는다고 결론지었고, 자이가르닉 효과는 보편적으로 성립하지 않으며 상황 요인과 개인차(예: 실험자의 권위, 과제 수행의 상황적 요구, 과제 몰입)에 달려 있을 수 있다고 봤다.

기회가 주어졌을 때 중단 과제를 재개한 사람의 비율인 재개율은 약 67%(21편)로 우연 수준인 50%보다 높았다. 연구마다 재개를 재는 방식이 달라 저자들은 이 값을 절대적인 측정치가 아니라 경향을 보여 주는 값으로 보라고 했다. 위 값은 출판물별 값을 표본 크기로 가중해 평균한 것이며, 신뢰구간, 유의성 검정과 이질성 통계는 보고되지 않아 50%와의 비교도 검정 없는 서술이다.

실험실 과제의 재개 경향을 제품의 재방문이나 양식 완료로 옮기는 것은 이 문서의 추론이다. 진행 표시 자체의 효과는 Villar, Callegaro, Yang(2013)이 웹 설문의 무작위 실험 32개를 메타분석해 다뤘다. 일정한 속도의 진행 표시는 전체적으로 중도 이탈을 유의하게 줄이지 못했고, 빠르다가 느려지는 표시는 이탈을 줄였지만 느리다가 빨라지는 표시는 늘렸으며, 작은 인센티브를 약속한 연구들에서는 일정한 속도의 표시가 이탈을 늘렸다. 이 설문 결과를 가입이나 견적 요청 양식으로 옮기는 것도 이 문서의 추론이다. 진행 막대나 체크리스트를 넣을 때는 넣지 않은 화면과 단계별 완료율, 이탈 뒤 재개율을 비교해 효과를 확인한다.

확인 범위(2026-11-02): Ghibellini와 Meier(2025)의 초록, 본문과 표 1, 2를 대조했다. Zeigarnik(1927)과 Ovsiankina(1928)의 원문은 확인하지 못해 원 연구의 내용은 이 메타분석의 정리로 적었다. Villar 외(2013)는 Crossref에 등록된 초록만 대조했고 본문은 확인하지 못했다.

## 백엔드 관점의 연결

- **0.4초를 API SLO로 그대로 옮기지 않는다** — 사용자가 기다리는 전체 경로, 네트워크와 렌더링을 측정해 p95 목표를 정한다. 즉시 완료할 수 없으면 진행 상태, 낙관적 업데이트나 비동기 처리를 검토한다.
- **포스텔의 법칙은 검증 생략 원칙이 아니다** — 신뢰 경계에서는 허용 형식을 명시하고 검증한다. 호환성을 위해 받아들인 동등한 표현만 정규화하고, 출력은 하나의 표준 형식으로 만든다.
- **테슬러의 법칙은 정량적인 보존 법칙이 아니다** — 불필요한 복잡성은 제거하고, 업무상 남는 복잡성만 사용자보다 시스템이 처리할 수 있는지 판단하는 휴리스틱이다.

## 면접 체크포인트

- 성능 목표는 실제 사용자 경로와 지연 분포로 정하고, 도허티의 0.4초는 역사적 참고값으로만 설명한다.
- 입력 검증 설계를 포스텔의 법칙으로 — 프론트 입력 제약(1차)과 서버 검증(최종 방어선)의 역할 분담.
- 기능 단순화 요구에 테슬러의 법칙으로 — 불필요한 복잡성은 먼저 제거하고, 업무상 남는 환원 불가능한 복잡성을 누가(사용자 vs 시스템) 감당할지의 의사결정임을 짚는다.
