# 화면 UI 설계

화면 단위 UI 설계 레퍼런스 — 컴포넌트 용어, 시각적 위계, 인지 법칙, 가이드 배치, 로딩 상태.

- [[UI-Terminology|UI 용어 정리]]: GNB, 팝업 vs 모달, 컨펌 vs 알럿, 체크박스 vs 라디오, 터치 제스처 9종, AI 수정 요청에 쓰는 컴포넌트 이름
- [[Visual-Hierarchy|시각적 위계]]: 크기, 색상, 질감, 공간감, 형태 (폰 레스토프 효과), 작은 요소의 강조 절제와 상태 배지 규칙, 상품 목록과 썸네일의 일관성, 대시보드 여백과 상태 표현, 텍스트 대비, 서체의 역할과 공식 배포처 확인, UI 스타일과 반투명 재질의 적용 층
- [[Font-Licensing-for-Client-Work|외주 납품의 폰트 라이선스]]: 비용 없이 받는 것과 이용 허락의 구분, SIL OFL 1.1과 Google Fonts, Adobe Fonts의 허용과 제외 용도, 눈누 요약표와 원 약관, 웹폰트 자체 호스팅, 소스 파일과 로고 인계
- [[UX-Laws|UX 심리학 10가지 법칙]]: 제이콥, 피츠, 힉, 테슬러, 도허티 임계와 백엔드 연결
- [[User-Guidance-Patterns|사용자 가이드 제공 패턴]]: 가이드가 필요한 3가지 상황, 5가지 제공 방식, 적재적소 배치 원칙
- [[Perceived-Performance|지각된 성능과 로딩 상태]]: 대기 시간별 피드백 선택, 스켈레톤 화면의 조건과 공간 예약, Core Web Vitals 기준과 체감 검증, 상품 목록 적용 예시
- [[UI-Reference-Research|화면 디자인 레퍼런스 조사]]: 전체 페이지, 영역과 상호작용별 조사, 설계 요구로 옮기기, 미감과 안목의 구분과 판단 순서, 내 취향과 고객 선호의 구분(미적 평가의 개인차, 문화와 연령 차이), 열람과 재사용 조건 구분
