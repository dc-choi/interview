# 크로스 디바이스 심리스 UX와 QR

서로 다른 환경(온라인과 오프라인, PC와 모바일, TV와 모바일)을 매끄럽게 잇는 접점 설계. QR코드가 대표 인터페이스다 — 1994년에 개발된 기술이 수십 년 외면받다가 보편화된 과정 자체가 기술 채택의 원리를 보여준다.

## 행동이 일어나는 조건: 포그 행동 모델

행동은 **높은 동기 + 낮은 행동 장벽 + 계기(Prompt)**가 한 순간에 수렴할 때 일어난다 (Fogg Behavior Model, B = MAP). 기능이 안 쓰이면 동기 부족인지, 장벽이 높은지, 계기가 없는지부터 분해한다.

QR코드가 오래 외면받은 이유는 동기와 장벽 둘 다였다 — 기본 카메라로 인식이 안 돼 별도 앱이 필요했고(높은 장벽), 스캔해 봐야 광고 페이지였다(낮은 효용).

## 기술 상용화의 조건

| 조건 | 의미 | QR의 경우 |
|---|---|---|
| 주변 인프라 뒷받침 | 기술을 쓸 하드웨어, 환경의 보편화 | 스마트폰 기본 카메라의 QR 인식 |
| 진정한 효용 | 사용자 입장의 실질 가치 | 보안성과 편의성의 동시 확보 |
| 사회적 학습 계기 | 대중이 사용법을 익히는 사건 | 코로나19 출입 인증 |

기술 자체보다 인프라와 환경이 채택을 가른다 — 한국 이커머스 역사([[Commerce-Korea-History|시대별 반복 패턴]])에서 반복 확인되는 원리.

## QR이 만드는 세 가지 심리스 경험

| 영역 | 패턴 | 가치 |
|---|---|---|
| 로그인 | 입력이 불편한 디바이스(공용 PC, TV)의 인증을 모바일에 위임 | 비밀번호 입력 제거 — 보안과 사용성 동시 확보 |
| 결제 | 실물 카드 번호 입력 대신 모바일 저장 결제수단으로 연결 | 결제 이탈 구간 단축 |
| 오프라인 접점 | 하드웨어 단말(LCD, 카드 리더기)을 스티커 한 장으로 대체 | 기기 원가와 유지보수 제거 + 주문, 결제 일괄 + 사업자에게 고객 데이터 자산 |

## 백엔드 관점: QR 로그인 플로우

디바이스 간 세션 핸드오프의 표준 설계 — 시스템 설계 면접 단골 소재.

1. 입력이 불편한 디바이스가 서버에서 **일회용 토큰**을 발급받아 QR로 표시
2. 이미 인증된 모바일이 스캔하고 **사용자가 명시적으로 승인**
3. 서버가 토큰에 세션을 바인딩
4. 원래 디바이스가 폴링 또는 푸시로 로그인 완료를 감지

보안 핵심은 일회용 + 짧은 만료 + 승인 단계다. 승인 없이 스캔만으로 로그인되면 QR 바꿔치기(쿼싱) 공격에 뚫린다.

## 면접 체크포인트

디바이스 간 이동뿐 아니라 같은 기기의 화면 상태 변화도 연속성 검토 대상이다. 아래 절의 기준을 QR 연결과 구분해 적용한다.

- 기능 활성화 부진 문제는 포그 모델로 분해해 답한다 — 동기 문제인지, 장벽 문제인지, 계기 부재인지에 따라 처방(가치 소구 / 마찰 제거 / 트리거 설계)이 다르다.
- 신기술 도입 검토 질문에 상용화 3조건(인프라, 효용, 학습 계기)을 체크리스트로.
- QR 로그인 설계 질문에 토큰 핸드오프 4단계와 보안 3요소(일회용, 만료, 승인)로 답한다.

## 폴더블 화면 전환: 과업 연속성을 검수한다

화면 크기와 자세가 바뀌는 제품은 정지 화면의 배치뿐 아니라 전환 중 하던 일을 이어갈 수 있는지 검토한다. 이는 사용자 과업을 기준으로 한 설계 제안이며 특정 기기에서 자동으로 보장되는 동작은 아니다.

2026-10-07에 확인한 공개 사례로, Apple은 iPhone Duo의 바깥 화면과 안쪽 화면을 같은 종횡비로 설계하고 안쪽 화면의 Split View를 소개했다. 2026-10-05 개발자 안내는 여러 자세와 방향에서 앱 동작을 확인하고, 스크린샷과 제품 페이지 자료도 준비하도록 한다. 제품 발표에서 말하는 연속성을 개별 앱의 검증 결과로 대신하지 않는다.

| 검수 상황 | 확인할 사용자 결과 |
|---|---|
| 입력 중 접기와 펼치기 | 작성하던 내용, 선택과 다음 행동이 유지되는가 |
| 목록과 상세 전환 | 선택한 항목과 돌아갈 위치를 다시 찾지 않아도 되는가 |
| 화면 분할과 회전 | 좁아진 영역에서도 핵심 조작과 오류 안내에 접근할 수 있는가 |
| 소개 화면과 실제 사용 비교 | 홍보에 제시한 배치와 사용 흐름이 지원 상태에서 재현되는가 |

표는 제품팀의 검수 질문이다. 소비자 출시 전 체험이나 제조사 발표만으로 장기 내구성, 사용자 채택과 전환율 개선을 확정하지 않는다.
