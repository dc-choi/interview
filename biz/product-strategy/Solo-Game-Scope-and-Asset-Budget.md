# 1인 게임의 범위와 에셋 예산

게임의 제작 범위는 코드뿐 아니라 장면, 캐릭터, 애니메이션, 소리와 검수할 조합으로 정한다. AI로 초안을 만들거나 에셋을 구매해도 그 결과를 한 게임 안에서 사용할 수 있는지는 별도로 확인한다. 아래는 작은 제작 실험의 운영 기준이며 특정 장르의 성공 확률이나 제작비 배수를 뜻하지 않는다.

## 핵심 플레이와 대표 장면부터 확인한다

게임 개발에 익숙하지 않다면 조작, 목표와 종료 조건이 있는 작은 게임을 먼저 완성하는 접근을 고려한다. Godot의 첫 2D 게임 안내는 이동, 적 생성과 점수 계산을 갖춘 예제를 제공하며, 게임 개발이나 Godot에 익숙하지 않은 사람에게 대체로 더 복잡한 3D보다 2D로 시작하도록 권한다(2026-10-24 확인). 이는 학습 난이도에 관한 안내이지 2D 게임의 판매 우위를 보인 자료가 아니다.

제작 범위를 정할 때는 다음 질문을 사용할 수 있다.

1. 플레이어가 반복할 행동 하나와 그 결과를 짧은 시제품으로 확인할 수 있는가.
2. 대표 장면 하나에 필요한 배경, 물체, 인물과 소리를 셀 수 있는가.
3. 같은 자산을 재사용할 수 있는 부분과 새로 만들어야 하는 부분은 무엇인가.
4. 샘플 이미지의 분위기를 실제 장면과 움직임에서도 유지할 수 있는가.
5. 콘텐츠를 추가하기 전에 조작과 결과가 읽히는지 확인했는가.

위 질문은 제작 실험을 위한 제안이다. 샘플 이미지의 완성과 플레이 가능한 시제품의 완성은 다르다. 특정 장르를 1인 개발에 일괄 금지하거나, 제작한 게임 수를 수요와 수익의 증거로 사용하지 않는다. 플레이 반응은 [[Game-Feel-and-Feedback|게임 손맛과 피드백]], 고객 행동은 [[Solo-Product-Market-Validation|시장 검증]]으로 나눠 확인한다.

## 묶음 개수보다 이번 게임에서 쓸 수 있는 범위를 본다

에셋 번들의 항목 수, 모델 수와 파일 형식은 서로 다른 정보다. 2026-10-24 확인한 Creator Bundle: Volume 1 판매 페이지는 85개 팩과 18,000개 이상의 3D 모델을 안내하며, FBX, Godot 프로젝트, GLB/glTF, Blender와 Unity 패키지의 제공 여부는 개별 팩에 따라 다르다고 명시한다. 이는 판매자가 공개한 구성 설명이며 파일을 모두 내려받아 검수한 결과는 아니다.

페이지 상단에는 25달러와 98% 할인 표시가 있었지만 계속 유지되는 가격으로 사용하지 않는다. 본문에는 무료 팩 24개가 표시되어 있어 과거 소개의 무료 팩 수를 현재 구성으로 옮기지 않는다. 구매 시점의 구성과 조건을 다시 확인한다.

다음은 구매 판단에 사용할 점검 항목이다.

| 항목 | 확인할 질문 |
|---|---|
| 필요한 범위 | 대표 장면에 실제로 쓸 자산이 포함되는가 |
| 적용 비용 | 선택, 변환, 수정과 장면 통합에 드는 시간이 어느 정도인가 |
| 표현의 일관성 | 서로 다른 팩의 크기, 색감과 움직임이 한 장면에서 어울리는가 |
| 실행 확인 | 목표 엔진과 기기에서 샘플을 불러오고 표시할 수 있는가 |
| 사용 조건 | 각 팩의 라이선스, 납품과 원본 파일 전달 조건을 확인했는가 |

자체 제작, AI 생성과 구매를 비교할 때는 구매액이나 생성 비용에 수정과 검수 시간을 더한다. 특정 방식이 언제나 저렴하다고 단정하지 않는다. 이미 산 자산이 많다는 이유로 게임 범위를 늘리는 대신, 핵심 장면에 필요한 자산부터 선택한다.

## 라이선스 표기가 충돌하면 사용 조건을 확정하지 않는다

같은 번들에 들어 있다는 이유로 모든 팩의 사용 조건이 같다고 가정하지 않는다. 2026-10-24 확인한 Free Fantasy Medieval Houses 페이지에는 본문에서 개인과 상업 프로젝트 사용을 허용하면서 원본 파일이나 다른 에셋 팩 형태의 재배포를 금지하는 설명이 있었다. 그러나 같은 페이지의 Asset license 필드는 CC0로 표시되어 있었다.

이 문서는 어느 표기가 우선하는지 판정하지 않는다. 배포자에게 충돌을 확인하고 실제 배포 파일에 포함된 조건도 확인하기 전에는 자유로운 재배포가 가능하다고 결론짓지 않는 방식을 제안한다. 이번 확인은 공개 페이지의 불일치를 찾은 것이며 번들 전체의 권리 검토나 개별 납품물의 이용 허가가 아니다.
