# 규제 업무의 AI 평가: 후보 생성, 검토와 최종 판단

규제 산업에 AI를 적용할 때는 업무의 일부를 빠르게 수행한 결과와 최종 제품의 안전성, 효능 및 승인 결과를 구분한다. 후보를 제안하는 모델, 실제 실험, 문서 검토와 출하 판단은 서로 다른 검증을 필요로 한다.

## 업무 단계마다 완료 기준을 정한다

| 단계 | 확보할 증거 | 대신 증명하지 못하는 것 |
|---|---|---|
| 설계 후보 생성 | 제안의 구조, 제약과 선택 과정 | 실제 실험의 기능이나 임상 효과 |
| 실험 해석 | 원자료, 측정 지표와 반복 검증 | 다른 표적과 조건의 재현성 |
| 문서 검토 | 페이지별 확인 범위, 오류 후보와 근거 위치 | 검토하지 않은 페이지의 무결함 |
| 규제 문서 초안 | 원자료와 초안의 사실 대조, 책임자의 검토 | 규제 승인이나 법적 적합성 보장 |
| 최종 판단 | 전문가의 검토, 승인 권한과 감사 기록 | 모델 결과만으로 자동 출하를 정당화함 |

평가에는 처리 시간뿐 아니라 놓친 중요한 문제, 오탐, 사람이 확인한 시간과 원자료 접근 범위를 넣는다. 비교 집단, 모델 버전과 업무 조건을 맞추고 반복 실행에서 찾은 문제의 합집합과 한 실행의 결과를 구분한다.

## 공개 사례의 읽는 범위

2026-10-27 Anthropic은 6개 조직과의 신약 개발 협력을 발표했다. 공급자와 협력사의 초기 자기 보고이며 임상 성공의 증거가 아니다.

- Generate의 CAR T 설계 한 후보는 특정 부분이 약 70% 짧아졌고 실험실 기능 개선이 보고됐다. 치료제 전체가 70% 작아졌다거나 환자 치료 효과가 입증됐다는 뜻이 아니다.
- BigHat의 항체 후보 최적화에서는 결합, 안정성과 응집 지표를 실험으로 확인하면서 기존 측정 지표도 재검토했다. 점수를 높인 것과 필요한 생물학적 특성을 개선한 것을 함께 확인하는 사례다.
- Enveda의 CDP는 제조 기록을 읽고 이슈 후보를 제시하며, 공식 기록의 수정과 최종 출하 판단은 사람의 품질 조직이 맡는다.
- 임상시험 계획, 연구 운영과 새 회사 구성의 실험은 별도 단계다. 계획의 분석 속도와 임상 성공 확률의 개선은 다른 결과다.

## 제조 기록 검토의 분모를 보존한다

Enveda의 공개 보고는 4개 제조 기록, 1,061페이지를 비교했다. 수작업 1,553분과 CDP 처리 및 사람의 코멘트 확인 166분의 차이는 약 89%다. 후자는 제시된 코멘트를 확인하는 작업을 포함하며, 모든 품질 업무를 89% 줄였다는 뜻이 아니다.

사람이 찾은 서로 다른 이슈 11개는 CDP의 실행들 중 적어도 한 번에서 모두 대응됐다. 9개는 직접 일치했고 2개는 판정자의 추가 설명을 거친 일치다. 측정된 Opus 4.7 실행에는 사람에게 없던 유효 이슈 7개도 있었지만 코멘트 42개 중 33개는 조치가 필요 없었다. 이 결과를 단일 실행의 100% 탐지율로 요약하지 않는다. Opus 5.5의 별도 실행 시간은 기록되지 않았다.

원 제조 기록은 비공개다. 공개 보고의 설계와 결과를 확인한 것이며 독립 재현이나 규제기관의 도구 승인을 확인한 것은 아니다.

## 적용 점검

- 자동화할 업무의 입력, 결과와 최종 승인자를 정했는가
- 오류 후보마다 원자료 위치와 판단 이유가 남는가
- 처리하지 않은 자료와 확인하지 못한 조건이 드러나는가
- 사람의 확인 시간과 수정 비용을 포함해 비교했는가
- 실험실, 문서 평가와 실제 제품 결과를 구분했는가
