# 지원사업 공고 용어

## 정의

정부 지원사업 공고를 읽을 때 반복해서 나오는 용어를 법령, 「중소기업창업 지원사업 통합관리지침」 제14차(2025-12-23 전부개정, 아래 지침)와 2026 공고의 정의로 정리했다. 같은 말이라도 창업사업화, R&D, 바우처 사업에서 뜻이 다를 수 있으므로 공고의 정의 조항을 먼저 본다(예: 2026 TIPS R&D 공고의 전문기관은 창업진흥원이 아니라 중소기업기술정보진흥원이다).

지침의 기관, 사업비, 협약과 사후관리 정의는 제3조의 적용 사업 기준이다. 2026-10-02 재확인은 자기부담의 계산과 현물 증빙, 정산과 반환, 중복 제한의 적용 범위, 두 환수 법률의 제재부가금 기준에 한정했다. 다른 사업의 지원한도와 비율 등은 기존 확인 시점의 기록이다.

## 대상과 성장단계

| 용어 | 뜻 |
|---|---|
| 창업기업등 | 예비창업자, 창업기업, 예비재창업자, 재창업기업을 함께 부르는 법상 지원 대상(중소기업창업 지원법 제3조) |
| 예비창업자 | 창업을 하려는 개인 등(법 제2조). 실제 자격은 공고가 정한다. 2026 예비창업패키지는 기준일 현재 본인 명의 사업자등록증이 없고 법인 대표권도 없는 사람이다 |
| 창업기업 | 중소기업을 창업해 사업을 개시한 날부터 7년이 지나지 않은 기업. 법인과 개인사업자를 모두 포함하고, 고시한 신산업 창업 분야는 10년까지 지원할 수 있다 |
| 사업 개시일 | 업력의 기준일. 법인은 법인설립등기일, 개인은 사업자등록증에 적힌 개업일이다 |
| 초기창업기업, 창업초기 | 사업 개시일부터 3년이 지나지 않은 창업기업. 공고는 3년 이내로 적고 신청 가능 업력을 날짜로 준다 |
| 창업도약기 | 창업초기 이후부터 사업 개시일 기준 7년이 지나지 않은 시기(신산업은 10년). 지침은 성장단계마다 1회씩 총 3회 지원을 원칙으로 한다 |
| 재창업, 예비재창업자 | 중소기업을 폐업하고 새 중소기업을 설립하는 것과 그것을 준비하는 개인 등. 재창업기업은 재창업 후 7년 이내 기업이다 |
| 청년창업기업 | 대표자가 39세 이하인 창업기업. 나이는 만 나이로 계산한다. 청년일자리도약장려금이 지원하는 채용 청년은 만 15~34세(군필자는 의무복무기간만큼 늘려 최대 만 39세)라 기준이 다르다 |
| 여성기업 | 여성이 소유하고 경영하는 기업으로 여성기업지원법 시행령 기준(대표권 있는 여성 최대출자자인 회사, 여성 개인사업자 등)에 맞는 기업 |

## 기관

| 용어 | 뜻 |
|---|---|
| 총괄기관 | 사업 전체를 총괄하는 중소벤처기업부 |
| 전문기관 | 중기부 장관이 지원사업을 수행하게 하거나 위탁한 기관(창업진흥원 등). 주관기관과 창업기업 선정, 협약, 사업비 지급, 점검과 최종평가를 맡는다. 제12차 지침(2024-03-12)까지는 전담기관이라 불렀고 제13차(2025-02)부터 전문기관이라 부른다 |
| 주관기관 | 전문기관과 협약해 창업기업 발굴, 선정평가, 교육, 멘토링, 사업비 집행관리와 정산, 종료 후 5년 성과관리를 맡는 대학, 창조경제혁신센터, 액셀러레이터, 공공기관 등 |
| 협력기관 | 주관기관과 함께 참여해 업무 일부를 수행하는 기관 |
| 사업수행기관 | 기업마당 공고 상세에 적는 사업 집행 기관(예: 초기창업패키지는 창업진흥원, 청년창업사관학교는 중소벤처기업진흥공단) |
| 수행기관(바우처) | 수출바우처 같은 바우처 사업에서는 참여기업이 고르는 서비스 공급 기관을 뜻한다. 공고마다 뜻이 달라 정의 조항을 확인한다 |

## 돈

| 용어 | 뜻 |
|---|---|
| 총사업비 | 정부지원사업비와 자기부담사업비를 합한 금액 |
| 정부지원사업비, 사업화 자금 | 정부가 부담하는 부분. 사업화 자금은 시제품 제작, 마케팅, 지식재산권 출원 같은 사업화 비용으로 쓰는 정부지원사업비를 가리킨다 |
| 자기부담사업비 | 창업기업이 부담하는 현금과 현물. 지침의 표는 총사업비를 분모로 현금 0~10%, 현물 0~20%를 두지만 실제 비율, 현금 최소액과 현물 한도는 공고가 정한다. 현물로 현금 납입을 임의로 대체할 수 없다. 매칭펀드는 지침과 확인한 2026 공고에 없는 용어다. 대응자금은 지침 용어는 아니지만 2026 혁신 소상공인 AI 활용지원 공고가 자부담금(대응자금)으로 병기한다 |
| 현물 | 대표자와 임직원 인건비, 보유 기자재, 사용 중인 사무실 임차료처럼 현금 납입 대신 인정받는 자원. 현금 지급액은 아니며, 승인된 산정 근거와 실제 사용내역을 증빙하고 정산한다. 임직원은 참여율에 따라 계상하며 전 사업 총 참여율은 100%를 넘을 수 없다 |
| 보조금, 출연금 | 반대급부 없이 교부하는 급부금. 중기부 창업활성화지원사업은 출연금이나 보조금으로 지원하고, 받은 자는 별도 계정으로 관리하며 협약한 용도로만 쓴다 |
| 기관부담연구개발비 | 국가 R&D에서 연구개발기관이 부담하는 현금과 현물. 중소기업의 정부지원 비율이 75% 이내인 과제는 해당 계산 대상 연구개발비의 25% 이상을 기관이 부담한다. 현금 최소 비율의 분모는 기관부담액이다. 사업별 지원 우대, 국가 소유 성과나 위탁기관 등의 부담 예외를 확인한다 |
| 기업분담금 | 수출바우처에서 기업이 부담하는 부분(30~50%) |
| 융자, 이차보전, 보증 | 융자는 대출이고, 이차보전은 은행 대출 이자 일부를 보전하는 방식이며, 보증은 기업의 대출 채무를 보증기관이 보증하는 방식이다 |
| 성공환원금 | 추가지원사업비를 받을 때 확약하는 금액. 협약종료 다음 해부터 최대 5년간 납부한다 |

## 신청과 평가

| 용어 | 뜻 |
|---|---|
| 통합공고 | 중앙부처와 지자체의 한 해 지원사업을 모은 목록 공고. 신청은 사업별 개별 공고로 한다 |
| 공고문 | 신청자격, 제외 대상, 제출 서류, 일정, 평가, 제재를 정한 문서. 붙임과 별첨의 양식, 질의응답까지 읽는다 |
| 요건검토 | 신청자격, 제외 대상, 제출서류, 사업계획서 중복률을 확인하는 단계 |
| 서류평가 | 사업계획서로 평가지표와 가점에 따라 점수를 매겨 발표평가 대상을 정하는 단계. R&D나 다른 사업에서는 서면평가라 부르기도 한다 |
| 발표평가, 대면평가 | 발표와 질의응답으로 진행하는 평가. 창업사업화 공고는 이 단계를 발표평가라 부르고 진행 방식을 대면평가 원칙으로 적으며, TIPS 공고는 선정평가를 대면평가로 적는다 |
| 가점 | 공고에 열거한 조건을 충족하면 평가 점수에 더하는 점수. 신청 때 증빙을 내야 인정하는 경우가 많다 |
| 우대 | 가점 외에 자기부담 경감, 서류평가 면제, 우선 선정, 지원한도 확대처럼 조건에 따라 주는 혜택 |
| 이의신청 | 평가 결과에 이의를 제기하는 절차. 기한과 횟수를 공고가 정한다(예: 2026 예비창업패키지는 결과통보 다음 날부터 6일 이내 1회) |

## 협약과 사후관리

| 용어 | 뜻 |
|---|---|
| 협약체결확약서 | 최종 선정 통보 뒤 기한 안에 내는 확약서(2026 초기창업패키지는 3일 이내). 내면 확약서 제출 전에 신청한 창업진흥원 수행 창업사업화 사업과 창업성공패키지(청년창업사관학교 등)의 선정 절차에서 빠진다(2026 예비, 초기창업패키지 공고 기준이고 범위는 공고마다 다르다) |
| 협약 | 선정 후 전문기관과 맺는 계약. 확정된 정부지원사업비를 반영한 수정사업계획서를 승인받아야 하고, 변경 신청은 협약 종료 1개월 전까지만 할 수 있다(전문기관이나 주관기관이 불가피하다고 인정하면 예외) |
| 점검 | 수시점검, 중간점검, 최종점검, 사후점검으로 나뉜다. 중간점검은 온라인 수시점검 방식이 원칙이고, 결과가 중단이면 협약 해지로 이어질 수 있다. 사후점검은 사업종료일부터 5년까지 할 수 있다 |
| 최종평가 | 협약기간 안의 최종 목표 달성 여부로 성공(최우수, 우수, 보통)과 실패(미흡, 극히불량)를 판정한다. 지침은 성과지표 대신 성과목표, 사업추진 성과라는 말을 쓴다 |
| 지출증빙 | 승인된 사업 목적, 집행기간, 거래와 결과물을 입증하는 비목별 증빙. 세금계산서나 카드영수증뿐 아니라 견적서, 검수조서(사진), 계약서, 결과보고서 등을 갖추고 장부와 함께 협약 종료일부터 5년간 보관한다 |
| 정산 | 협약 종료 후 15일 이내에 집행실적과 사용실적보고서, 회계감사결과를 내는 것이 원칙이다. 자기부담사업비도 대상이며 정상 완료해도 집행잔액, 발생 이자, 불인정금액 중 정부지원사업비 부분을 반환한다. 제출기한 연장과 반납의 세부 기준은 지침과 사업별 기준을 확인한다 |
| 환수 | 중도포기, 실패 판정, 목적 외 사용, 허위 등으로 정부지원사업비 전부나 일부를 회수하는 것. 정당한 사유로 포기하거나 실패해도 잔액은 환수한다 |
| 참여제한, 제재부가금 | 이 창업지원법의 참여제한은 7년 한도이며 다른 제도의 한도까지 뜻하지 않는다. 제재부가금은 법정 사유에 따라 환수에 추가하는 금액으로, 보조금법은 반환대상 보조금이나 간접보조금 총액, 공공재정환수법은 부정이익 가액의 5배 이내를 기준으로 한다. 적용 법률, 감면과 배제, 다른 법률 우선 규정을 확인하며 정산 잔액 반환에 일률적으로 붙이지 않는다 |
| 중복 수혜 제한 | 사업 동시수행 금지, 수혜 이력과 횟수, 동일 비용의 중복 집행을 각각 확인해야 하는 제한. 이 지침의 성장단계별 1회와 총 3회에는 후속과 연계 지원 등의 예외가 있다. 계획서 유사성 검토는 별도 요건검토 절차이며 같은 규칙을 모든 R&D, 고용 지원이나 지자체 사업에 적용하지 않는다 |

## 사업 유형

| 용어 | 뜻 |
|---|---|
| 바우처 | 수요기업이 받은 바우처로 등록된 공급기업의 서비스를 사는 방식. 공급기업은 사전에 Pool이나 포털에 등록해야 하고 기업분담금이 붙는 경우가 많다(데이터바우처, AI바우처, 수출바우처) |
| 컨소시엄 | 여러 주체가 역할을 나눠 함께 신청하는 형태. 주관 측과 참여 측의 책임이 다르다 |
| TIPS | 민간투자주도형 기술창업지원. 팁스 운영사가 2억 원 이상(비수도권 1억 원 이상) 투자한 창업기업을 추천하면 정부 평가를 거쳐 R&D 자금을 일반트랙 기준 최대 8억 원(최대 2년) 매칭한다(2026 기준, 일반트랙을 완료한 기업이 대상인 딥테크 트랙은 최대 15억 원) |
| IR | Investor Relations의 약자로 투자자에게 사업과 성과를 설명하는 활동이다. 지침은 판로개척, 네트워킹, 컨설팅과 함께 창업기업 지원 프로그램의 한 유형으로 IR을 든다 |
| PSST | 창업사업화 사업계획서의 네 항목(문제인식, 실현가능성, 성장전략, 팀 구성). [[Government-Grant-Business-Plan|정부 지원사업 사업계획서]]에서 다룬다 |
| R&D 과제 | 국가연구개발사업을 추진하려고 소관 중앙행정기관의 장이 정하는 과제(국가연구개발혁신법 제2조 제2호). 국가 R&D 공고와 접수는 IRIS가 원칙이고 중기부 기술개발사업 일부는 SMTECH를 쓴다(2026 기준) |

## 공식 자료와 다른 풀이

공고 용어를 공식 자료와 다르게 푼 설명과 공식 자료의 내용을 나란히 둔다.

| 다른 풀이 | 공식 자료 |
|---|---|
| 주관기관은 정부 대신 사업을 운영하는 곳이다(예: 창업진흥원, KOTRA, 중진공) | 창업진흥원은 전문기관이다. 주관기관은 전문기관과 협약한 대학, 창조경제혁신센터, 액셀러레이터 등이다 |
| RIPS는 R&D 공고와 신청을 하는 시스템이다 | RIPS라는 시스템은 확인되지 않는다. 그 기능은 IRIS가 한다 |
| 매칭펀드는 5:5, 7:3 같은 비율로 정부와 나눠 낸다 | 지침과 확인한 2026 공고에는 없는 용어이고 비율은 사업마다 정해진다(창업사업화 정부 70~100%, 중소기업 R&D 정부 75% 이내, 수출바우처 정부 50~70%) |
| 초기는 1~3년, 도약기는 4~7년이다 | 초기는 사업 개시일부터 3년 이내, 도약기는 3년 초과 7년 이내(신산업 10년)다. 경계일은 공고의 신청 가능 업력 날짜로 본다 |
| 산업통상자원부(산자부) | 2025-10-01 정부조직법 개정으로 산업통상부가 됐고, 에너지 업무는 기후에너지환경부로 옮겨졌다(원자력발전 수출과 자원산업은 산업통상부에 남았다). 특허 업무를 맡는 지식재산처도 이때 신설됐다 |
| 창업강좌 수료 시 가점 2점, 발표 PPT 필수 | 확인한 2026 초기창업패키지 공고 본문에는 없다. 가점과 발표 자료 형식은 공고마다 확인한다 |
