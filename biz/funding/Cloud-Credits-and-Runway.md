# 클라우드 크레딧과 현금 계획

클라우드 프로모션 크레딧은 정해진 서비스 요금을 상계하는 혜택이다. 지원 한도, 승인된 잔액과 실제 절감한 현금은 서로 다르다. 임대료나 인건비에 쓸 현금처럼 취급하지 않고, 적용 가능한 비용과 만료 이후 비용을 나누어 계획한다.

## 지원 한도와 실제 수혜를 구분한다

AWS Activate는 사례다. 다음 조건은 2026-10-07 공식 안내를 확인한 것이며 신청 시 다시 확인한다.

| 경로 | 공개 안내 | 확인할 조건 |
| --- | --- | --- |
| Activate Founders | 자가 자금으로 운영하는 스타트업, 시작 크레딧 1,000달러와 일부 참여자의 추가 크레딧을 합해 최대 5,000달러 | 모든 신청자에게 최대액을 주는 조건이 아니다 |
| Activate Portfolio | Series B 이전 스타트업에 최대 200,000달러 | Activate Provider의 Organization ID가 필요하다 |

공통 자격에는 설립 10년 이내, Series B 이전 단계, AWS Paid Tier 계정, 신규 수혜 또는 이전 수혜액보다 큰 크레딧 요청이 포함된다. 자격과 제출 자료를 확인한 뒤 신청하므로 최대액을 승인 전 예산에 넣지 않는다. 특정 개인 사업자나 외주 사업이 적격인지는 이 표만으로 판정할 수 없다.

## 크레딧이 대신 내는 비용의 범위

AWS 프로모션 약관은 현금 교환과 환급을 허용하지 않으며, 크레딧을 넘는 서비스 요금은 청구한다. 적용 대상 세금에도 크레딧이 사용되지 않는다. 적용 가능한 서비스와 유효기간은 받은 크레딧의 조건을 확인한다.

Billing의 크레딧 상세에서 잔액, 시작일, 만료일과 적용 가능한 상품을 확인한다. 크레딧은 적격 요금에 자동 적용되며 소진되거나 만료되면 적용이 끝난다. 만료월의 세부 처리는 약관과 청구 주기 기준을 따른다.

## 파트너 PoC 지원은 신청, 승인과 정산을 구분한다

2026-10-13 AWS Partner Central 공개 문서 확인 기준이다. 파트너 지원은 프로그램에 따라 현금 또는 AWS 프로모션 크레딧 형태로 제공된다. 고객이 직접 받는 Activate 크레딧과 같은 신청 경로로 보지 않는다. 파트너 계정의 자격과 해당 프로그램의 요건을 먼저 확인한다.

PoC 지원의 `Tech Approval`은 프로젝트 계획과 작업 범위의 기술적 실행 가능성을 검토하는 단계다. `Finance Approval`은 현금 요청의 구매주문서(PO)나 크레딧 코드를 준비하는 단계이며, 요청 제출 자체가 지원금 수령을 뜻하지 않는다. 프로그램별 승인 절차에는 차이가 있다.

`Pre-Approval`은 필요한 승인을 받아 활동을 시작할 수 있는 단계다. 현금 지원의 `Cash Claim`은 프로젝트나 마일스톤 완료 뒤 실제 수행 내역을 제출하고 검토받는 과정이며, 승인된 내역에 따라 송장을 제출한다. MAP 요청은 별도 `Pre-Approval` 단계를 거치지 않는 예외가 있으므로 단계 이름만으로 모든 프로그램을 같은 절차로 처리하지 않는다.

계약과 현금 계획을 위한 점검 제안: 지원받는 주체, 크레딧 적용 계정, 지원 제외 비용, 증빙과 청구 시점, PoC 이후 운영비를 구분해 확인한다. 파트너에게 승인된 혜택이 고객에게 동일한 금액으로 전달된다고 가정하지 않으며, 지원 승인과 기술 검증 성공도 따로 판단한다.

## AI 지원 프로그램은 자격과 혜택을 나누어 확인한다

Claude Startups는 2026-10-06 공지, 프로그램 페이지와 약관을 대조한 사례다. 지원 조건과 심사 통과, 혜택 수령은 별개다.

2026-10-11 확인한 프로그램 페이지 FAQ는 Claude Team과 1,000달러 API 크레딧 혜택이 제공 한도를 넘었다고 안내하고, 모든 신청을 다시 심사해 일부 신청의 상태가 바뀔 수 있다고 밝힌다. 이미 혜택을 받은 조직은 계정에서 계속 쓸 수 있다. 공지된 혜택이 신청 시점에 제공된다고 가정하지 말고 현재 제공 여부부터 확인한다.

| 확인할 항목 | 공개 조건과 예산 반영 경계 |
| --- | --- |
| 신청 자격 | 2026-10-06 공지 기준 설립 5년 이내 또는 최근 2년 내 투자 유치한 스타트업이다. 2026-10-11 프로그램 페이지는 부트스트랩, 프리시드와 VC 투자 기업 모두 신청할 수 있다고 안내하고 설립, 투자 시점 기준은 적지 않는다. 신청은 Claude Console에서 하며, 2026-10-08 확인 당시에는 웹사이트 도메인과 일치하는 회사 이메일과 만드는 제품 설명도 요구했다. 지원 가능 지역 등 정책도 충족해야 한다 |
| 심사 | 신청마다 심사하며 공식 목표는 1주 이내다. 약관상 사업 성과, 투자와 자금 조달, Claude 통합과 사용 등 여러 요소를 고려하며 최종 적격 여부는 Anthropic이 판단한다. 도메인과 회사 이메일만으로 승인을 보장하지 않는다 |
| API 크레딧 | 공지는 승인 기업에 1회 1,000달러를 제공한다고 밝혔다. Claude Console의 직접 API에 적용되고 Bedrock, Vertex AI 등 제3자 플랫폼에는 적용되지 않으며, 받은 멤버는 API rate limit이 자동으로 올라간다. 2026-10-08 확인 당시 부여일부터 6개월 후 만료로 안내됐지만 2026-10-11 프로그램 페이지에는 만료 문구가 없으므로 받은 크레딧의 만료일은 Console에서 확인한다 |
| Team 구독 | 공지는 Claude Team을 처음 쓰는 조직이 Premium 좌석 최대 5개를 1년간 무료로 쓸 수 있다고 밝혔다. 공지는 Premium 좌석 5개를 연 결제 기준 좌석당 월 100달러로 1년 쓴다고 보고 이 혜택을 6,000달러로 계산하며, 실제 가치는 좌석 수와 종류에 따라 다르다고 밝힌다. 일반 Team 플랜은 최소 2명부터다. 스타트업 혜택에 같은 하한이 붙는지는 공지와 프로그램 페이지에 없으므로 1인 사업자는 신청 전에 좌석 조건을 확인한다. API 크레딧과 구독 혜택의 기간을 같은 것으로 계산하지 않는다 |
| 지원 활동 | Applied AI 오피스아워는 멤버 대상 45분 라이브 세션으로 격주로 열린다. 파트너 네트워크에 속한 VC의 투자를 받은 회사는 그 VC를 통해 최대 10만 달러의 추가 API 크레딧 대상이 될 수 있다. VC를 통해 청구하며 대상 여부도 보장되지 않는다 |
| 파트너 혜택 | 최대 45,000달러는 제휴사의 할인과 크레딧 등을 합친 제안 가치다. 현금 지급액이나 모든 회사의 확정 절감액이 아니다. 각 혜택은 제3자가 제공하며, 제공사가 달리 정하지 않으면 멤버당 한 번 교환(redeem)할 수 있고 양도할 수 없으며 현금 가치가 없다. 각 제공사의 자격, 기간과 약관을 따로 확인한다 |

승인 뒤에도 Console에서 실제 제공된 혜택과 수령 조건을 확인한다. 신청 준비 때는 현재 제품과 Claude 사용 방식을 사실대로 설명하고, 실제로 줄일 수 있는 비용만 현금 계획에 반영한다. 신청 후기가 심사 기준이나 개인 사업자의 적격 여부를 대신하지 않는다. 재심사로 상태가 바뀔 수 있다는 안내가 있으므로 승인 메일만으로 혜택을 기본 시나리오에 넣지 않는다.

## 만료 전후 현금 지출을 따로 계산한다

다음은 지원 정책 자체가 아니라, 일시적 혜택을 현금 계획에 반영하는 관리 방법이다.

1. 크레딧 적용 전의 예상 청구액을 계산한다. 현재 사용량과 성장 시나리오를 따로 둔다.
2. 비용을 적용 대상, 적용 제외와 세금으로 나누고 월별 상계액을 계산한다.
3. 상계액을 잔액과 유효기간 안으로 제한한다. 승인되지 않은 추가 지원은 기본 시나리오에서 제외한다.
4. 소진 또는 만료 뒤의 현금 지출로도 운영 가능한지 확인한다. 그렇지 않으면 사용량 축소나 이전 준비 시점을 앞서 정한다.

가상 예로 한 달 클라우드 요금이 120이고 그중 100만 크레딧 대상이며 다른 청구가 없다면, 해당 월에 쓸 수 있는 잔액이 충분할 때 현금 지출은 20이다. 혜택 종료 뒤 동일한 사용량과 가격을 유지하면 지출은 120으로 늘어난다. 세금과 다른 사업비는 이 예에서 제외했다.

지원 규모가 커도 필요 없는 서비스를 쓰면 지속 비용과 이전 부담이 늘 수 있다. 크레딧 적용 전 비용, 적용 뒤 현금 지출, 종료 뒤 비용을 함께 비교한다. 크레딧 수혜를 제품 수요나 수익성의 검증으로 보지 않는다.
