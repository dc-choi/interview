# Economics Domain Rules

이 파일은 `econ/` 아래의 경제, 투자 지식 문서와 카테고리 인덱스에 적용한다. 메모 입력을 문서화할 때는 `memo` 스킬도 함께 사용한다.

## 문서 표기

- `## 출처`의 표기는 `tech/AGENTS.md`의 출처 표기 규칙을 준용한다. 기존 econ 문서의 `- [매체 — 제목](URL)` 역순 표기는 문서 내 선례로 유지하고, 선례 없는 새 문서는 tech 기본형을 쓴다.
- 하단 절 순서도 같은 규칙을 준용한다. 2026-08-25의 기존 문서 순서 정규화와 `## 관련` 헤딩의 `## 관련 문서` 통일은 사용자 지시로 수행한 일회성 예외다.
