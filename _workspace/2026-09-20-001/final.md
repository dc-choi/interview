# 한국어 문체 정리 결과

일반 문서 1,993개를 작업 목록으로 확인하고, 후보 표현의 문맥을 검토해 297개를 수정했다. 수정하지 않은 문서는 1,696개다. 이 가운데 세미나 원본과 면접 회고 42개는 원문 그대로 보존했다.

수정본은 각 문서에 직접 반영했다. 파일별 상태, 변경 규칙, 전후 글자 수와 SHA-256은 [manifest.json](manifest.json)에 기록했다. 기준 커밋은 `65c23f2797cee9de877b4b1db17854bd9e47b351`다.

후속 [자기소개와 면접 답변 재검토](../2026-09-20-002/final.md)에서 공통 답변 4개를 추가 수정하고, 아래에 기록한 검색 학습 상태의 차이를 정리했다. 이 보고서의 변경량과 해시는 1차 작업 종료 시점의 기록이다.

## 범위와 수정 방식

| 영역 | 확인한 문서 | 수정한 문서 |
|---|---:|---:|
| root | 1 | 0 |
| biz | 61 | 19 |
| econ | 35 | 8 |
| fit | 272 | 61 |
| ontology | 24 | 8 |
| tech | 1,600 | 201 |

번역투, 상투적인 도입문, 반복 접속사와 불필요한 쉼표를 줄였다. 문서의 격식, 기술 용어, 유용한 표와 목록은 유지했다. 지침, 스킬, 코드와 설정은 작업 대상에서 제외했다.

전체 목록을 패턴 검색한 뒤 후보 구간을 문맥과 함께 검토했다. 모든 문서의 모든 문장을 사람이 쓴 글인지 판별했다는 뜻은 아니다. 기술 정의, 실제 발화, 원본 기록에 필요한 표현은 검색에 걸려도 유지했다.

## 변경량

- 전체 목록 글자 수: 8,033,045 → 8,032,010
- 수정 문서 글자 수: 1,676,017 → 1,674,982
- 수정 작업: 736건. 같은 문장에 여러 규칙이 적용된 경우가 있다.
- 파일별 최대 변경률: 약 0.7%. 변경률 경고(30%)와 중단(50%) 대상은 없었다.

글자 수는 마크업을 포함한다. 변경률은 스킬의 `verify_change_rate.py`로 파일마다 검증한 문자 유사도 차이이며, 글자 수 감소율과 다르다. 도구 출력에 맞춰 소수점 한 자리로 기록했다.

추가로 수정한 줄의 기존 후행 공백 1건을 제거했다. 여러 규칙을 적용한 작업은 각 규칙에 중복 집계했다.

## 전후 검색 참고치

수정한 297개 문서에서 같은 검색식을 적용했다. 프론트매터, 제목, 코드와 출처 절 등은 제외했다. 아래 수치는 문맥상 문제가 확정된 건수나 AI 작성 확률이 아니다. 예를 들어 C-11에는 절을 구분하는 데 필요한 쉼표도 포함된다.

| 규칙에 대응하는 문자열 | 수정 전 | 수정 후 |
|---|---:|---:|
| D-8 | 142 | 9 |
| A-19 | 76 | 11 |
| A-7 | 4 | 0 |
| A-8 | 1 | 0 |
| C-11 | 1,708 | 1,144 |

검색식은 `manifest.json`의 수치와 대응하며, D-8은 강조 도입, A-19는 이중 조사, A-7은 가지고 있, A-8은 이중 피동 후보, C-11은 연결어미 뒤 쉼표를 세었다.

## 검증

- 수정 문서 297개: 프론트매터, 제목, 코드, 링크 대상, 수식, 체크 상태, 표 구조와 숫자 순서 보존 검사 통과.
- 온톨로지 추출 결과: 링크, 명시 관계, 제목 기반 단위 ID와 추출 범위 경고 보존 검사 통과.
- 평가 자료의 고정 검색 문구: 문서별 출현 횟수 보존 검사 통과.
- 보존 대상 42개와 나머지 미수정 문서: 작업 전 사본과 바이트 일치.
- 실제 변경 파일과 편집 기록 일치. 수정 문서에 금지 구분자 없음. 새로 길이 제한을 넘긴 문서 없음.
- `git diff --check` 통과.

온톨로지 검증에는 작업 트리의 수정본을 직접 파서에 전달했다. 커밋된 HEAD만 읽는 색인 빌드를 수정본 검증으로 사용하지 않았다. 의미와 문체는 수정 구간을 전후 비교해 검토했으며 자동 구조 검사만으로 의미 보존을 판정하지 않았다.

## 기존 내용에서 확인한 차이

[면접 답변 초안](../../fit/interview/common/My-FIT-Answers-Extended.md)의 최근 학습 문단은 검색을 현재 1순위로 설명한다. [현재 목표](../../fit/growth/Current-Goals-and-Roadmap.md)는 검색 학습을 보류 상태로 기록한다. 문체 수정으로 학습 상태를 결정하지 않도록 두 문서의 해당 사실 서술은 유지했다.

## 표현 예시

- Provider는 일반적으로 애플리케이션 수명 주기와 일치하는 수명(Scope)을 가지고 있습니다 → Provider의 수명(Scope)은 일반적으로 애플리케이션 수명 주기와 일치합니다
- 중요한 것은 변환 규칙보다 의미와 무결성이 보존되는지다 → 변환 규칙보다 의미와 무결성이 보존되는지가 중요하다
- 잊혀진 데이터 → 잊힌 데이터
- 짧은 문장에서 반복되는 연결어미 뒤 쉼표를 줄이고, 긴 절의 구분에 필요한 쉼표는 유지했다.
